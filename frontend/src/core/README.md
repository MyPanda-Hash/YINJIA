本目录承载多个 MES 面板共同使用的请求基础能力、响应处理和通用视图。完整页面规则见 [前端面板设计](../../../docs/frontend/前端面板设计.md)。

## 内容

| 位置 | 职责 |
|---|---|
| `request.js` | Axios 基建、JWT 注入、认证失效处理和错误归一化 |
| `panel-engine.js` | 面板接口响应解包和消息提取 |
| `panel-runtime.js` | 通用视图依赖的运行时契约、安装和边界校验 |
| `views/PanelxList.vue` | 配置驱动的列表、单据浏览和工具栏入口 |
| `views/PanelxForm.vue` | 配置驱动的表单和明细编辑 |
| `views/*Dialog.vue` | 参照、选单、审批历史、导入和业务明细弹窗 |

## 边界

`core/views` 只通过 `usePanelRuntime()` 使用运行时契约。当前应用在 `main.js` 安装 SQL 适配器 `business/engine.js`；PLM 可以提供自己的适配器或在现有适配器上增加能力，不需要复制通用视图。

维护时遵守以下规则：

1. 通用视图中不保存面板配置、种子数据或演示行。
2. `core` 不得导入 `business`；面板码、接口差异和业务查询集中在适配器或业务模块。
3. 某个面板需要的新控件先抽象成通用能力，再由 SQL 配置启用。
4. 不在通用组件中按业务面板编码增加一次性渲染分支；确有必要时记录边界和移除条件。
5. 修改后至少运行前端生产构建；涉及保存、审批、选单或生单时执行对应交互回归。
6. 运行 `node tools/architecture-audit.mjs` 检查依赖方向。
