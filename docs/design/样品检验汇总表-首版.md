# 样品检验汇总表 —— 首版设计与实现契约

> 任务来源(用户 2026-11-17 口径,原文):
> 「为当前的样品检验增加汇总表,能够查看到一天或者一周,送好多个样品,测试啥的总表。
> 要按一个时间范围,去导出有多少人送了啥样品测试啥,安排检测工作。」
>
> 需求三问的答复(同日确认):
> 1. 放置位置 = **样品检验下新增独立页面**(不是塞进检验委托单面板);
> 2. 汇总视角 = **按送样人** + **按委托单/样品**(一单一行,列出该单要测的项目);
> 3. 本期**不做**「安排人 / 计划检测日期」等可写字段 —— 先看汇总 + 导出 Excel 线下安排。

本文件是这条功能的唯一契约:页面行为、取数口径、字段、权限、迁移与验收以本文件为准。

## 二、取数口径(唯一真源)

- **行源**:`qc_insp_commission_head`(检验委托单头)`LEFT JOIN` `qc_insp_commission_detail`(行)。
  一行 = 该单的一个检测项目;没有行的单也保留(检测项目数 = 0)。
- **时间范围**:按单头 `单据日期` 闭区间 `[日期起, 日期止]`;传反了按同一区间查(不报错)。
- **排除**:单头 `asp_cancel='Y'` 的一律不查;**默认不含**「已作废 / 已中止」的单(废单不算检测工作量);
  要看待废单必须在「单据状态」里显式选择。
- **单据状态**:与 `QueryService` / `QcFlowService` **同一口径**(单一真源 `yj_doc_status`):
  - `yj_doc_status` 有行:已作废 > 已中止 > 审批中 > 已审核 > 草稿;
  - 没行(旧数据/导入):先看单头 `审核时间`,再看单头 `单据状态` 列,最后兜底「草稿」。
- **送样人**:单头 `联系人`(2026-11-17 起是"有账号人员姓名"下拉,也允许历史手输姓名);
  空值统一显示「未填送样人」。
- **收费**:单头 `合计收费`(含 6% 增值税,由行表收费合计回写);单头为空/0 时退化为行表收费合计。
- **检测项目**:行表 `检测元素`(目录里的检验项目名)。

## 三、两个视角(界面上两个页签)

### 3.1 按送样人(`按送样人` 页签,默认)

行 = 一个送样人(时间范围内)。列:

| 列 | 口径 |
|---|---|
| 送样人 | `联系人`(空 → 未填送样人) |
| 送样单数 | 该人的委托单数 |
| 检测项目项次 | 该人所有委托单的检测项目行数之和 |
| 涉及样品 | 该人送过的 `样品名称` 去重(顿号连接) |
| 检测项目 | 该人所有项目去重(顿号连接) |
| 已审核单数 / 待检单数 | 单据状态 = 已审核 / 其余(草稿 + 审批中) |
| 收费合计 | 该人所有单据「合计收费」之和 |
| 最近送样日期 | 该人最大 `单据日期` |

排序:送样单数降序 → 收费合计降序 → 最近送样日期降序 → 姓名升序。
展开行 = 该送样人的委托单列表(单据日期 / 单号 / 样品 / 类别 / 数量 / 项目数 / 项目 / 收费 / 状态)。

### 3.2 按委托单/样品(`按委托单/样品` 页签)

行 = 一张检验委托单。列:单据日期、单据编号(可点开该单,需检验委托单查看权)、送样人、委托单位、
样品名称、样品型号/规格、样品数量、检测项目数、检测项目、测试方法、收费合计、单据状态、审核人、审核时间。
展开行 = 该单的检测项目明细(行号 / 检测元素 / 测试方法 / 测试周期 / 收费)。

### 3.3 顶部汇总条

送样人数 / 送样单数 / 检测项目项次 / 收费合计 / 已审核单数 / 待检单数 —— 与两个视角**同一次取数**折叠而来,
不会出现"按人合计 ≠ 按单合计"。

## 四、时间范围与筛选

- 快捷区间:**今天 / 本周(周一→今天)/ 本月 / 上月 / 自定义**;默认「本周」。
  点快捷区间即查询;自定义 = 用户选日期后点「查询」。
- 筛选:送样人(模糊)、单据状态(全部/草稿/审批中/已审核/已作废/已中止)、关键字
  (单号 / 样品名称 / 检验类别 / 委托单位 / 检测项目,任一命中)。
- 「重置」回到本周 + 清空筛选。

---

## 五、导出 Excel(安排检测工作的那张表)

点「导出 Excel」一次给 **3 个 sheet**(前端 `xlsx` 现生成,不落服务端):

1. **按送样人** —— 与界面页签同列 + 末行合计;
2. **按委托单** —— 与界面页签同列 + 末行合计;
3. **检测明细** —— 一行 = 一个检测项目(日期/单号/送样人/样品/类别/数量/行号/检测元素/测试方法/测试周期/收费/状态)
   + 末行收费合计。**这张就是拿去排班的明细**。

文件名:`样品检验汇总表_<起>_<止>.xlsx`。导出按钮按 `pagePerms` 的 `export` 词显隐(管理员恒可)。

## 六、权限与可见性

- 服务端:`InspSummaryController` 入口 `perm.requirePanelView(INSP_SUMMARY)` —— 拿 token 直调也拦得住;
- 前端:菜单按 `visiblePanels` 过滤(与其它页面级面板同一口径),路由 `meta.panelCode` 拦手输 URL;
- 授权初值:`migrate-insp-summary-20261117.sql` 给**已能看检验委托单或送样登记表的角色** + 管理员
  补 `view,query,export`(按角色码整批补,不写死 role_id);
- 跳转权限:点单号前用 `canViewPanel` 判检验委托单查看权,没权限只提示、不发路由。

## 八、验收标准

1. 两账套执行迁移成功;`yj_role_panel` 中 `INSP_SUMMARY` 的授权覆盖全部"能看检验委托单/送样登记表"的角色,
   `yj_translation` 有 10 条面板名译名;
2. `mvn package` + `npm run build` 通过;5173 打开:
   - 样品检验下出现第三个菜单「样品检验汇总表」,点开无 403;
   - 默认「本周」自动出数;切「今天 / 本月 / 上月」数字与明细随之变化;
   - 「按送样人」展开能看到这个人的单;「按委托单/样品」展开能看到该单的检测项目;
   - 点单号能跳到检验委托单并定位该单;
   - 「导出 Excel」生成 3 个 sheet,合计与界面一致;
3. 切 English 后:菜单/页面标题/列头/按钮/提示为英文(业务数据如人名、样品名、单据号不翻译);
4. 对既有面板零影响(不改 `yj_panel` / `yj_field` / 任何业务表结构)。
