# 首件检验单 · 取成型工艺清单(按列合并) + 选生产工单（2026-10-16 第四轮）

用户口径：

> 「让当前取成型工艺清单的按钮实现的时候能够**带入当前其对应列内填写的数据内容**。然后**去除**当前首件
> 检验单中**检验项目/检验方案**的按钮，然后让当前的首件检验单**也可以选择到生产工单**。当前制程检验单中
> 存在实现方式，可以参照制程检验单的实现方式进行。」

## 一、取成型工艺清单：改成**按列合并**（保留已填数据）

**病根**：这个按钮原先借用了 `PanelxList.applyShipPlanItems` —— 那是给「一行一个检验项目」的四张工序检验单
写的**平表**追加器。首件检验单是「样品序号 × 检验列」的**长表**，喂进去的行没有
`行类型 / 样品序号 / 检验列` ⇒ 纸上会长出一列**没有标准行、没有样品格**的怪列，而且是把同名项目当"新项目"
再追加一遍（判重键不同），已填数据也就带不过来。

**现在**：换成列模型自己的合并实现 `frontend/src/core/qc/firstInspCols.js` →
`mergeFetchedColumns(head, fetched)`，规则**以列**为单位（列身份 = 检验列 key，与后端 `FirstInspItems` 同一套）：

| 情况 | 处理 |
|---|---|
| 已有同名列 | **只刷新「标准」**（工艺清单改版要能带过来）；列名/分组/已录数据（实测数值、结果判断、备注）**一律保留** |
| 没有的列 | 整列新增（1 行标准 + 8 行样品），接在明细末尾 |
| 已有列缺样品行（手删过/老单） | 补齐缺的行，**已有的数据行不重复、不覆盖** |
| 任何情况 | **不删列** |

提示话术如实报出结果：`已按成型工艺清单 DEMO-MP-001：新增 0 列、刷新标准 10 列、保留已填数据 2 格`
（1 个新词条 × 10 语言；`kept` = 实测数值 / 结果判断 各算一格）。

## 二、去掉「检验项目/检验方案」按钮

`PanelConfigService` 给四张检验单注入「检验项目/检验方案」（检验标准库入口）；首件检验单的检验要求有**专用
来源**《成型工艺清单》(`RD_MOLD_PROC`，即「取成型工艺清单」)，挂上标准库入口只会让品质点错来源 ⇒
注入时**首件检验单除外**。

## 三、首件检验单「选生产工单」（照制程检验单那套做）

| 层 | 制程检验单（原有） | 首件检验单（本批新增，同一套做法） |
|---|---|---|
| 工具栏入口 | 「选生产工单」 | 「选生产工单」（排在「取成型工艺清单」之前：先按工单行建单，再带检验项目） |
| 弹窗 | `QcProcInspWoPicker.vue` | **同一个组件**，新增 `mode` prop 分流（不复制一份） |
| 取工单行 | `GET /api/qc/procInsp/woLines` | `GET /api/qc/firstInsp/woLines`（同口径：未作废未结案 + 「已建单号」） |
| 建草稿 | `POST /api/qc/procInsp/fromWoLine`（明细**留空**） | `POST /api/qc/firstInsp/fromWoLine`（明细**按《成型工艺清单》预铺**，与报工审核自动出单同源：同一个 `FirstInspItems`） |
| 表头 | 单据日期/检验日期/工单号/工单行号/产品/规格/批次/生产线/生产车间/检验类别/检验员 | 同上，**另带 客户代码 + 客户名称**（`plang.khdm` → `dm_kh.mc`；纸面相关要求第 6 条的 C-95 判据） |
| 幂等 | 同一 (工单号, 工单行号) 已有存活单 ⇒ 返回那张 | 同左 |
| 生产日期 | — | **刻意留空**，仍由「工单第一批完工」回填（上一轮口径，见 `FirstInspBackfill`） |

## 五、回滚点

- 合并逻辑：`firstInspCols.js` 的 `mergeFetchedColumns` / `ensureColumnRows`（纯函数，删掉即回到旧行为，
  但旧行为会造怪列）；
- 工具栏：`PanelConfigService` 两处（首件除外 + 注入「选生产工单」）；
- 选工单：`QcFirstInspController.fromWoLine/woLines` + `QcProcInspWoPicker.vue` 的 `mode` +
  `PanelxList` 的 `woPickerMode` 接线。删这三处即回到"首件检验单不能选工单"。
