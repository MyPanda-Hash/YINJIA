## 1. 总体流转（面板↔面板）

```
订单结转工作台(生产计划→订单结转)          【已上线】
   剩余=需求−已排产−已采购 → 转工单(自制)/转采购单(外购成品),行级占用链防重复,不改销售订单状态
        │ 「生成生产加工单」/SO_ORDER 面板按钮(同一核心 createFromOrderLine)
        ▼
生产加工单面板(MANU_ORDER)                 【已上线】
   编制/保存/审核;附件1~6(两套纸质工单上传);混料批次号/重点管控/模具类型;
   按钮:拆单·结案·首件完成通知·生成采购申请·生成产品批号·复制·打印工单二维码
        │ 审核
        ▼
排产工作台(生产计划→排产工作台)            【已上线·§5 三段式】
   待排产池(已审核·未指派产线) → 选生产线(档案下拉,带负荷) → 单笔/批量排入 → 撤销排产回池
        │ scheduleOne(守卫+数量守恒+留痕)
        ▼
工单排产看板(生产计划→工单排产 WorkOrderBoard)   【已上线·2026-09-23 纠偏】
   产线骨架(=生产线档案全部线,停用标记可查看;开线切换) → 按线查看运行中工单(未完工/已完工/全部) + 批量调线;
   当日再拍板:去白班/夜班维度(开线=日×线),骨架与基础资料生产线一一对应(停用线可看不可排);
   替代「生产排产 MANU_SCHEDULE」平铺看板(菜单下线,面板/权限行保留可回滚,同 WO_ORDER 先例)
        ▼
产线排产负荷面板(LINE_LOAD)   【已上线】
        ▼
工序报工/领料/入库(回写 入库数量·余量·完工日期) → 结案
```

**范式**：单据流转=面板↔面板（按钮生单/跳转 gotoPanel）；工作台仅为"判断+生成/分配+跳转"的调度台，
生成的单据仍是标准面板单据。曾经的「快速排产」专用页（含 /api/px/quickSchedule/*）已按此口径整体移除。

## 3. 生产线档案（归位基础资料）

- **表 `bs_prod_line`**（基础资料·生产组菜单「生产线」PROD_LINE）：生产线（唯一）/生产车间/日产能/小时产能/排序/停用/备注，
  表+关键列中文注明。**产能是档案属性**：日产能=负荷/超载基准，小时产能与 工序工时(OP_TIME) 互补。
- **初始铺底 8 条**：成型1~5线（成型1~5号车间）、切炭线、组装线、装箱线；日产能=0 待业务维护（0=不判超载）；
  混料线暂不建（材料段涉密不进系统）。
- **旧方案收编**：`bs_line_capacity`/LINE_CAP「产线产能」（曾在生产计划组）数据迁入后整体下线；
  `v_line_load` 改读 bs_prod_line（含停用过滤）。口径更正记录：C-000=张莉 为金蝶档案合法客户名
  （dm_kh 解名），并非业务员污染——客户解名链=bs_partner → **dm_kh** → SO 原值。

## 4. 已上线能力清单（生产域）

| 能力 | 入口 | 要点 |
|---|---|---|
| 生单（一单多次多张） | SO_ORDER「生成生产加工单」 | 需求数量=订单行数量(xq_sl)；数量/排产数量=本次生单量(pl_sl)；占用=剩余，用尽退出 |

## 6. 口径速查

- 排产判定=指派生产线（生产线为空=未排产）；**仅已审核可排**（排产台口径）。
- 数量守恒：排产数量≤本单生单量（超限拒绝，增产=同订单行再生成一张）；占用随排产数量走。
- 余量=排产数量−入库数量（头级优先）。开产量=首道有报工工序（混料→成型→切炭→组装→装箱）完成数量。
- 生产状态：完工（入库≥排产）/在产（开产>0）/待产（已指派产线）/未排产。
- 交期紧迫度=工序交期−今天（负=逾期红）；7天/15天/大于15天 已排产三桶（逾期归首桶）。
- 负荷均摊：计划开工日→工序交期 摊到自然日，超窗截断、逾期归当日；停用产线不显示。
- 超载只提示不拦截（排产人工拍板）。
- **停用全链生效点**(2026-09-23 修复完备):排产工作台产线下拉(v_line_load 只出启用线)·排入 assign·调线 reassign·开线 setOpen
  四处后端守卫拒绝停用线;工单排产骨架显示全部线(停用灰显可看不可动);MANU_ORDER 表单生产线已只读(排产台单一写入)。
