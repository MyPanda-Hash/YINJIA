# 首件检验单 · 生产日期完工回填 + 顶栏标题居中（2026-10-16 第二轮）

面板 `QC_FIRST_INSP`（首件检验单《炭棒成型车间首件检验记录表》）。本批两件事，都来自同一张截图红框。

## 一、用户口径（原话）

> 「让当前的红框内容居于空白位置中央，让生产日期在当前根据当前的生产工单完成首批次后进行回填到当前的实现，
> 生产的环节是有工单号，检验单是绑定工单号的，这个工单生产啥样的批号，检验人员是不知道的，追溯的时候，
> 由批号找到工单，再由工单找到检验单的，批次号是完工时自动生产的就这样实现吧。」

拆成两条：

| # | 诉求 | 落地 |
|---|---|---|
| 1 | 红框（纸张顶栏：左上空白 + 右上信息三格）里的大标题「居于空白位置中央」 | **纵向**移到顶栏空白的正中央；**横向仍以整张纸为参照居中**（用户当场在 A/B 口径里选了 A：与纸质表单一致） |
| 2 | 「生产日期」按**当前生产工单完成首批次**后回填 | 首件检验单**出单时不再写死今天**；工单行**第一次进入生产完工**（批号就是这一刻自动生成的）时，由系统把 **生产日期 = 完工当日**（+ 空着的批号）回填到**绑该工单号**的那张首件检验单上 |

## 二、口径与链路

```
报工审核（本批第一张）
        │  ButtonService.firstInspGenerate
        ▼
首件检验单 QC_FIRST_INSP  ── 绑「工单号 + 工单行号」，出单时 生产日期/批号 不做假设
        ▲
        │  FirstInspBackfill.backfillOnFirstBatch（同一次事务）
        │
工单行首次「生产完工」 ── ProcessTaskService.assignProductionBatch
        │  批号 = 当天 yyyyMMdd（空则取号），同步到 plang_pc / wo_progress / scjl
        ▼
追溯：批号 → 工单（plang.批次号）→ 检验单（qc_first_insp_head.工单号+工单行号）
```

三条硬口径：

1. **出单不写死日期**：出单那一刻本行还没完工，完工日就是未知的 —— 该项留空，等完工回填
   （只读纸张仍按 `生产日期 → 检验日期 → 单据日期` 回落显示，纸面不会开天窗；见 `QcFirstInspSheet.vue` 的 `headText`）。
2. **只填空格**：回填一律 `COALESCE(NULLIF(现值,''), 新值)` —— 品质手工填过的生产日期/批号**不覆盖**。
3. **回填的是「工单完工日」**：取 `plang.完工时间`（完工那次写入），不是出单日、不是系统当天。

## 三、代码落点

| 文件 | 作用 |
|---|---|
| `backend/.../service/FirstInspBackfill.java`（新） | 深模块（与 `FirstInspItems` 同范式，静态 + `JdbcTemplate`）：`completedBatch()` 取本行完工批次/完工日；`backfillOnFirstBatch()` 按 工单号(+工单行号) 回填、只填空格 |
| `backend/.../service/ProcessTaskService.java` | `assignProductionBatch()` 增加 `prevState` 入参：**首次**进入 `生产完工` 才回填（重算/重审/再报工不重复） |
| `backend/.../service/ButtonService.java` | `firstInspGenerate()` 不再 `head.put("生产日期", today)`；若出单时本行**已经完工**（单工序路线走首张报工即完工，或事后补出单）当场按完工日填上 |
| `frontend/src/core/qc/QcFirstInspSheet.vue` | 顶栏合成一块 `.fi-header`（`position:relative` + `padding-bottom:47px` 顶住原高度），标题绝对定位两向居中；信息三格 `z-index` 抬高 + 白底，窄屏也不挡点击 |

- ① 首张报工审核自动出单，**生产日期为空**、检验单绑到 工单号+工单行号；
- ② 末道报工审核 ⇒ `完工状态=生产完工`，检验单回填 **生产日期 = 完工当日**；
  ⚠ 完工程序里预置 `plang.完工时间 = 2026-08-08`（完工那次对它只保留不改）⇒ 检验单上回填出来的
  是 **2026-08-08 而不是今天**，证明这一格取的是**工单完工日**，不是出单日/系统当天；
- ③ 另一行的检验单在完工前被"人工填了生产日期、批号空着" ⇒ 人工日期**不被覆盖**，空批号被补上；
- ④ 「出单即完工」分支：临时把路线前道作废（只留末道）⇒ 出单与完工落在同一笔事务，生产日期当场按完工日填上；
- ⑤ 批号 → 工单 → 检验单 追溯链通。
