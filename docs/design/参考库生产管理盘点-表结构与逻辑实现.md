### 1.2 业务主线(单据流与数据流)

```
销售订单 order/order1(order_bs 明细)

    │  委外:dh+View_WB_WLQTY 系列;wbgd 外包工单台账            [委外]
    ▼
报工/完工 scjl(工单×工序,状态机 到位→开始→完工)              [SCGL·工序报工/完工登记]
    │  完工即入库:inh(bz1='生产入库'),单号回写 post_no→rk_no     [CKGL·产品入库]
    ▼
kucun 库存资料(rkl/ckl/yl 滚存) ←→ zc 转仓单 / pd_zzp 在制品盘点
    ▼

```

## 3. 逻辑实现(参考库)

### 3.0 架构事实:逻辑不在存储过程,在「视图 + 应用层 + 数据约定」

对 `sys.objects` 全量盘点(见 `tools/archive/_ref-dump` 取证):**375 张表、0 个存储过程、
0 个触发器、0 个函数、102 个视图**(另有 376 PK/10 UQ/2018 默认约束)。
即参考库的全部数据库侧逻辑 = 102 个视图表达的业务口径 + 旧应用(ASPSMT)内的 SQL + 统一数据约定:
软删 `asp_cancel`、审计四段 asp_user1..4、软结案 `ja`、单号池 s_allno、批号三元组 lot_no+color+siz。

### 3.1 排产口径(plang_pc,新系统直接继承的权威口径)

1. **一张工单 = 一条订单行,1:1**:plang_pc.pl_xc 恒为 1;25 行工单对应 25 条订单行
   (od_no+od_xc 关联 order_bs.id)。`View_pcqty` 按订单行汇总 `SUM(plang_pc.pl_sl) AS pc_qty`。
2. **数量链**:`xq_sl 需求数量(=订单行数量) → pl_sl 排产数量(可改、可分批增量) → rk_sl 入库数量(完工回填) → yl 余量(=pl_sl−rk_sl)`;
   plang.ypl_sl 已排产数量用于控制订单行不超排。pl_sl2 排产数量2 为二次数量(双单位口径)。
3. **交期链**:jh_date 订单交期(排产屏的紧迫度基准)→ st_date 开始 → cp_date 计划完工 → cp_date2 实际完工。
4. **回写单号**:rk_no 入库单号、ll_no2 领料单号、wb_no 外包单号、cgrkdh 采购入库单号、lldh 来料单号;
   llxz 来料性质(新货/返工/客退)、djlx 单据类型 区分工单来源。
5. **结案**:ja='T'/'Y' 后工单退出需求统计(View_od_cost1/2 同口径取 ja IN('T','Y'))。
6. **生产线指派**:scx ∈ dm_gx(lb='SCX');排产变体屏「工单排产-挂镀」=按挂镀车间产线过滤。

### 3.2 报工/完工口径(scjl)
