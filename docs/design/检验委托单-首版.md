> 任务来源(用户 2026-11-15 口径):
> 1. 送样登记表 + 检验委托单都放「品质管理」,新增一列(目录)「样品检验」;

## 一、两个面板

| 项 | 送样登记表 | 检验委托单 |

## 四、前端纸面组件契约(`frontend/src/core/qc/InspCommissionSheet.vue`)

写法照 `frontend/src/core/qc/QcLinePatrolSheet.vue`(props/emit/编辑态/只读态/@media print 白名单)。

```
props:  head(Object,必填)  fields(Array)  editable(Boolean)
emits:  'dirty'
根元素: <div class="ic-sheet" :class="{'is-editing': editable}" data-ic-sheet="INSP_COMMISSION">
数据:   表头 = head['<label>'](键必须是第三节的中文 label);
        行表 = head.detail.items(数组,元素键 = 行表 label);
        行对象可能被上层 markRaw ⇒ 改值后 bump++ 强制刷新,并 emit('dirty')。
```

- 全部可见文案走 `tt('中文')`(含静态法律法规文字;禁止裸写中文),只读态全部渲染成 `<span>`。
- **委托方三行合并(2026-11-16 用户口径「制造商和对应地址合并,生产厂也和对应地址合并;按文件的形式处理」)**:
  纸样本来就是「委托单位/单位地址」「制造商/地址」「生产厂/地址」各一行(**名称与地址在同一行同一格**),
  本版按纸样合并;合并只发生在**显示层**——行标签是合并文案(如「制造商/地址」),值格里仍是两个独立输入框
  (`委托单位` + `委托单位地址` 等),数据键 / `yj_field` / 物理列 / 查询一个都没改。
  英文标签见 `en.js`:`Client / Address` / `Manufacturer / Address` / `Production Plant / Address`。
- 复选框用 `■/□` 字符渲染(纸面风格):可编辑时点击切换,只读时展示;值 = 选中项的中文文案。
- 默认值(仅新建空单):单据日期=今天;样品处理方式=委托单位自行取走;判定规则=无需判定;
  检验报告有效期=长期有效;报告类型留空。
- 打印:文件末尾 `@media print` 照 QcLinePatrolSheet 的 `body.approval-printing` 白名单写法,
  把 `.ic-sheet` 放行、隐藏 `.topbar/.func-zone/.tabsbar/.approval-side/...`;
  **编辑控件(选择检验项目/日期控件/删行 ×/占位提示)另有一份不依赖 body 类的裸 @media print 规则**,
  任何打印路径都不会印出控件;「导出 → 打印预览」对这张纸走原生打印、导出 PDF 走 html2canvas
  (理由见 §八.9);纸面宽度 880px、A4 竖版 1 页。
- 纸宽约 800~900px(单页 A4 竖版),不要横向滚动条。

### 4.2 「检验类别」= 从送样登记表带入(核心需求)

- 单元格内展示 `head['检验类别']`(文本,只读展示由纸面拼接的摘要)+ 可编辑态一个「选择检验项目」按钮;
- 点按钮弹 `SampleCatalogPickDialog.vue`:读 `POST /api/px/queryFormDataList {panelCode:'SAMPLE_REG', keyword, condition:{}, pageNo:1, pageSize:500}`,
  **注意**:SAMPLE_REG 是 archive 面板,返回 `{list:[虚拟单据]}` ⇒ 行 = `res.list[0].detail.items`;
  弹窗内搜索框前端过滤「检测元素/测试方法/检测标准」,表格多选(勾选列),底部「带入」;
- 确认后(不覆盖用户手填的其它头字段):
  1. 行表追加(按「检测元素」去重,已存在的不重复追加),`行号` 重排 1..n;
  2. `检验类别` = 选中项「检测元素」去重后以「、」拼接(整份行表重算);
  3. `检验依据` = 行表「检测标准」去重后以「；」拼接;
  4. `合计收费`(纸面显示「总金额（含增值税6%）RMB」)= 行表「收费」合计 × (1+6%),按分四舍五入保留两位(2026-11-16 口径)。
- 行表小表列:序号 | 检测元素 | 内部检出限 | 检测误差 | 测试方法 | 测试周期 | 收费 | 检测标准;可编辑态每行末「×」删除。
- 找不到目录数据/无权限:弹窗内给出中文提示,不抛异常。

## 五、审批流(基础)

  (提交 SUBMIT / 通过 APPROVE / 驳回 REJECT / 弃审 UNAUDIT),侧栏「审批情况」可查。
