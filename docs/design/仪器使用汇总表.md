## 二、页面能力（照样品检验汇总表）

1. **时间区间**：今天 / 本周 / 本月 / 上月 / **全部** / 自定义；默认「本周」。`全部` = 不传日期 = 不限区间。
2. **筛选**：仪器名称/型号、使用人、关键字（项目名称内容 / 备注 / 仪器 / 使用人）。
3. **统计条**：记录条数、涉及仪器、使用人数、涉及项目（按去重值算）。
4. **记录表**：用户图样的 9 列，日期倒序；前端每页 200 条分页（后端单次上限 5000 行，触顶给出提示）。
5. **勾选 → 只导所选**：勾选列 + `row-key="记录id"` + `reserve-selection`（跨页保留）；
   勾中的行在工具条回显条数并可一键清除；导出按钮文案变成「导出所选 Excel (N)」。
   **不勾 = 导出当前查询结果全部**（原行为）。
6. **重新查询即清勾选**：导出条件永远对应"当前看得见的结果集"，不会带出上一轮已消失的行。

## 三、数据口径

- 一行 = **一条使用记录**（不是一张单一行：同一张单可登记多台仪器/多个项目，跨全部单据）。
- 行源：`rd_instr_use_detail d JOIN rd_instr_use_head h ON h.单据编号 = d.单据编号`。
- 仪器名称/型号：优先取明细行 `[仪器名称/型号]`（「一台仪器一组」写在这里），为空退回表头同名列。
- 日期：优先取明细 `[使用日期]`，为空退回表头 `[单据日期]`。
- 数量：物理列 `[样品数量]`，显示名按用户表样叫「数量」。
- 作废过滤：头/行任一 `asp_cancel = 'Y'` 都不进汇总（与列表页删除口径一致）。
- 日期列是 **nvarchar**（源表按纸样填 `yyyy-MM-dd`）：过滤/排序用
  `CASE WHEN ISDATE(...) = 1 THEN CONVERT(date, ...) END` 兜底脏值；**不用 `TRY_CONVERT`**
  —— 本机 SQL Server 兼容级别不认（实测消息 195）。显示值统一 `yyyy-MM-dd`。

## 四、导出「实验室仪器使用记录表」

`InstrSummaryService#export` 用 POI 生成 `.xlsx`（SheetJS 社区版写不出这些版式需求）：

- 第 1 行：跨 9 列的居中大标题「实验室仪器使用记录表」（16pt 加粗）；第 2 行：灰底表头；之后一行 = 一条记录；
- 空结果也补一行空白行，保证表头有下边框、可直接打印；
- 表头冻结 + 自动筛选；A4 **横向**、按宽度缩放到 1 页（用户图样就是整行 9 列）；
- 请求体带 `记录id: [...]` = **只导勾选行**（缺省/空数组 = 全部）；
- 文件名：`实验室仪器使用记录表_<起>-<止>.xlsx`（全区间时为 `_全部.xlsx`）。

## 五、权限

- 页面：`PanelPermissionService.requirePanelView(INSTR_SUMMARY)`；
- 导出：`requireButton(INSTR_SUMMARY, "导出")`，按钮映射 `export` 词
  （`PanelPermissionService` 里同时登记「导出」与「导出 Excel」两个按钮名）。
- 迁移按**角色**整批补：凡能看 `RD_INSTR_USE` 的角色 + 管理员 → `view,query,export`。
  不补授会让老账号上线后菜单消失、接口 403，而管理员并不知道要重新勾。
- 幂等：已有行只补缺词（不覆盖人工调整）；两账套（`HSDZ_MES` / `HSDZ_MES_TEST`）均已执行并登记
  `tools/db-migrations.txt`、写入 `yj_schema_log`。
