- 页签配置：`frontend/src/core/views/recordSheetConfigs.js` → `RD_INSTR_USE.pages[1].ledger`
- 渲染：复用 `RecordSheetPanels.vue` 的 `ledger` 只读台账块（与测试申请单的「委托测试汇总表」同一套）

## 二、数据口径

- 一行 = **一条使用记录**（不是一张单一行；同一张单可以登记多台仪器/多个项目，跨全部单据）。
- 行源：`rd_instr_use_head × rd_instr_use_detail`（`单据编号` 关联）。
- 仪器名称/型号：优先取明细行上的 `[仪器名称/型号]`（「一台仪器一组」写入），为空退回表头同名列。
- 日期：优先取明细 `[使用日期]`，为空退回表头 `[单据日期]`；按日期倒序、同日按明细 id 倒序。
- 数量：物理列 `[样品数量]`，汇总页显示名按用户表样叫「数量」。
- 头/行任一 `asp_cancel = 'Y'` 的记录都不进汇总（与列表页删除口径一致）。
- 日期是 nvarchar（源表按 `yyyy-MM-dd` 填）：排序/过滤用
  `CASE WHEN ISDATE(...) = 1 THEN CONVERT(date, ...) END` 兜底脏值；
  **不用 `TRY_CONVERT`**——本机 SQL Server 兼容级别不认（实测消息 195）。

## 三、接口与权限

- `POST /api/px/instrUseSummary`（`PxController`）→ `QueryService.instrUseSummary(dateFrom, dateTo, instrument)`
- 只读派生视图：不落库、不建表、不产生单据；返回 `{ list, totalSize }`
- 权限：`PanelPermissionService.requirePanelView("RD_INSTR_USE")`（能看这张记录表就能看汇总）
- 当前页面不传过滤参数 = 全量；接口预留 `dateFrom / dateTo / instrument`（后续要加筛选不用改契约）
