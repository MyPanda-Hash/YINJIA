# 首件检验单 · 打印预览 / 导出 PDF / 导出当前这张纸的 Excel（2026-10-17 第八轮）

用户口径：

> 「然后让当前的 excel 可以导出当前这个报表页面，打印预览也需要实现导出 pdf 也是」

三件事都落在**当前这张纸**（《炭棒成型车间首件检验记录表》）上。先量了现状，三处**都是坏的**：

| 入口 | 改前实测 |
|---|---|
| 侧栏「打印」 | **打出来是一张空白页** |
| 导出 →「导出 PDF」 | 弹提示「未找到可导出的单据」，**一个字节都不产出** |
| 导出 →「导出 Excel」 | 导的是**明细长表**（90 行 × 行类型/样品序号/检验列…），不是这张纸 |
| 导出 →「打印预览」 | **根本没有这一项** |

## 一、打印空白页：纸面自己也是 `visibility: hidden`

公共打印样式（`DocSheet.vue` 的非 scoped 块，各纸张组件各抄一份）是这么写的：

```css
@media print {
  body.approval-printing .portal { visibility: hidden; }      /* 先把整页藏掉 */
  body.approval-printing .approval-sheet { visibility: visible !important; }   /* 再逐个把纸张捞回来 */
  ...
  @page { margin: 8mm; }
}
```

捞回的名单里有 `.approval-sheet` / `.progress-sheet` / `.catalog-sheet` / `.qc-rec-sheet` / `.rsp-sheet`，
**没有 `.fi-sheet`** ⇒ 首件检验单点「打印」出来的是一张白纸。实测判据：

```
改前 getComputedStyle(.fi-sheet).visibility === 'hidden'
改后 === 'visible'（且 .fi-title 一并可见）
```

**修法**：在 `QcFirstInspSheet.vue` 末尾补一个非 scoped 的 `@media print` 块（与检验目录/检验记录表逐条同构），
把 `.fi-sheet` 捞回来，并顺手做三件纸上该做的事：

- **列多时收回纸宽**：屏上是「表格按 `min-width` 撑开 + 外层横向滚动」，打印必须
  `body.approval-printing .fi-grid { min-width: 0 !important; width: 100% !important }`，否则右半张被裁；
- **缩到一页**（照仓库既有口径：`font-size: 10px` + `padding: 1px 2px` + `height: auto` + 允许换行）——
  实测打印产物从 2 页（第 2 页空白）收敛到 **1 页**；
- **列名改用文字版**：见下条。

### 列名被裁成「炭棒表」

列头在可编辑态是个 `el-input`（点它改列名）。**输入框是单行控件**，列一窄文字就被裁成
「炭棒表 / 炭棒脱 / 挤压强」这种残词 —— 打印出来很难看。修法：模板里**恒定渲染一个列名文字版**
`.fi-colhead-text`，可编辑时屏上让位给输入框（`.fi-sheet.is-editing .fi-colhead-text { display:none }`），
**打印时显形**、同时把 `.fi-colname/.fi-colgroup` 隐掉。打印产物实测：

```
改前:  炭棒表   炭棒脱   炭棒外   炭棒内   炭棒长   炭棒重   跌落   挤压强   浊度N   压降kP
改后:  炭棒表观状态 / 炭棒脱粉情况 / 炭棒外径(mm) / … / 浊度NTU / 压降kPa    ← 会换行、完整
```

顺带修掉两个纸上不该有的东西：**占位提示词**与**弹窗** ——

- `el-dialog` 是 `append-to-body`，**不跟着 `.portal` 一起隐藏**，开着弹窗按打印会把它印上去 ⇒ 打印时显式 `display:none`；
- 占位提示词分两种实现，要分别对付（实测两种态都抓过）：
  - `el-select` 的「请选择」**不是** input placeholder，而是 `.el-select__placeholder.is-transparent`
    （选中值那一个**没有** `is-transparent`）⇒ `visibility: hidden` 只藏占位、不藏真值；
  - `el-date-picker` 的「选择日期」是 input placeholder ⇒ `color: transparent`。
    ⚠ 视觉上不印了，但 **PDF 文本层里仍留着一串不可见的字样**（CSS 去不掉 placeholder 的属性，只能让它透明）。

## 二、导出 PDF：`$el` 是注释锚点 + 兜底名单漏了 `.fi-sheet`

`exportSheetPdf()` 先取 `approvalSheetRef.$el`，判不出元素时按**纸张根类名**兜底：

```
改前兜底名单: .record-sheet .approval-sheet .progress-sheet .catalog-sheet .qc-rec-sheet
改后兜底名单: …+ .fi-sheet + .qr-sheet
```

而 `$el` 判不出来的原因正是 §5.5 **B1**：`QcFirstInspSheet` 模板顶部有一大块注释、组件内又有
`append-to-body` 弹窗 ⇒ dev 下渲染成多根 fragment，`$el` 是**注释锚点**（`instanceof HTMLElement` 为假）。
生产构建会剥注释、单根正常 —— 也就是"prod 偶尔正常 ⇒ 假通过"，所以**必须在 dev 上验**。

**修法**：把「纸面 → PDF blob」抽成 `buildSheetPdfBlob()`（导出与预览**共用一份实现**），
兜底名单补上 `.fi-sheet`。实测产出 303 KB 的真 PDF（blob 头 `%PDF`）。

## 三、打印预览：新增一项，复用同一份 PDF

「导出」格式框里加第一项**打印预览**：`window.open('', '_blank')` **同步先开窗占位**（await 之后再开会被
弹窗拦截——与 `previewServerReport` 同一套做法），拿到与「导出 PDF」**同一份** PDF 后
`win.location.href = blobURL`。浏览器 PDF 阅读器自带打印/缩放/另存为 ⇒ 所见即所得。

⚠ headless 里新窗口不进 `/json/list`、blob PDF 直接落下载页，所以探针的判据是：
**调了 `window.open`** + **没报「被拦截」**（⇒ 拿到了句柄、`location.href` 那步跑了）+ **生成了 PDF** + **无失败提示**。

## 四、导出 Excel：导的是**这张纸**，不是明细长表

用户口径「让当前的 excel 可以导出当前这个报表页面」= 导出当前这张纸（与制程检验单同口径，
见 `core/qc/qcProcInspExport.js`）。新增纯函数模块 **`core/qc/firstInspExport.js`**（+ 8 例单测）：

```
大标题 → 副标题(公司/单号/状态) → 空行
→ 抬头四对(产品编号/产品型号/生产日期/组别,每行 2 组「标签|值」)
→ 两层表头:第一级=分组(跨本组各列),第二级=测试项目;左上角「测试项目 ╲ 样品序号」纵跨两行
→ 标准行 → 1#..8# 八个样品行 → 相关要求 6 条 → 表尾 检验结果 | 检验人 | 审核人
```

> ⚠ 表尾第三格「审核人」是 **2026-10-18** 追加的（用户口径「为当前的首件检验单增加审核功能，
> 审核功能实现参照当前的制程检验单」）：制程那张纸的表尾就是「检验人 | 审核人」，首件同口径。
> 三段等分（`pairW = floor(N/3)`，列太少时顺延不覆盖前段）；值取虚拟字段 `head['审核人']`
> （= `yj_doc_status.shr`，未审核为空）。面板纸面（`QcFirstInspSheet.vue` 表尾）与服务端报表
> （`qc_first_insp.jrxml` / `QcFirstInspReportSupport`）同批同口径，见
> `docs/design/首件检验单-服务端报表模板.md` 第六节。

- **样品格与纸面同源**：`isFillableCell(样品, 分组)` —— 本组那一对写实测值，其余格写 `/`（与图纸一致）；
- `!cols` 列宽 + `!merges` 合并区**能**落进 .xlsx；单元格样式（加粗/底色/自动换行）**落不进**
  （xlsx 社区版 0.18.5 不写样式，与制程检验单同一取证）—— 要纸面级 Excel 得换 `xlsx-js-style` 或走后端报表，另开任务；
- 入口：`PanelxList.exportSheetExcel` 的按面板码路由表加 `QC_FIRST_INSP: 'exportFirstInspExcel'`，
  「导出 Excel」那一项的说明也**按面板如实切换**（`sheetExcelDesc`：纸面版式 / 控制列表版式 / 头字段+全明细）。

实测导出的 xlsx（探针把 blob 解出来核对）：sheet 名 `炭棒成型车间首件检验记录表`、26 行、22 个合并区、
首行是大标题、含四个分组名与测试项目名、含标准行与 1#..8#、含相关要求与表尾，且**没有**「行类型/检验列」这种长表列头。

## 五、顺手修的一处纸面瑕疵

列头单位重复：`浊度NTU` + 单位 `NTU` ⇒ 纸上/Excel 里印成 **`浊度NTU(NTU)`**。
新增 `columnHeadText(col)`（纯函数 + 单测）：列名里已含该单位就不再后缀括号 ⇒ `浊度NTU` / `压降kPa`，
`炭棒外径` 仍拼成 `炭棒外径(mm)`。纸面、打印、Excel 三处**共用这一个函数**。
