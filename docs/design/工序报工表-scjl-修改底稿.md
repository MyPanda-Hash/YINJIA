## 4. 口径速查

- 报工=**工序级**(五道下拉,参考库无此维度系其缺陷;银嘉开产量/五工序完成数依赖它);
  一张报工单=一个工单的一个工序的一次数量(+直销数量双出口)。
- 批次链:混料批次号(工单头)→碳棒批号(头.批号,生成产品批号)→**报工快照批号**(本表)→组装沿用。
- 完工=审核(状态机),无独立完工标志/时间列;入库回执落「入库单号」。
- 电镀域(挂具/每挂/盘数/每盘/多单位)与班次**不落库**(历次拍板)。
