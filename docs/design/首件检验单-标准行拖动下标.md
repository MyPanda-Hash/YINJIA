# 首件检验单 · 标准行「拖动下标」贴到格子右下角（2026-10-17 第七轮）

用户口径（截图红框 = 标准行「炭棒长度」格里的拖动抓手）：

> 「这个拖动下标应该跟着当前的这个表格框的右下角走」

## 一、病根：原生抓手贴的是**文本域**右下角，不是**格子**右下角

标准行的每格是 `<el-input type="textarea" :autosize>`。textarea 自带 `resize: vertical`，
浏览器把抓手画在**文本域**的右下角。

而这一行里各格内容长短不一：`跌落 / 挤压强度 / 压降` 的标准文字有 2~3 行，把**整行**顶到 89px；
`炭棒长度` 这类格子只有 1 行 ⇒ 文本域只有 25px 高，抓手就悬在离格底 **64px** 的半空（现场实测）：

| 列 | 格高 | 文本域高 | 抓手离格底 |
|---|---|---|---|
| 炭棒外径 / 内径 / 长度 / 重量 / 表观 / 脱粉 / 浊度 | 89 | 25 | **64** |
| 压降kPa | 89 | 44 | 45 |
| 跌落 | 89 | 64 | 25 |
| 挤压强度 | 89 | 83 | 6 |

## 二、试过但走不通：让文本域撑满格子（纯 CSS）

想让原生抓手自动落到格角，就得让文本域 = 格子高度。**表格里百分比高度解析不了** ——
实测三种写法一律无效（`height:100%` 在 `td` 里全被算成 `auto`）：

```
A  .standard-row td{position:relative} + .el-textarea{height:100%} + inner{min-height:100%}   → 底差仍是 64
D  A + 给 <tr> 显式 height:120px                                                              → 底差仍是 95
E  D + td 也 height:100%                                                                       → 底差仍是 95
```

⇒ 结论：**格角这件事只能自己画**。

## 三、修法

1. **关掉原生抓手**：`.standard-row .fi-cell :deep(.el-textarea__inner) { resize: none }`
   —— 否则格子角上会多一个，而原来那个还悬在半空（两个抓手）。
2. **自绘抓手锚在 td 上**：`.standard-row td { position: relative }` +
   `.fi-rowgrip { position:absolute; right:0; bottom:0 }`，三道斜线用
   `repeating-linear-gradient(-45deg)…` + `mask-image` 只在右下角显形（与原生抓手同款外观）。
   每格一个 ⇒ **永远跟着本格的右下角走**，行高怎么变都贴得住。
3. **拖动 = 改本行行高**（`stdRowH`，px）：行给 `height`（表格里是**最小值**，标准文字更高时
   仍是内容说了算，打印照样完整），文本域给 `min-height`，写字区跟着一起变大。
4. 拖动实现照仓库既有那套（`DocSelectRail.vue` 的 resizer）：`@mousedown.prevent` +
   window 上挂 `mousemove/mouseup`，拖动期间 `body.userSelect='none'` / `cursor='ns-resize'`，
   `onBeforeUnmount` 兜底解绑。**不改单据数据、不标脏** —— 这是版面偏好，刷新即回到内容自适应。

⚠ 一个坑：Element Plus 的 `autosize` 会把 `min-height` **内联**写到 textarea 上（按 minRows 算），
所以"撑满格子"那条只能用 `!important` 才盖得住 ⇒ 给它加一个 `has-std-h` 门（**只在用户拖过行高时**启用），
默认态一个字都不干预，与改前的 autosize 行为完全一致。

## 四、验了什么

`node tools/archive/_probe-first-insp-grip.mjs <base> [--measure] [--shot 前缀]` —— **9/9 PASS**：

| # | 断言 | 实测 |
|---|---|---|
| ① | 标准行每格都有拖动抓手（操作列除外） | 10/10 列 |
| ② | 抓手贴在各格自己的右下角（底/右偏差 ≤ 4px） | 底 1 / 右 1 |
| ③ | 原生 textarea 抓手已关（不会有两个） | 全部 `resize: none` |
| ④ | 往下拖 60px ⇒ 行高 89 → 149，抓手仍贴角 | ✓ |
| ④ | 短内容格的文本域跟着撑满（写字区一起变大） | `[20,20,20,20,20,20,59,78,20,39]` → 全 137 |
| ④ | 松手后 body 的选中/光标已还原（无拖拽残留） | ✓ |
| ⑤ | 行高稳定（没有测量↔撑高的反复抖动） | ✓ |
