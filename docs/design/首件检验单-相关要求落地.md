## 纸面红字（2026-11-20）

用户口径（截图红框 + 「字体还是黑色的」）：受控表单上那三条**红字**在系统纸面上也要照印成红色。

| 位置 | 做法 |
|---|---|
| 面板纸面 | `QcFirstInspSheet.vue` 的 `RED_REQ_INDEXES = new Set([7, 8, 9])`（0 基下标 ⇒ 第 8/9/10 条）→ `li.is-red { color:#ff0000 }` |
| 服务端打印报表 | `reports/qc_first_insp.jrxml` 新增样式 `reqRed`（`forecolor="#FF0000"`），第 8/9/10 条 `staticText` 用它 |
| 浏览器打印 | 走屏幕同一份 DOM/CSS，文字颜色不受 `print-color-adjust` 限制 ⇒ 打印件照样是红字 |
| Excel 导出 | **带不出颜色**：xlsx 社区版会丢单元格样式（见 `firstInspExport.js` 头注）⇒ 导出纸仍黑字；要红字请用「打印」或「导出报表(PDF)」 |

红字范围改口径只动两处：面板的 `RED_REQ_INDEXES` + 报表的 `reqRed`（两边必须同步）。
