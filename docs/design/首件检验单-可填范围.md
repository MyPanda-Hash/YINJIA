# 首件检验单 · 可填范围（2026-11-14 第十轮 · 现行口径）

用户口径（2026-11-14，随《炭棒成型车间首件检验记录表》原图一起给）：

> 「将当前的首件检验单格式修改为图中所示，也就是**没有黄色的格子就打上斜杠，不可填写**，
>  其余的不用修改，就还需要把**对应的表格修改为黄色**。」

即：**可填范围回到纸面（黄格 = 要填、白格 = 打 `/` 不填）**，恢复四对样品行分组录入；
除「可填/不可填 + 黄色」外，其它（列集、勾选项、相关要求、抬头、表尾、打印/导出入口）一律不动。

## 一、矩阵（唯一真源，图片逐格量色得到）

图片量色方法：`#FFF3CA` = 黄色可填格（连通域 30 块，总面积 74,366 px ≈ 18 格）；
`#D9D9D9` = 灰底（表头分组 + 标准行的表观/脱粉格）。

| 测试项目列（按列名认） | 可填样品行 | 纸面颜色 |
|---|---|---|
| 炭棒表观状态（勾选式） | **1#、2#** | 淡黄 `#FFF3CA` |
| 炭棒脱粉情况 / 炭粉情况（勾选式） | **1#、2#** | 淡黄 `#FFF3CA` |
| 炭棒外径 / 炭棒内径 / 炭棒长度 / 炭棒重量 | **3#、4#** | 淡黄 `#FFF3CA` |
| 跌落（跌落强度） | **5#、6#** | 淡黄 `#FFF3CA` |
| 挤压强度（抗压强度） | **7#、8#** | 淡黄 `#FFF3CA` |
| 压降kPa / 压缩kPa | **7#、8#** | 淡黄 `#FFF3CA` |
| 浊度NTU（**系统比纸面多出的一列**，纸面无此列） | **7#、8#**（随「浊度及压降」组） | 淡黄 `#FFF3CA` |
| 其它/新增列（认不出列名） | 按分组兜底：表观及脱粉 1#/2#、尺寸及重量 3#/4#、强度 5#/6#、浊度及压降 7#/8#、未知组 7#/8# | 淡黄 |

- 除上表以外的样品格一律 **`/` 占位、不可填写**（白底）。
- **标准行**：表观/脱粉两列纸面是**灰底 `#D9D9D9` + `/`（不填）**；其余列照旧（来自《成型工艺清单》，可改）。
- 老单据里已填过、本轮变成不可填的格：**原样只读显示，不吞数据**（与历史口径一致）。

合计（10 列、8 行）：可填格 **20 个**；`/` 占位格 **60 个**。

> 纸面列只有 9 个（无浊度NTU），系统多一列浊度NTU；用户口径「**其余的不用修改**」⇒ 不清列，
> 浊度NTU 随「浊度及压降」组记 7#/8#。

## 二、真源（三处必须同口径，改一处必须同步另两处）

1. 前端列模型 `frontend/src/core/qc/firstInspCols.js`
   ```js
   export function isFillableSample(sample, col)   // 本格能不能填（组件/导出共用）
   ```

## 三、沿革（别再照旧版改）

| 版本 | 规则 | 被推翻的原因 |
|---|---|---|
| 第六轮之前 | `SAMPLE_LIMIT = 2`：每个测试项目都只记 1#/2# | 尺寸/强度/浊度永远填不进去 |
| 第六/七轮 | 四个分组各绑一对样品行（表观→1#/2#、尺寸→3#/4#、强度→5#/6#、浊度→7#/8#），其余 `/` | 被第九轮「全开」口径取代 |
| 第九轮 | 只前两列限 1#/2#，其余列 8 行全开 | **2026-11-14 用户重新按纸面口径拍板 ⇒ 本轮（第十轮）恢复分组对** |
| **第十轮（现行）** | 照纸面黄格：表观/脱粉 1#/2#、尺寸四项 3#/4#、跌落 5#/6#、挤压+压降(+浊度) 7#/8#；黄格可填、其余 `/` | — |

⚠ 与第六/七轮的区别（别照抄旧实现）：**强度组的「跌落」在 5#/6#、而「挤压强度」在 7#/8#**
（纸面黄格就是这样，不是按组一刀切）。
