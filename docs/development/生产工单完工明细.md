# 生产工单完工明细

生产工单列表增加「完工明细」按钮。勾选一行或点击当前行后打开只读弹窗;多选拒绝,避免工单行混用。

数据直接取 `scjl` 已审核完成(`wgzt='Y'`)且未作废记录。接口 `POST /api/px/workOrderList/completionDetails`,参数 `{工单号,行id}`;权限沿用生产工单页面查看权。

关联先校验有效 `plang.id+pl_no`:
1. 正 `gd_id` 只按 `plang_pc.id → plang_pc.plang_id` 关联,锚缺失/错行不降级。
2. 未锚定记录按工单号+工单行号匹配;附带批次时同时核验,必须唯一。
3. 无行号才按非空批次匹配,工单内该批次必须唯一。歧义不猜行、不回填。

展示逐笔报工单号、工序、完成数量、单位、生产线、批次、产品、人员、时间、产成品流水号、入库单号及关联依据。上方按工序分别汇总完成数量与记录数,不跨工序累计为成品数。英文/日文新增显示词条已交付。
