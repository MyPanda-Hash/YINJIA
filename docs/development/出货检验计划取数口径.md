# 出货检验计划 → 检验单取数口径(表观 / 功能)

| 属性 | 内容 |
|---|---|
| 文档类型 | 业务口径说明(唯一权威) |
| 适用场景 | 改动「取出货检验计划」取哪些行、表观单/功能单默认带什么 |
| 维护状态 | 生效(2026-11-22 改为按**检查频率**区分) |

## 一、现行规则(2026-11-22 用户口径)

> 用户原话:「表观抓取 1%/一个生产批次,功能是抓取 1PCS 字眼来区分。」

| 单据 | 面板码 | 默认带哪些行 |
|---|---|---|
| 出货检验（表观） | `QC_ASM_INSP` | 检查频率**含「1%」**的行(含历史写法「生产量*1%」) |
| 出货检验（功能） | `QC_PROC_INSP` | 检查频率**含「1PCS」**的行(大小写不敏感) |
| 两者都不命中 | — | 「型式检验 / 型式检验半年一次」、检查频率为空 ⇒ **两边都不默认带** |

- 取数入口只有一个:`GET /api/qc/inspPlan/fromShipPlan?productCode=`,取该产品**最新一张未作废**计划
  (按 `id` 倒序,不校验审批状态),返回整张计划的明细(控制项目→检验项目、控制标准及要求→检验要求、
  控制方法→检验方法、检测频率→**检查频率**、检验内容→表区/检验类型)。
- 判据取自计划表**「检验频率」(检测频率)那一列**:填了 `1%/一个生产批次` 的归表观、填了 `1PCS…` 的归功能;
  **填为空的既不带入表观、也不带入功能**(2026-11-22 用户口径「每天填写为空的就不带入」)。
- 接口只下发**填了内容**的检验项:没有「控制项目」的空行、以及「修订记录」分块行(`表区='修订记录'`)一概不下发。
- 「默认带哪些」只影响**默认勾选**与**生单预铺**;弹窗里其余行照常列着,手勾就能带(不是硬门槛)。
- 行序 = 计划序号序,不再按类别重排。

## 二、三条链路、一处规则

| 链路 | 落点 | 用的规则 |
|---|---|---|
| 弹窗「检验项目/检验方案 → 出货检验计划」页签的**默认勾选** | `QcInspPlanDialog.applyDefaultShipSelection` | `defaultShipRows(panelCode, rows)` |
| 工具栏「**取出货检验计划**」按钮 | `PanelxList` 的 `action === '取出货检验计划'` | 同上(没命中就转开弹窗,让用户手勾) |
| 表观单**生单预铺**(选生产工单 / 自动出单) | `AsmInspItems.load` (Java) | 只铺「检查频率含 1%」的行 |

规则本体(前端,含单测):`frontend/src/core/qc/shipPlanDefaults.js` —— `shipFreqOf / isAppearanceRow /
isFunctionalRow / defaultShipRows`;后端 `AsmInspItems` 是同一口径的 Java 实现(只有表观这一半)。

## 三、类别列(检验类型 / 表区)只是显示分组

计划表的「检验内容」是隐藏列、**实测全空**,所以带入/预铺时按**项目名关键词**兜一个分组值
(含 外观/尺寸/重量 → 三类之一,其余留空,报表按「检验项目」成组)。
⚠ 它**不参与取数**:改项目名不会再改变某行进表观还是功能。

## 四、口径变更史

| 日期 | 口径 | 备注 |
|---|---|---|
| 2026-10-30 | 表观 = 外观/尺寸/出货重量 三类(按项目名关键词),功能 = 三类以外全部 | 首次把「整张计划全量带入」收成"默认勾选" |
| **2026-11-22** | 表观 = 检查频率含 1%,功能 = 含 1PCS | 本文件;关键词三类退化为**显示分组**用途 |

**影响面(两账套实测,`表区='检验项目'` 的行)**:测试库 表观 27 行(生产量*1% 15 + 1%/一个生产批次 12)、
功能 29 行;「型式检验」8 行与「检查频率为空」15 行**现在两边都不默认带**(改成按频率口径前,前者落在功能侧)。

## 五、改规则要同改哪几处(防止分叉)

1. `frontend/src/core/qc/shipPlanDefaults.js`(规则本体 + 单测 `shipPlanDefaults.test.js`);
2. `frontend/src/core/qc/QcInspPlanDialog.vue`(默认勾选、带入时类别兜底);
3. `frontend/src/core/views/PanelxList.vue`(`applyShipPlanItems` 的类别列 / 判重键、按钮入口);
4. `backend/src/main/java/com/yinjia/mes/service/AsmInspItems.java`(生单预铺,表观那半);
5. `backend/src/main/java/com/yinjia/mes/service/QcAsmInspReportSupport.java`(`groupName`:报表分组词表)。

改完至少跑:`cd frontend && node --test src/core/qc/*.test.js`,并 `npm run build` / `mvn -o -DskipTests package` 各一次。
