# 数据库表清单(YINJIA-MES)

| 属性 | 内容 |
|---|---|
| 文档类型 | 开发规范·数据库表清单 |
| 适用场景 | 新增/修改表、查表结构、判断「这张表能不能动」 |
| 维护状态 | 生效 |
| 数据口径 | **正式库 `HSDZ_MES`**（本清单由它生成）。测试库 `HSDZ_MES_TEST` 是它的**快照副本**，会陈旧、甚至结构不同源 —— ⚠ **不要假定两库结构一致**；判定与重建见 [环境与数据库](环境与数据库.md)「测试库」节 |
| 数据来源 | `sys.tables` / `sys.views` + 扩展属性 `MS_Description` + `yj_panel` 面板对照 |
| 生成日期 | 2026-09-21 |
| 覆盖范围 | 441 张表 + 101 个视图（含遗留与备份表，全部列出不留盲区） |
| 生成方式 | 在仓库根目录依次执行:① `java -cp tools/lib/mssql-jdbc.jar tools/gen/GenDbCatalogDump.java`(JDBC 导实库,SQL 走文件避免中文乱码);② `node tools/gen/gen-db-catalog.cjs`(按下方分组渲染本文档) |

> **本清单是表的「户口本」，不是结构文档**：列级定义以实库为准（`tools/setup-db.sql` + `tools/db-migrations.txt` 链）。
> 新增表必须同时：① 在 `db-migrations.txt` 追加幂等迁移脚本；② 加 `MS_Description` 中文说明；③ 重跑上面的生成命令刷新本文档。

## 0. 表命名与归属规范（强制）

| 前缀 / 形态 | 含义 | 归属模块 | 建表要求 |
|---|---|---|---|
| `yj_` | 面板引擎元数据与运行时（面板/字段/翻译/状态/权限/日志） | 系统 | 只由引擎读写，业务代码禁止直连 |
| `bs_` | 基础档案（主数据） | 基础设置 | 必须走**单单据结构**（`archive` 模式）；保存必须全量提交 |
| `bd_` / `bl_` | 业务单据 **头表** / **行表**（成对） | 订单/生产/仓库管理 | 必须齐备 `asp_user1/2`+`asp_time1/2` 审计列；删除=软删 |
| `rd_` | 研发管理模块单据 | 研发管理 | `*_head`+`*_detail` 成对；无后缀的旧单表只读保留 |
| `qc_` | 品质管理单据 | 品质管理 | 头行成对 |
| `wo_` | 生产执行（工单/报工/进度） | 生产管理 | 头行成对 |
| `dm_` / `s_` / 拼音缩写 | **经典 HSDZ 遗留**，非 MES 自有结构 | 遗留 | 新功能**禁止**使用；面板仍在用的（见下表「关联面板」）改动前须评估 |
| `RENAME_` / `*_bak_*` / `tmp_*` / `t1` / `t2` | 备份与临时 | 待清理 | 禁止引用；清理走技术债清单 |

**通用硬约束**（表清单之外的「列级」规范见 [代码规范与防臃肿](代码规范与防臃肿.md) §C3 与 [开发与质量](开发与质量.md) §3「列名安全规范」）：

- 列名**禁止含 `.`**；含 `%`/空格等特殊字符的列，SQL 中必须写 `t.[列名]`。
- 一切写入经 `asp_user1/2` + `asp_time1/2` 留痕；删除=软删（`canceled` 状态）。
- 库变更**禁止手工改库**：一律写幂等迁移脚本进 `tools/db-migrations.txt`（§代码规范 E2）。
- 表的中文说明写进 `MS_Description` 扩展属性——本文档的中文名就是从这里读的。
