# 金蝶真实账套「出入库」到底用到哪几种单据(2026-11-13 实测)

> 用户问题:「查一下金蝶 erp 真实账套出入库,用到了哪几种单据」。
> **唯一口径:直接读金蝶真实账套(星辰 OpenAPI),不看文档、不看沙箱。**
> 取证脚本:`tools/archive/_kingdee-io-bills-20261113/`(两个探针,只读,可复跑)。

## 一、结论(一句话)

真实账套里**会动库存的单据一共 11 种有数据**(入 5 / 出 4 / 仓间移动 1 / 盘点 1),
另有 **4 种接口在、但账套内 0 张**(调拨出库、调拨入库、组装单、拆卸单 —— 说明这家公司不用它们)。
MES 侧只覆盖其中 **6 种**(采购入库 / 销售出库 / 材料出库→生产领料 / 产成品入库→产品入库 / 其他入库 / 其他出库),
**金蝶里天天在用的「生产退料单 953 张」「销售退货单 96 张」在 MES 没有对应单据**。

### 4.1 三个实打实的口径缺口(对账时会被问到)

1. **生产退料单 953 张(金蝶)↔ MES 没有这张单**。
   MES 的「退料」走的是**其他入库单 `bd_other_in`**(`WoPickDocService` 注释:领料单 `bd_material_out` 与退料单 `bd_other_in` 是两张不同面板的单据)
   ⇒ 推进金蝶后落成**其他入库单 `QTRK-`**,而现场在金蝶里是**生产退料单 `SCTL-`**。
   同一件"车间退料",两侧单据类型不同,按单据类型对账必然对不上。
2. **销售退货单 96 张(金蝶)↔ MES 没有销售退货面板**。MES 只有销售出库,退货只发生在金蝶侧。
3. **移仓单 206 张(金蝶)↔ MES 调拨单不推金蝶**。且 MES 调拨/盘点按现口径**对库存完全无效**(见 `docs/development/金蝶库存同步-以金蝶为准.md` §"调拨/盘点"),这类移动只在金蝶侧存在。

> 这三条都不影响"库存数量以金蝶现存量覆盖"的主口径(每 5 分钟 `sync-stock.mjs` 一覆盖就抹平),
> 但**影响单据级对账与追溯**:MES 里查不到的那部分出入库,只能回金蝶按单号反查。

## 五、旁证:接口字段名与分页坑(复跑时别再踩)

- 列表返回行字段是 **`bill_no` / `bill_date` / `bill_status`**(不是 `billno`/`billdate`),`count` 是全量张数;
- `page_size=1` 时金蝶返回 **空 `rows`**(`count` 仍正确)⇒ 取首尾单据要 `page_size>=5`;
- 不存在的接口返回 **HTTP 519**(不是 404),`kingdeeTryGet` 会吞成 `ok:false`。
