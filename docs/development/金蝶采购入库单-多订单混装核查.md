# 金蝶采购入库单:一张单里能不能混装多张采购订单(2026-11-13 核查)

> 用户问题:「金蝶的采购入库单,能不能做到不同采购订单在同一张入库单里(通过采购订单和采购订单行号来对应和回填采购数据)?查一下真实账套里面有没有出现这样的单据」。
> 本文只记录**只读取证**结论;没有改库、没有改代码、没有改面板字段。

## 一、结论(先看这三条)

1. **金蝶能,而且真实账套里是常态** —— 真实账套(星辰 `clientId 359797`)全量 3647 张采购入库单、
   9102 行,**1146 张(31.4%)含 2 个及以上不同采购订单**,最多一张挂 **12 张订单**
   (`CGRK-20250930-00843`,17 行)。这些单**全部已审核(`bill_status=C`)**,行上的订单行号
   **没有一行缺失**(`src_seq` 空值 0)。
2. **"对应关系"全在行级,表头没有采购订单字段** —— 金蝶 `pur_inbound` 表头无 `src_bill_no`;
   每行各自带 `src_bill_no`(订单号)+ `src_seq`(订单行号)+ `src_bill_type_id/number`(常量
   `pur_bill_order`)+ `src_inter_id`(订单单据 id)+ `src_entry_id`(订单分录 id)。
   于是"回填采购数据"就是**按行 join 订单行**:MES 本地 `bl_pu_order` 已有 `行号`/`基本数量`/
   `行已执行数量`/`行未执行数量`/`行入库状态`(同步自金蝶,目前全隐藏),`(源单编号,源单行号)`
   对得上 `(单据编号,行号)` 即可。
3. **MES 当时(本条写下时)做不到,连"看得见"都做不到** —— 该时刻 MES 采购入库单的订单是
   **表头单值**(`bd_purchase_in.采购订单号`),转 ERP **整单所有行都推同一个订单号**;行级
   `源单编号` 是隐藏字段、**全库 0 行有值**;金蝶导进来的 313 张入库单里 **122 张在金蝶侧本来
   就是多订单混装**,而 MES 侧**表头订单号 0/313 有值、行源单编号 0 行有值** —— 多订单信息在
   导入时就丢了。

## 四、改造清单(已按 1/2/3/5 落地,4 仍未做)

1. ✅ 行级落点:`bl_purchase_in.源单编号`(订单号)+ `源单行号`(订单行号)成对使用。
2. ✅ 转 ERP 按行解析:`PoRefs` 增加行级 `PoLineRef` 缓存,逐行解析订单 id / 分录 id。
3. ✅ 生单允许跨来源单合并:采购订单「合单生单」(`generateMerged`)。
4. ❌ **金蝶入库单同步/导入仍未映射 `src_*`** —— 历史 313 张(CGRK-*)的订单关联补不回来;将来若接
   `PURCHASE_IN` 同步,必须映射 `src_bill_no`/`src_seq`/`src_bill_type_*`/`src_inter_id`/`src_entry_id`。
5. ✅ (回填"采购数据"零成本)`(源单编号,源单行号) → bl_pu_order(单据编号,行号)` join 即可取
   `行已执行数量`/`行未执行数量`/`行入库状态`/`基本数量`(这些列已在库里)。
