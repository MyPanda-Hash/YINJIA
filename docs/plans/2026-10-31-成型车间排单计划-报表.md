# 成型车间排单计划（纸表报表，2026-10-31）

> 用户口径：甩来一张手填的《成型车间排单计划》纸表照片 + 「**这个需要能打出这样的报表形式，
> 就在当前工单排产处实现即可，这样就不需要根据那个产线进行处理了**」。
>
> 结论：在**工单排产**页加「排单计划」按钮，照纸表版式打一张**全产线一张**的报表（不分产线、不用先选线）。

## 1. 纸表列 → 系统字段

| 纸表列 | 取数（系统字段） |
|---|---|
| 客户等级 | `dm_kh.khjb`（**现役全空** → 印空白，等客户档案补） |
| 客户名称 | `plang.khdm` → `dm_kh.mc` |
| 产品编号 | `plang.dm`（物料编码，形如 A-48-17） |
| 型号 | `plang.gg`（规格型号，形如 53*16*60） |
| 成型车间 | `plang_pc.scx`（生产线；纸表写"1号车间"这类） |
| 未完成总数 | **未交量**（排产数量 − 入库数量） |
| 生产计划数量 | 排产数量 |
| 实际完成数量 | 当前工序完工量 |
| 成型交期 | `plang.cp_date`，印成 `10月10日` |
| 成型交期紧迫度 | 交期 − 今天（负数 = 已逾期，与页面同口径） |
| 7天 / 15天 / 大于15 | **已排三桶**（累计 ≤7 / ≤15 / >15，与纸表「7天=15天」同口径） |
| 日期列（10月5日 … 手写那几列） | **日计划**（人工指定 ∪ 自动摊剩余），默认**从今天起 7 天** |

## 2. 取数：全产线一张

新接口 `POST /px/scheduleBoard/planSheet`，body `{ scope }`，返回 `{ 日期, 今天, 行 }`：

1. `ScheduleBoardService.scheduled("", scope, workshop)` —— **空产线 = 全部产线**
   （原 SQL 是 `ISNULL(pc.scx,N'') = ?`，改成 `(? = N'' OR …)`；同时补 `生产线`、`客户等级` 两个字段）；
2. 再用 `WorkOrderDayPlanService.data(行id列表)` 拿每行的日计划/7天已排/15天已排/交期，
   按 `行id` 合并 —— 与页面格子**同一把尺**（人工指定 ∪ 自动摊剩余）；
3. 只读、不落表；动作词 **打印**（两页任一授予即可）。

## 3. 出纸

`frontend/src/business/print-formats.js` 新增：

- `schedPlanSheetHtml(rows, dates, {today, days})` —— **纯函数**，返回整张表的 HTML（便于单测）；
- `printSchedPlanSheet(rows, dates)` —— 走 `printInPage`（**页面内打印层**，不弹窗、不卡页面，见 2026-10-20 统一通道）；
- `planSheetDates(dates, today, days)` —— 取要印的日期列：从今天起 `days` 天；今天以后没有就退化取最后几天。

版式：A4 **横向**、6mm 页边距、9.5px 字、`table-layout:fixed` + `<colgroup>` 百分比列宽
（固定列合计 74%，剩余均分给日期列）。**页头只有标题**（沿用 2026-10-21 口径：不印打印日期 / 制单人 / 线体）。

## 4. 入口

**工单排产**页头部按钮「**排单计划**」（`打印` 权）→ 拉 `/planSheet`（当前页签 scope）→ 出纸。
左侧产线树选不选、选哪条都不影响（就是不按产线处理）。

## 6. 遗留 / 待拍板

1. **客户等级列现役是空的**：`dm_kh.khjb` 全 NULL（纸表的甲级/乙级还在纸上）—— 要这列有值需先补客户档案，
   或在客户面板加「等级」字段后导入。
2. **日期列默认 7 天**（纸表只印 3~5 天）：要更长/更短改 `printPlanSheet` 里的 `days` 即可。
3. 纸表右侧手写「应按改数量，换一次性派工」—— 若指的是"**在这张表上直接改数 / 一次性派工**"，那属于
   表格/弹窗交互（已实现：双击日期格改当天数量、改排产日期、调线），**打印件本身不承载录入**。

## 7. 主要信息与二维码**融进同一行**（2026-11-01 口径修正）

> 用户口径：「**不是这样实现，是当前同一行融合起来**」—— 不要"第 1 张排单计划 + 第 2 张生产任务单"两张纸，
> 而是把任务单的主要信息和二维码放进排单计划的**同一行**（一张表、一张纸）。

改法：
- **删掉**第 2 张「成型生产任务单」（`schedTaskSheetHtml` / 分页 `page-break-after` 一并移除）；
- 排单计划表**加两列**：`单据编号`（工单号，放在客户名称后面）与 `二维码`（行尾，34px；
  内容与「打印工单」一致：`公司代码@工单号@1000+行号`）；
- 列宽重排（固定列 73% + 日期列 5 天 ≈ 20% + 二维码 5%）；表头 9px 允许换行，避免互相压行；
- 日期列默认 **5 天**（纸表也就 3~5 天；要更多天调 `printPlanSheet` 的 `days`）。
- 单测同步改：`schedPlanSheetHtml` 变 async；断言「同一行有单据编号 + 二维码」「不再另起任务单」。


## 8. 按选中产线出纸（2026-11-01 口径；触发方式已于 2026-11-03 改为「勾选打印」，见 §9）

> 用户口径：「**当前一个产线打印的排单计划只存在当前的产线东西内容**」。

- 接口 `POST /px/scheduleBoard/planSheet` 增加 `生产线` 入参：传了就只取这条线的行
  （`scheduled(line, scope, workshop)`）；**不传 = 全部产线**（保留整车间一起打的能力）。
- 「排单计划」按钮：取左侧当前选中的产线一并提交（按钮 tooltip 写明「打印当前选中产线的排单计划；
  未选线=全部产线」）。
- 复核：`{未完工}` ⇒ 7 行（1号机/7号机/2号车间）；`{未完工, 生产线:'1号机'}` ⇒ 3 行且全是 1号机；
  页面点按钮（选中 1号机）⇒ 打印层 3 行。
- 预览：`node render-sheet.mjs http://127.0.0.1:8090 sheet-line.png 1号机`（第 4 个参数=产线）。

## 9. 勾选打印（2026-11-03 口径，取代「整条产线全打」）

> 用户口径：「**修改打印的形式，不是点击排单计划把目前生产线的所有单据打印，而是选择勾选几个打印几个的形式**」。

- 「排单计划」按钮改为**跟随勾选**：只打印排产明细里**勾选的行**（勾几张打几张）；
  **未勾选时按钮置灰**（与同页「打印工单」同一套勾选口径）；表头全选 = 打整条产线（旧能力保留）。
- 实现：`WorkOrderBoard.vue#printPlanSheet` —— 仍按 `{scope, 生产线}` 拉 `/px/scheduleBoard/planSheet`
  （接口零改动），出纸前用勾选行的 `行id` **过滤**；按钮文案带张数「排单计划（N）」，
  tooltip＝「勾选工单后打印排单计划,只打印勾选的工单」。
- 为什么过滤放前端：这是纯出纸选择交互，不值得为它改后端 jar；8090 现役实例不重启也能在
  5173（源码态）上验到效果。
- 验收（`tools/archive/_plan-sheet-select-20261103/`，对着 5173 实测 **6/6 PASS**）：
  2号车间 4 行 → 未勾选按钮 disabled → 勾 `GD-2026-10-0227`/`GD-2026-10-0228` 两行 →
  `window.print` 调 1 次、打印层 **2 行**、单据编号与勾选一致、标题仍为「成型车间排单计划」。

## 10. 日期列改为「勾选行 最前日期 → 最后日期」（2026-11-04 口径，取代 §1/§7 的「今天起 5 天」）

> 用户口径：「**当前想法是打印的就按这些勾选的表中最前面的日期到最后的一个日期就行**」。

- 前端 `WorkOrderBoard.vue#printPlanSheet`：`pickPlanSheetRows` 之后调
  `planSheetDatesFromRows(rows)` —— 取勾选行 `日计划` 里**最早 → 最晚**的日期（连续、含中间空列），
  随 `printSchedPlanSheet(..., { dates })` 出纸；**不再从今天起算**，历史/跨月计划可直接补打。
- 边界：勾选行没有非零日计划 ⇒ 回退「今天起 5 天」；跨度 >31 天 ⇒ 截最近 31 天；
  列数 >7 走 compact 版式（表头 `M/D` 7px、正文 8px、固定列按比例收紧）；纸表固定列/二维码/页头口径不变。
- 接口：后端 `/planSheet` **未改**（本来就返回含历史日期的 `日期[]` 与逐行 `日计划`）。
- 取证：`tools/archive/_plan-sheet-range-20261104/`（单测 17/17、CDP 页面链路 9/9 PASS、三张出纸截图）。
- 二维码/比例（2026-11-04 口径演进）：显示按物理尺寸 —— 行少（≤5）52px≈13.8mm、≤8 行 48px、≤14 行 42px、更多 36px，
  列宽 6%（让出 1.5% 给日期列），行高 = 二维码 + 6px；同时 `woQrImg` 底图提到 300px、静区 margin=2
  —— 修「有的行能扫、有的扫不到」（原底图仅 108px，打印放大发虚）。
- 日期列很长（>12 天，用户报障「挤成竖条」）：日期表头**始终横排**（用户明确不要竖排）——
  `nowrap` 禁止折行 + 窄列自动降字号（7px → 6px）；固定列设**最小宽度**（数字列 2.2% 起，不再叠字）、
  二维码随列数缩（>16 天 44px / >22 天 40px）、极窄（>28 天）格内数字 7px。
- 空列自动隐藏（2026-11-04 用户口径「客户等级这个列下不存在数据就默认隐藏了」）：
  勾选行该列全空 ⇒ 不印该列；有值才印（`hideIfEmpty`，目前只挂「客户等级」）。
- 部署：本次改动已入库；服务器需重打 jar + 增量部署后生效（截至提交时未部署）。

## 11. 标题 / 车间列头按工序产线动态（2026-11-04 口径，取代 §1/§3/§9 中「成型」写死）

> 用户口径（截图红框圈住纸表标题）：「**当前在不同的工序产线显示的这个工序名称也要不同**」。

- 问题：纸表标题「成型车间排单计划」、车间列头「成型车间」、交期两列「成型交期 / 成型交期紧迫度」
  在 `print-formats.js` 里是**写死字符串**；打印切炭/组装线的计划时，标题仍写「成型」，
  而车间列里印的是「切炭(自动)」——纸面矛盾。
- 修复（**纯前端**，后端 `/planSheet` 零改动）：
  - `print-formats.js` 新增 `planSheetShop(rows, opts)`（车间名解析：`opts.shop` → 行内唯一
    `生产车间`/`当前工序`/`工序` → 混打多工序返回空）与 `planSheetTitle(shop)`
    （`<车间>车间排单计划`，未知回退通用「排单计划」；档案值自带「车间」后缀不叠字）；
  - 纸表「车间 / 交期 / 交期紧迫度」三列改为 `tOf(shop)` 动态列头（切炭车间 / 切炭交期 …）；
  - `printSchedPlanSheet` 把同一份标题用于 `document.title`（打印页眉 / 另存 PDF 默认文件名）；
  - `WorkOrderBoard.vue#printPlanSheet` 按左侧**选中产线**在 `linesSummary` 的 `生产车间` 传 `shop`
    （未选线时由行内推导；夹带多工序的旧调用退回通用标题，不冒充车间）。
- 边界：未选线且勾选行跨多工序 ⇒ 通用「排单计划 / 生产车间 / 交期」；`opts.shop` 显式传入优先。
- 验证：`frontend/src/business/print-formats.test.js` **18/18 PASS**（新增动态标题/列头用例，
  含「切炭纸不再出现成型列头」「混打退回通用」「document.title 随工序」）；
  渲染样例与取证说明见 `tools/archive/_plan-sheet-title-20261104/`（`title-samples.txt`）。
- 生效：5173 源码态刷新即生效；8090 需宿主侧 `npm run build` +
  `pwsh -File tools/scripts/apply-frontend-only.ps1 -NoBuild`（或 rebuild-prod）换 jar 内 static；
  服务器随下次增量部署生效。⚠ 本 agent 沙箱无法构建前端（esbuild spawn EPERM），
