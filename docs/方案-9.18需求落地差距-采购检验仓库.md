## 二、流程契约（需求的运行时含义）

### 2.1 采购到货 → 暂收 → 检验 → 入库 / 退料 / 特采（需求 3.4）

| 步 | 动作 | 附加约束 |
|---|---|---|
| 1 | 采购单在 ERP 审核通过 → **自动同步 MES** | — |
| 2 | 打印采购单报表（挂二维码 = 单号） | **两版**：含单价 / 不含单价 |
| 3 | 含单价版转 PDF 发供应商 | **有条件的开供应商账号自助打印：只见自己的单** |
| 4 | 供应商送货随附该单 | 送货单上注明采购单号即可绑定 |
| 5 | **仓库手机端扫采购单二维码绑定** | 校验该单物料 / 数量防错；**送货日期 = 扫码当天** |
| 6 | **扫码暂收 → 完成后自动生成检验单** | — |
| 7 | 品质检验 | **输产品编码带出检验项目模板**；**输批次号带出数量等信息**；**一批一单** |
| 8a | 结果=**合格** → 生成采购入库单 → 仓库审核 → **转 ERP** | 库位按"预设库位"自动带出；审核前仓库可改；无则手填 |
| 8b | 结果=**特采** → **先走特采单审批（挂报表）** → 批完按入库处理 + **特采标记** | 特采不能直接选 |
| 8c | 结果=**不合格** → 生成暂收退回单 → 采购打印退料单给供应商 | — |

> 补充：**暂收单、检验单不打印；退料单挂报表打印**；**客供料不走此流程**（见 2.3）。

### 2.2 标签与扫码体系（需求 3.5）

| 码 | 内容 | 载体 / 时机 | 打印方 |
|---|---|---|---|
| **采购单码** | 采购单号（**不含日期**） | 采购单报表上 | 我方打印转 PDF，或供应商账号自助打印（选**不含单价**报表） |
| **材料箱码** | **物料编码 + 批次 + 单箱数量** | 标识卡 **100×75**，**贴纸箱/卡板（不贴货架）** | 供应商自打（可编辑模板）或我方在**暂收处**打印；**固定码在物料编码处打** |
| 工单码 / 产品码 | （沿用第二次设计） | 领料、报工、追溯 | 已有 |

> 领 / 发料动作：领料 = **扫工单码 → 扫箱上物料码 → 输入实际数量**；整箱发货扫几箱算多少，**拆箱手输**。

### 2.3 客供料流程（需求 3.6）

客供料到货（有物料编码、无采购单）→ 手机端【其他入库】（**直接扫码 + 输入库数量，不扫采购单**）→ 单据入"其他入库"界面查询、**与正常采购入库区分、防混扫** → 领用走手机端【其他出库】扫码出库 → 系统留出入库记录。
