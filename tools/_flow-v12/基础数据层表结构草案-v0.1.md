## 0. 现状盘点(先有什么、缺什么)

### 已有可直接承载(字段中文化+状态列+asp_*审计列)

| 表 | 承载 | 关键既有字段 | 备注 |
|---|---|---|---|
| `bs_inv` | 物料/存货主数据 | 存货编码/名称/规格/类别/属性(外购自制)/单位/成本/停用 | 现有种子为铝业演示数据,需换银嘉真实物料 |
| `bs_bom` | BOM | 父件/子件/定额数量/损耗率/需用数量/版本/生产车间/预入仓库/默认BOM | 已补物料种类/规格/外观要求列(migrate-bom-*) |
| `bs_op` | 工序 | 工序编码/名称/**默认车间/关键工序/标准合格率%**/计件依据 | 承载五道工序 |
| `bs_wc` | 车间(工作中心) | 编码/名称/所属分类/**产量每小时(=排产产能)**/工作时间/班组/设备 | 承载真实车间+产能 |
| `bs_wh` | 仓库 | 编码/名称/负责人/允许零库存出库 | 隔离仓/不良品仓/线边仓=数据行 |
| `bs_qc_item`/`bs_qc_plan` | 质检项/检验方案 | 检验内容/标准/数据类型/判定规则/上下限 | 品检分流后的检验依据 |
| `bs_uom`/`bs_dept`/`bs_emp`/`bs_equip` | 单位/部门/员工/设备 | — | 齐备 |

### 已挂面板但走旧 HSDZ 表(双轨现状)

CKDA 仓库档案→`dm_ck`、CGD 采购单→`Porder`、KHDD 客户订单→`order_bs/order_bt`、
RKD 入库单→`inh`、CKD 出库单→`outh`、STOCK_STATUS→`kucun`(拼音缩写字段 wzdm/lot_no)。
`bs_*` 系**无任何面板**;`bd_manu_order` 是铝业模板结构(锭号/测试程序),工单表留待生产过程层重设计。

### 差距(本草案要补的)

1. `bs_inv` 无**是否检验**标志——品检分流(流程图:"根据物料编码中是否检验项,自动判段")无依据
2. `bs_op`/`bs_wc`/`bs_wh` 无面板、无银嘉真实数据
3. 无 **ERP 导入通道**(资料/BOM/采购单/销售订单四类)
4. 无**批号流水**(批号=入库日期+3位流水号,二维码=物料编码+批号)

## 1. 既有表补列(ALTER,幂等脚本风格同 migrate-*)

```sql
-- bs_inv 品检分流与溯源标志
IF COL_LENGTH('bs_inv','是否检验') IS NULL ALTER TABLE bs_inv ADD [是否检验] bit NOT NULL CONSTRAINT df_inv_jy DEFAULT(1);
IF COL_LENGTH('bs_inv','检验方式') IS NULL ALTER TABLE bs_inv ADD [检验方式] nvarchar(20) NULL;      -- 全检/抽检(字典 JYFS)
IF COL_LENGTH('bs_inv','数据来源') IS NULL ALTER TABLE bs_inv ADD [数据来源] nvarchar(20) NOT NULL CONSTRAINT df_inv_ly DEFAULT(N'ERP'); -- ERP导入/手工
IF COL_LENGTH('bs_inv','ERP更新时间') IS NULL ALTER TABLE bs_inv ADD [ERP更新时间] datetime2 NULL;
-- bs_bom / bs_wh / bs_op / bs_wc 结构已够,不加列
```

## 2. 新增表(2 张:通用导入通道 + 批号流水)

```sql
-- ── ERP 导入通道:一个批次头 + 通用暂存行(四类导入共用,原始行存 JSON,解析后定位写入) ──
IF OBJECT_ID('dbo.erp_imp_log','U') IS NULL CREATE TABLE dbo.[erp_imp_log] (
  [id] int IDENTITY(1,1) NOT NULL,
  [批次号] nvarchar(30) NOT NULL,              -- ERP+类型+日期+流水,如 ERP-PO-20260910-001
  [导入类型] nvarchar(20) NOT NULL,            -- 资料/BOM/采购单/销售订单
  [文件名] nvarchar(260) NULL,
  [总行数] int NOT NULL DEFAULT(0),
  [成功数] int NOT NULL DEFAULT(0),
  [失败数] int NOT NULL DEFAULT(0),
  [跳过数] int NOT NULL DEFAULT(0),            -- 已存在未变化
  [状态] nvarchar(10) NOT NULL DEFAULT(N'待确认'), -- 待确认/已入库/已取消
  [操作人] nvarchar(50) NULL,
  [导入时间] datetime2 NOT NULL DEFAULT(sysdatetime()),
  [备注] nvarchar(500) NULL,
  [asp_user1] nvarchar(50) NULL, [asp_time1] datetime2 NULL,
  [asp_user2] nvarchar(50) NULL, [asp_time2] datetime2 NULL,
  [asp_cancel] char(1) NULL DEFAULT('N'),
  CONSTRAINT pk_erp_imp_log PRIMARY KEY (id),
  CONSTRAINT uq_erp_imp_log_batch UNIQUE ([批次号])
);

IF OBJECT_ID('dbo.erp_imp_row','U') IS NULL CREATE TABLE dbo.[erp_imp_row] (
  [id] int IDENTITY(1,1) NOT NULL,
  [批次id] int NOT NULL,                       -- FK erp_imp_log.id
  [行号] int NOT NULL,
  [源单号] nvarchar(50) NULL,                  -- 采购单号/订单号/物料编码(BOM)
  [原始JSON] nvarchar(max) NOT NULL,           -- ERP 原始行,审计与重放依据
  [解析状态] nvarchar(10) NOT NULL DEFAULT(N'待解析'), -- 待解析/成功/失败
  [错误信息] nvarchar(500) NULL,
  [目标表] nvarchar(50) NULL,                  -- bs_inv/bs_bom/bd_pu_order/bd_so_order
  [目标键] nvarchar(100) NULL,                 -- 写入后的业务键(如存货编码)
  [处理状态] nvarchar(10) NOT NULL DEFAULT(N'待确认'), -- 待确认/已写入/忽略
  CONSTRAINT pk_erp_imp_row PRIMARY KEY (id)
);
CREATE INDEX ix_erp_imp_row_batch ON erp_imp_row([批次id]);

-- ── 批号流水:批号=入库日期(yyyymmdd)+3位流水;二维码=物料编码+批号 ──
IF OBJECT_ID('dbo.yj_lot_seq','U') IS NULL CREATE TABLE dbo.[yj_lot_seq] (
  [日期] date NOT NULL,
  [当前流水] int NOT NULL DEFAULT(0),
  CONSTRAINT pk_yj_lot_seq PRIMARY KEY ([日期])
);
-- 取号(原子): UPDATE yj_lot_seq SET 当前流水+=1 OUTPUT inserted.当前流水 WHERE 日期=@d;
-- 无行时 INSERT(日期,1) 重试;批号 = CONVERT(char(8),@d,112) + RIGHT('000'+CAST(流水 as varchar),3)
```

> 设计理由:导入通道做**通用暂存行**而非四张分类型表——与项目"配置驱动"哲学一致,四类导入共用
> 批次/行/审计/重放骨架,差异只在解析器;原始 JSON 留底,人工确认界面按类型渲染字段。

## 5. 决策点(需拍板后才出正式迁移脚本)

1. ~~**仓库双轨**~~ **已拍板(2026-09-10)**:`bs_wh` 为唯一真源。WHDA 上线后 CKDA 改挂 bs_wh,
   旧 dm_ck 数据一次性迁移,不再双轨。
2. ~~**BOM 面板**~~ **已拍板(2026-09-10)**:WLBOM 改挂 bs_bom(版本/默认BOM/生产车间/预入仓库完整结构,与基础数据层同源)。
3. ~~**检验标志形态**~~ **已拍板(2026-09-10)**:bit(是否检验) + 方式(全检/抽检) 两列,免检=是否检验为否,不设第三态。
4. ~~**ERP 对接方式**~~ **已拍板(2026-09-10)**:API 自动同步——MES 定时拉取自动入库。
   通道表(erp_imp_log/erp_imp_row)骨架不变,写入器走 API 拉取实现;
   `文件名`列可空(API 模式记接口批次号于备注),`状态`在自动模式下直接流转为`已入库`,
   失败行留`待确认`供人工重放。ERP 厂商与接口规格待补(影响字段映射器,不影响表结构)。

## 6. 明确不在本层(避免范围蔓延)

- 工单表(bd_manu_order 铝业结构)——生产过程层重设计
- 采购单/销售订单业务单据结构(bd_pu_order/bd_so_order)——材料入库链/计划层;本层仅经导入通道**暂存**它们
- 库存表(kucun 旧表 vs 新设计)——材料入库链
- 隔离仓/不良品仓的**流转逻辑**——品质层(本层只建仓别数据)
