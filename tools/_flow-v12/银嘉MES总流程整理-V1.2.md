## 1. 总览:一条主线 + 三条支线,11 个泳道

泳道(从左到右):**研发 | 采购 | 仓库 | 生管 | 混料 | 成型 | 组装 | 品质 | 销售 | 财务 | 备注**
(裁切工序出现在成型与组装之间,图面未见独立泳道标题)

**主线(订单→交付)**:
销售订单(ERP自动导入MES) → 生成工单(ERP单据审核后自动生成) → 工单排产 →
打印工单二维码 → [混料领料→混料报工] → [成型领料→成型报工→打印产品二维码] →
裁切报工 → [组装领料→组装报工] → 成品入库 → 成品仓库 → 销货出库单(审核) → 转ERP

**采购支线(材料入库)**:
ERP资料导入 → 基础资料/BOM → 采购单(ERP里输入,自动导入MES) → 打印材料二维码 →
是否品检(按物料编码是否检验项自动判断):
- 免检 → 直接扫码入库 → 采购入库单 → 材料仓库
- 检验 → 送料暂收单 → 来料检验单 → 是否合格:
  - 合格数量 → 采购入库单 → 材料仓库
  - 不合格数量 → 暂收退回单
- 采购入库单同时 转ERP

**财务支线**:
- 采购入库单审核 → 自动生成应付账款 → 应付对账单
- 销货出库单审核 → 自动产生应收账款 → 应收对账单
- 备注:应收应付在ERP里完成,MES 主要处理成本核算

**研发支线(已交付)**:
立项申请 → 项目实施计划 → 数据记录表 → 项目进度查询;相关技术文件随工单下发

## 4. 横切关注点

- **二维码体系**:材料二维码、工单二维码、产品二维码;规则=物料编码+批号(入库日期+3位流水号),取代产品流动标识卡
- **报工终端**:所有报工都在 PDA 或手机端扫码完成(领料/报工全扫码)
- **文档采集**:仓库相关文档电脑端上传附件;生产各阶段(裁切/组装等)文档手机录入
- **仓别体系**:材料仓库、线边库存、成品仓库、隔离仓、不良品仓
- **ERP 集成点**:基础资料/采购单/销售订单导入(ERP→MES);采购入库单/销货出库单转出(MES→ERP);应收应付留在ERP;工单由ERP单据驱动生成

## 5. 本轮已确认决策(2026-09-09)

1. **裁切双出口**:裁切报工后合格品一部分自动入成品仓(对外直销半成品),其余继续组装
2. **工单生成方式**:ERP里自动导入MES,单据审核后自动生成工单

## 7. 建议开发顺序(依赖驱动)

1. **基础数据层**:ERP资料导入 + 基础资料/BOM + 物料检验项标志 + 二维码规则 → 一切的地基
2. **材料入库链**:采购单导入 → 材料二维码 → 品检分流 → 暂收/检验/退回 → 采购入库单 → 材料仓库(#2-#5)
3. **计划层**:销售订单对接 → 工单生成 → 排产(产能/拆单/齐套) → 工单二维码(#6-#8,#16)
4. **执行链**:混料 → 成型 → 裁切 → 组装(PDA/手机扫码报工 + 线边库存)(#9-#12)
5. **品质层**:三工序质检数据 → 隔离仓/不良品仓 → 品质追溯(#13-#14)
6. **出货与财务**:成品仓 → 销货出库 → 成本核算(#15,#17)

每层可独立验收;2、3 可并行(材料链与计划链互不阻塞,在执行链汇合)。
