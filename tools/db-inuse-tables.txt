# 依据:2026-09-29 四源审计(①) yj_panel 面板绑定且面板在运营 ② 在运营视图依赖 ③ backend/src/main/java

# 用法:① 判断一张表「是不是我们自己的」→ 在册即自有/在用,不在册即脏数据;
#   ② 新建表必须先在本文件登记(连同 db-migrations.txt 迁移脚本 + MS_Description);
#   ③ 本文件之外的业务表出现,按未用表清理流程处理(见 migrate-drop-unused-tables.sql 头部)。
# 例外保留(未用但不删,逐条有据):yj_schema_log=DbSync 迁移登记表;erp_imp_row=ERP 导入通道;
#   dm_key=含明文接口密钥的历史资产(单独处置)。系统自带 dtproperties(is_ms_shipped=1)不在登记范围。
# 格式:table:<表名>   # 中文说明
