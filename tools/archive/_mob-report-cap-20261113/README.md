现场数据（GD-2026-11-0012 行3，今天 2026-11-13）：

```
成型  已报 600 / 计划 2500   可加工量 2500（首道=排产折算）  ⇒ 可报 1900
装箱  已报 1100 / 计划 5000  可加工量 1200（上一道已审完工 1200 折本道）⇒ 可报 100
```

| 填 200 时按钮下方 | 实时提示 `本次最多可报 100`（不用等点提交） |

| 英文（顶栏切 English） | `Qty exceeds the reportable limit` / `You entered 200（over 100）` / `Reportable = previous op「Molding」Approved Output 1200 − reported by this op 1100 = 100` / `Got it / Set to 100` |

## 踩点/口径

1. 口径唯一：`可报 = 可加工量 − 本道已报`，`可加工量 = 上一道已审完工折本道（首道=排产折算）` ——
   与后端 `ProcessFlow.剩余可报`、页面 `leftOf()` 同源；后端闸门仍在（`WoReportService.validateRow`，1% 容差）。
2. 弹窗样式必须放**非 scoped** style（`append-to-body` 后 scoped 够不到），类名统一 `.mp-cap-dlg`。
3. 前端要**同时认新老后端文案**：`/超出(允许|可报)上限/`（旧 `超出允许上限(...)`、新 `超出可报上限:...`），
   否则后端没重部署时弹窗不触发。
4. 手机适配：`width: 92%` + `max-width: 420px`；≤360px 按钮竖排；大字号大按钮。
