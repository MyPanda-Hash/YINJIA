## 1. 结论(两账套 UI 只读验证均 PASS,未写任何排产)

- **场景 A 正式库(YJ)** —— `GY-CB-STD` 换算率 1/1/1:
  勾 `GD-2026-10-0225#1` / `GD-2026-10-0226#1` / `GD-2026-10-0230#1` 三行 → 点「排产」→
  内嵌快速排产页①池**只出这 3 行且默认全选** → 点「批量排产」→ 弹窗显示本批工序 `成型>切炭>组装`、
  计划量链 `200·200·200` / `90·90·90` / `100·100·100`、合计 390 → 取消后 `/pending` 仍 6 行(未写库)。
- **场景 B 测试库(YJ_TEST)** —— `GY-CB-STD` 成型换算率 = 3:
  勾 `GD2608100001#1` / `GD2608100002#1` → 计划量链 `600·200·200` / `1500·500·500`,
  成型本批计划量 2100(= 700 × 3)、切炭/组装各 700 → 取消后池仍 4 行(未写库)。
  这一条证明「计划量按**各行自己**的工艺路线换算」的路径通,且换算率 >1 不会串。
- **计划开工/完工日期(两场景均 PASS)**:工序表已有 `计划开工日期 / 计划完工日期 / 实际开工 / 实际完工`
  四列(与单行排线弹窗一致);打开即带出默认日期链且**上一道计划完工 = 下一道计划开工**、
  每道完工不早于开工(实测默认链 `2026-11-01` 三道相接);实际开工/完工在未排产行显示「-」。
- **场景 D 写库端到端(2026-11-01,测试账套,`_batch-sched-write-test.mjs`)PASS**:
  批量排产 `GD-2026-10-0016#1` / `GD-2026-10-0015#1`(特意选**无报工、可撤销**的行)→ 一次点击
  「排产 2 行」成功;直连库断言 6 条预排台账(2 行 × 3 道),**每道计划数量 = 本行排产数量 ×
  本行该道换算率**(例:0015 成型 100 × 3 = 300、切炭/组装 100),计划生产线/计划开工·完工已落、
  `plang.scx` 已写;随后 `/unassign` 撤销 → 待排产池恢复 6 行、台账 0 条未作废。
- **顺手修**:批量提交成功后,内嵌页**不再误报**「以下工单行已不在待排产池…已跳过」——
  刚排走的那几行属预期消失;缺行告警只保留给「别人先排了」的场景。
