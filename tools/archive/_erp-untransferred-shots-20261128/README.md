## 四、数据取法(不依赖页面)

`_scratch/server-pin-dump.ps1` / `server-dump-full.ps1` / `server-analyze.ps1`:
`POST /api/auth/login`(admin/123456, 不传 factory = 正式库)→ `POST /api/px/queryFormDataList`
(`panelCode=PURCHASE_IN|PU_ORDER`)→ 按「物料编码 + 采购订单行号」把入库单明细对到订单行,
读 `金蝶已入库数量 / 金蝶未入库数量` 判定「已收满 / 超出未入库量 / 有余额」。
⚠ PowerShell 5.1 的 `Invoke-RestMethod` 会把响应按 Latin-1 解码(中文属性名变乱码、取值全空),
必须用 `System.Net.Http.HttpClient` 取字节再 `UTF8.GetString`。
