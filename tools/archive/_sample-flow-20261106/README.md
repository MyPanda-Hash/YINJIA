## 一、版式（像素级复刻）

| 项 | 模板（xlsx） | 实现 |
|---|---|---|
| 外部单纸宽 | A:N 列宽合计 1188px | `.approval-sheet` 1188（`FIXED_SHEET_W.RD_SAMPLE_EXT`） |
| 信息条 | row2：样品单编号 / 客户名称 / 费用 / 下单日期 / 期望交期 | 同 5 格、同顺序，48px 高 |
| 表体 | row3-6：8 列横排（306/136/136/136/68/134/136/136） | 同列宽、同列名；模板 row4 提示词降为单元格 placeholder |

| 标题 | 宋体 24pt 粗体居中黑字 | 32px 粗体黑（24×4/3） |

调整（模板不合理处，已在代码注释里写明）：① 提示词不印进填写区（模板 row4 整行是说明文字）；
② 内部单 68px 的默认列宽放大到 ≥70/≥100；③ 标题黑色取代文书式的蓝字（仅这两张单）。

## 二、流程

| 单据 | 流程 | 落点 |
|---|---|---|
| 外部单 | 草稿 → 提交审批 → 审批中 → **审核**（一级，同时选定确认人）→ 待二级审批 → **确认**（二级签核）→ 已审核 | 纸面「申请/审核/确认」由 `ButtonService.writeSampleSign` 按审批留痕回写（只读格，不许手填） |
| 内部单 | 草稿 → 提交审批 → 审批中 → **确认**（单节点）→ 已审核 | 「申请人」新增时按登录用户带出；「确认人」= 审批通过人 |
| 权限 | 申请人只能看自己的单；审核人/单据管理人看全部 | `yj_role_panel` 授权：user=view/query/add/modify；rd_review、rd_file_owner=+audit(can_approve=Y)；admin=全量 |
| 打印 | 提供打印服务 | 横向 A4（`@page{size:A4 landscape}` 动态注入）+ `zoom = 1062/纸宽`（1188⇒0.894、1450⇒0.732） |

未做（明确留待下一轮）：模板 row12 的「总表+子表（一单多样品）」仍是**一单一样品**（表头 8 列即该样品）；
「不同用户只看自己的单」的服务端行级过滤尚未实现（当前靠角色授权 + 列表查询，无 ownDocs 过滤，
`QueryService.queryDocs` 里没有创建人条件）；样品仓库/制备环节未建单据（现由「单据状态 + 样品状态」表达）。
