# _print-paper-20261105 — 按电脑设纸张(A5 / A4,只换纸不缩放)

用户 2026-11-05 口径(在「自动打印」页截图圈出打印电脑那一行):

> 「能不能实现方框内可以设定打印的纸张大小。(如A4或者A5),但是表格实际占用大小不变」

## 一、怎么落的

| 层 | 改动 |
|---|---|
| 面板(前端) | 「打印电脑」每行加 **纸张** 下拉:`A5 · 中一刀 210×148.5 横` / `A4 横 297×210(内容大小不变)`;改完即时保存 |
| 服务端 | 站点配置多一个键 `print.station.<站点名>.paper`(A5/A4,缺省 A5);**派单时**把本站点的纸张塞进任务(`/pending` 的 `task.纸张`) —— 同一张单可能派给多台电脑、纸可以不同,所以纸张是**按站点**而不是按任务的属性 |
| 打印代理 | `print-agent.ps1 -Paper`:`Send-LabelToPrinter` 按 A5/A4 选标准纸型 + 横打;**绘制坐标永远是 210×148mm** ⇒ 换纸不缩放,内容从左上角起画 |

## 二、验收(真代理链路,18777 端口,Pdf 模式)

| 站点纸张 | 产出 PDF 的 `/MediaBox` | 换算 |
|---|---|---|
| **A4** | `0 0 841.92 595.32` | 297 × 210 mm(A4 横) |
| **A5**(默认) | `0 0 595.32 419.52` | 210 × 148 mm(中一刀) |

- 同一台代理、同一个单据结构,只改站点纸张 ⇒ 纸变了、**内容尺寸没变**;
- A4 那页截图(`pdf-paper-a4.png`):二维码/标题/表格/签名仍是原来的大小,整块贴在左上角,右侧与下方是空白;
- 接口:`POST /api/px/print/station {stationName, paper:'A4'}` → 返回 `stationPaper=A4`,
  之后 `/pending` 的任务里带 `纸张:'A4'`;不传 `paper` = 保留原值(改开关/类型不会把纸冲回默认)。

## 三、注意

- 只支持**标准纸型**(A5/A4)。自定义纸型会被 Microsoft Print to PDF 丢掉(2026-11-02 已踩过,见代理注释)。
- 浏览器打印层(站点离线时的兜底)仍固定 `@page size:210mm 148.5mm` —— 那条路径不知道是哪台电脑、也就没有纸张配置。
- 现场生效:代理要换新 `print-agent.ps1` 并重启;服务端换 jar 后新面板才会出现「纸张」下拉。

复现脚本:`round-49.mjs`(设 A4 → 发单 → 设 A5 → 发单 → 读 MediaBox)、`round-50.mjs`(截 A4 那张)。
