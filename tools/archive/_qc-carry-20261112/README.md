## 四、过程与证据(ego,round-NN.mjs)

| 轮次 | 做了什么 | 结果 |
|---|---|---|
| round-01 | 打开检验数据记录,侦察纸面/参照控件/带入按钮 | 表体列头只剩 2 处「标准库维护」(检验结论、处理意见)—— 检验项那颗已消失 |

| round-03/04 | 逐张打开(物料编码一填即**自动带入**),读表体 | 行值在输入框里(innerText 读不到),改用 `input.value` 读到 |
| round-05 | ① 0010 点「带入检验要求」→ toast**「已按来料检验要求带入 1 项检验项」** ② 0011 再点 → **「检验项已与来料检验要求一致，无需带入」**(幂等) ③ 0012 点按钮后行值出现 ④ 三张都「保存为草稿」成功 | 落库即为上表 |
