# 出货检验表观(QC_ASM_INSP)增加审批流(2026-11-13)

## 用户口径

「为当前的出货检验表观增加审批流程」(截图:表观侧栏只有 新增/保存/保存为草稿/选生产工单/取出货检验计划/检验项目·检验方案/审批情况,
**没有提交审批/审批通过**)。

## 实现(与出货检验功能同形 = 单级审批)

- 后端 `ButtonService`:
  - `SINGLE_LEVEL_INSP_PANELS` 加入 `QC_ASM_INSP`;**提交审批 → 审批通过(一次) = 已审核 → 弃审回草稿**;
  - `SINGLE_LEVEL_PREPARER` 加 `QC_ASM_INSP → 检验员`(表尾「检验人」=编制:可手填,提交审批时为空才兜底写提交人);
  - 审批通过时写纸面「审核人/审核时间」(表内真值列),驳回/弃审清空 —— 与首件/制程检验单同一路径;
  - 顺带修一个既有 bug:`clearAuditSignCells` 盲写「审批人/审批时间」两列,而 `qc_asm_insp_head` 没有这两列
    ⇒ UPDATE 报「列名无效」被 catch 吞掉,弃审后纸面仍挂着上一轮审核签名(实测 ZJ-2026-10-0085)。
    改为按表结构拼 SET(有列才清),弃审后签名格正确清空。
- 前端 `PanelxList.hasApprovalBtns` 加 `QC_ASM_INSP` ⇒ 侧栏在草稿态放出「提交审批」、审批中放出
  「审批通过/审批驳回」(能否点仍由 isDisabled + 后端裁决)。
- 权限:角色权限 `yj_role_panel` 里 QC_ASM_INSP 的 audit/can_approve 与 QC_PROC_INSP **完全一致**
  (仓库管理/生产/质量审核=Y),无需迁移。

## 验证

- 接口全流程(测试账套 ZJ-2026-10-0085,`round-54.mjs`):
  草稿 → 提交审批(**审批中**,检测周期仍单端 `2026-10-16 02:43`)
  → 审批通过(**已审核**,审核人=系统管理员、审核时间落库,检测周期 `2026-10-16 02:43 ~ 2026-11-13 09:19`)
  → 弃审(**草稿**,审核人/审核时间清空,检测周期回退单端)—— 验完单据回到草稿,未改明细。
- 界面(正式库,`round-55.mjs`):表观草稿侧栏出现 **提交审批**(可点)/审批情况;弃审在草稿态正确置灰。
