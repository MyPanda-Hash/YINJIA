# 打印材料码：带入后「每箱数量」仍可填（2026-11-13）

用户口径（附截图，红框标在「每箱数量」列）：

> 打印材料码带入后，每箱数量填不了，只锁定本次打印数量就行，每箱数量可以填

## 一、改了什么

`frontend/src/core/views/MaterialLabelDialog.vue`

| 位置 | 改前 | 改后 |
|---|---|---|
| 主表「每箱数量」输入框 | `:disabled="lockedBySource \|\| !(Number(qtyOf[row.id] \|\| 0) > 0)"` | `:disabled="!(Number(qtyOf[row.id] \|\| 0) > 0)"` —— **不再吃带入锁定** |
| 补登表「每箱数量」 | 同上（含 `lockedBySource`） | 同上处理（保持两处一致） |
| 「本次打印数量」与行勾选 | `lockedBySource` 锁定 | **不变**（用户明确"只锁定本次打印数量"） |
| 带入提示条 | 「数量和行已锁定，只能修改批次号和生产日期」 | 「**本次打印数量和行已锁定；「每箱数量」仍可填**，也能改上面的批次号与生产日期」 |

「每箱数量」原有的约束一条没动：必填（0/空拦在「确定并打印」）、上限 = 本行本次打印数量、
张数 = ⌈本次打印数量 ÷ 每箱数量⌉、零头箱自动多出一张。

`round-12 / round-13` 是有效证据（前几轮是本机 ego 窗口只有 960×256、记录表内层滚动导致点不到按钮的摸索过程，保留备查）：
