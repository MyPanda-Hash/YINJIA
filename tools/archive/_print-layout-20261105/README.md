# _print-layout-20261105 — 领料单版面回归(空行/二维码大小/分页)

用户 2026-11-05 口径(附一张打歪的 PDF):

> 「生产领料单打印有问题,明细只有 3 行,却给了多行的数据,并且二维码过大。
>   而且打印行数,会有限制吗?如果大于 9 行,还能打印吗」

## 一、三个问题与改法(全在打印代理端 `print-agent.ps1`,不动服务器 jar)

| 问题 | 根因 | 改法 |
|---|---|---|
| 只有 3 行明细却像有 8 行 | 纸表固定补到 8 行,且**空行也印订单号** `GD-…-#1` | 空行 `$vals = @('',…)`,只有真有数据的行才写订单号/材料 |
| 二维码过大 | `$qrSize = 132`(占整张中一刀近 1/6) | 132 → **96**(≈24mm);`领料部门/日期` 随之上移(166→134),表格起点 200→166 |
| 行数会不会有限制 | `<#13> if ($rowCount -gt 12) { $rowCount = 12 }` —— **第 13 行起被静默丢弃** | 一页 `PER_PAGE=10`,超出**自动续页**(`$e.HasMorePages`),每页重画抬头/表格线/签名,右上角标「第 n/N 页」,**无上限** |

## 三、两份代理文件要保持一致

`tools/printing/print-agent.ps1`(源)与 `deploy/print-agent/print-agent.ps1`(客户电脑拷走的那份)
内容一致,只有一处差别:**deploy 那份带 UTF-8 BOM**(Windows PowerShell 5.1 读无 BOM 的
UTF-8 会把中文读成 GBK,纸面文字会乱码)。

改完同步命令(仓库根):

```powershell
$src = [System.IO.File]::ReadAllBytes("tools\printing\print-agent.ps1")
$bom = [byte[]](0xEF,0xBB,0xBF)
[System.IO.File]::WriteAllBytes("deploy\print-agent\print-agent.ps1", $bom + $src)
```

## 六、2026-11-06:字被截断(材料名称/规格)+ 多单连续打印

用户口语(附打印件照片):「打印效果不好,会出现字被挡住的问题(没有显示完整)」+「批量生成是否只能有一单被自动打印,没有多单连续打印」。

### 6.1 字被截断

根因:`StringFormatFlags::NoWrap` + 规格列只有 118(约 30mm),`滤芯内盖（闭孔）`、`38.5*38.5*26（…）`
这类**中英混排无空格**的串在 GDI+ 里根本不断行,整段被矩形裁掉。

改法(`print-agent.ps1`):
- 列宽重排 780 总宽:**订单号 168→130 / 材料名称 172→150 / 规格 118→165 / 单位 45 / 请领 92→85 / 实发 92→85 / 备注 93→120**;
- 格子字号 10 → 8;
- **材料名称/规格按字符测宽手动折行**(`Get-CellLines`,最多 2 行,每行单独绘制),
  不再依赖 GDI+ 的"空格换行";
- 其余列仍单行(订单号/单位/数量/备注,保证不被挤到隔壁格)。

验收:`GD-WRAP-1` 一张单塞进 `38.5*38.5*26（超长规格文字测试）` 等长串 → PDF 里两行完整显示,
见 `pdf-wrap-v3.png`。

### 6.2 多单没有连续打印?

机制上**是逐张打、不是只打一张**:一批单会排进服务端队列,代理一张一张取。
但旧版每张之间固定等 4 秒,9 张要 40 秒以上,现场看着就像"只打了一张"。

改法:代理**打完一张立刻取下一张**(`if ($did) { Start-Sleep -Milliseconds 300 } else { Start-Sleep -Seconds 4 }`),
实测 3 张连续发单 → 3 张都在 ~13 秒内落盘(间隔 ≈6 秒一张,受绘制耗时限制),队列归零。
## 七、2026-11-06 第二轮:每一列都自适应,不再有"省略"

用户口径(附打印件照片):「报表还是会省略,如计量单位这边,报表也是省略了后面的内容」。
根因:上一轮只给「材料名称/规格」折行,**其它列仍是单行硬裁**;
`计量单位 = 支（成型前）`(6 字)在 45(≈11mm) 的格子里只放得下 `支 (`,后半截直接没了。

改法(`print-agent.ps1`,明细绘制处统一一套):
- **字号阶梯** 8 → 7.5 → 7 → 6.5 → 6:每格先用 `MeasureString` 量,第一个放得下的字号直接单行绘制;
- 都放不下才**折行**(`Get-CellLines`,最多 2 行),折行优先**在空格处断**
  (不把 `12.7*2.82` 拆开),没有空格才按字数对半;
- 列宽再平衡(总 780):订单号 130 / 材料名称 138 / 规格 150 / **单位 70** / 请领 85 / 实发 85 / 备注 122。

验收(`GD-UNIT-4` 一张单 4 行,含 `支（成型前）`、`黑色密封圈 12.7*2.82（EPDM70度）`、
`56±1mm*108±1mm`):PDF 里单位完整单行、材料名称在空格处断成两行、无任何截断,见 `pdf-unit-fit4.png`。
浏览器打印层(`pickSlipHtml`)本轮未改:HTML 自带 `word-break:break-all` 折行,本来就不会省略。
