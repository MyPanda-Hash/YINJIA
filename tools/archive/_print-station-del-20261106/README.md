用户 2026-11-06 口径:

> 「现在扫码后已存在的领料单,是不在打印的。但是现在是需要给他打印只是不生成领料单。」
> 「还有自动打印界面,要可以删除离线的电脑。像图片那样。」

## 一、删除离线电脑

- 离线行右侧出现「删除」按钮(`print-station-delete.png`:打印电脑-01 离线 → 有删除);
- 服务端 `POST /api/px/print/station/delete`:清内存 + 队列里摘掉该站点 + 删 3 行 `print.station.<名>.*`;
- **在线(90 秒内有心跳)拒绝删**,提示「请先在那台电脑上停掉打印代理,等它变成离线再删」
  —— 否则下一次心跳又把它写回来,删了也白删。

## 二、已存在的单也打印

- `MobilePickController.existingResult` 以前写死 `打印 = null`,重复扫码什么都不打;
  现在用同一个 `printPayload(...)` 生成**已存在单据**的载荷(单号/明细照取),只是不新建台账;
- 前端 `autoPrintAll` 只跳过"没有载荷"的,重复单照打;消息报「已开过单的按原单重打 N 张」,
  结果行标签 `已存在·已打印`。
