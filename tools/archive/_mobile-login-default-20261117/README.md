# 手机端登录页「服务器地址」默认 = 服务器 IP:端口(2026-11-17)

> **用户口径**:「手机端的登录界面的配置默认为服务器的 ip 和端口」

## 1. 现场问题

手机壳(APK)里的登录页,配置项是**接口号**(= 服务器地址 IP:端口)。
2026-11-17 之前:

| 层 | 旧值 | 后果 |
|---|---|---|
| `android/.../MainActivity.java` `DEFAULT_BASE` | `http://192.168.1.10:8090`(占位地址) | 首装 `getBase()` 返回空 ⇒ **强制弹「接口地址」框**让用户手填;不填/填错就进不去 |
| `frontend/src/business/appConfig.js` `API_ORIGIN` | `http://36.140.66.163:8090`(线上服务器) | 与原生默认值**不一致**:首装显示一个地址、请求按另一个地址发 |
| 登录页 | 只给一条黄色横幅「首次使用请点顶部的『设置』确认服务器地址」 | 用户看到的第一个界面就是"要你去配东西",而不是"已经配好了" |

## 2. 本次改动

1. **原生默认值改成线上服务器**:`DEFAULT_BASE = "http://36.140.66.163:8090"`;
   `getBase()` 在 SharedPreferences 为空时**返回默认值**(不再是空串)⇒ 首装不弹设置框、直接进登录页。
2. **登录页多一行只读的「服务器地址」**(仅壳内 = `file://` / `YjNative` / `Capacitor` 时渲染):
   `服务器地址  http://36.140.66.163:8090  [默认]` + 「默认已连服务器,如需修改请点顶部『设置』,改完自动重连」。
   仍是**只读**——改地址的唯一入口还是顶部原生工具条「设置」(2026-11-01 收敛那次的口径:
   页面白屏时原生入口照样能点,网页里的输入框会死在白屏上)。
3. 顶部「设置」对话框:默认值预填服务器地址、提示文案改成"默认已连服务器 X,只有要连别的服务器才改这里"。
4. 与前端默认值对齐:`appConfig.js` 的 `API_ORIGIN` 注释写死"必须与 MainActivity.DEFAULT_BASE 一致"。
5. 多语言:`en.js` 补 `默认` / `默认已连服务器,如需修改请点顶部「设置」,改完自动重连`。
