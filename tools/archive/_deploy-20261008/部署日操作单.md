## 步骤 7：回滚（只在需要时）

顺序必须是「先停应用 → 再回滚库 → 最后起应用」，否则 RESTORE 会报库正被使用。

先停应用：

```
taskkill /f /im java.exe
```

回滚库（把 `<时间戳>` 换成 GO 打印的那个 pre-deploy 备份名）：

```
sqlcmd -S localhost -d master -E -Q "RESTORE DATABASE [HSDZ_MES] FROM DISK=N'C:\yinjia\backup\pre-deploy-<时间戳>.bak' WITH REPLACE, RECOVERY"
```

如果上面报「因为数据库正在使用，所以无法获得对数据库的独占访问权」，先踢会话再重试：

```
sqlcmd -S localhost -d master -E -Q "ALTER DATABASE [HSDZ_MES] SET SINGLE_USER WITH ROLLBACK IMMEDIATE"
```

回滚 jar：

```
copy /y C:\yinjia\backup\app-<时间戳>.jar C:\yinjia\app.jar
```

起应用：

```
C:\yinjia\start.bat
```

回滚后核一下别是孤儿登录（跨机还原的老坑）：

```
sqlcmd -S localhost -d HSDZ_MES -E -h -1 -W -Q "SET NOCOUNT ON; SELECT 'DBOK'"
```
