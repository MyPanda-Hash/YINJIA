# 采购订单打印「可勾选 / 可填数量 / 打印记录」取证(2026-11-07)

## 需求(用户原话)

> 采购订单的打印(两个报表一个有金额,一个没有金额)中,需要能够在打印报表的时候编辑
> (像打印材料码的编辑一样),要可以勾选打印和填写数量。

> 弹窗有对已经打印的做记录吗

→ 追问后选 **A:「像材料码那样」** —— 每次打印存一份快照,弹窗里列出,可重打 / 作废。

## 打印记录口径(与材料码的区别)

| | 材料码(`bd_pu_label`/`bl_pu_label`) | 报表打印记录(`bd_pu_print`/`bl_pu_print`) |
|---|---|---|
| 一张单代表 | 一个批次号 | 一次打印(哪几行 × 各自数量) |
| 是否占用订单量 | **预约**,作废释放 | **不占用**,作废只软删这张纸 |
| 重打 | 打印次数 +1 | 同 |
| 面板 | 不建(弹窗反查) | 不建(弹窗反查) |
| 单号前缀 | `MQ-yyyy-MM-nnnn` | `MP-yyyy-MM-nnnn` |

小计口径:数量**没改** ⇒ 沿用订单原金额(折扣/整单分摊不会被打印抹掉);改了 ⇒ `单价 × 本次数量`(4 位小数)。
落纸「备注」列取订单行备注(该字段此前未进 `yj_field`,纸面恒空;现在随快照带上)。

## 口径说明(为什么打印不写回订单)

「打印材料码」弹窗要**落库**(批次号权威登记 + 预约数量);采购订单报表只是把已保存的订单打出来,
勾选与数量若写回会绕过保存/审核链路。故打印记录只存**快照**(以后重打按快照原样出纸),
订单上一个字段都不动 —— 弹窗顶部那句话就是口径本身:
「勾选要打印的明细行，并填写本次打印数量；只影响这张报表，不改动订单数据」。
