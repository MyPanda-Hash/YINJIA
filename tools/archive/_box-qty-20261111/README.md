> 用户原话(2026-11-11):
> 「材料码多加一个每箱数量打印,每箱数量才等于标识卡上的数量。」
> 「还有弹窗需要尽量大,减少左右横拉」
>
> 追问确认的口径:
> - 每箱数量怎么落地 ⇒「**用 B 就行**,打印多少张卡可以用通过**预览**来选择」

## 一句话结论

材料码弹窗新增「每箱数量」列(可空,空=沿用旧行为),**标识卡卡面「数量」改印每箱数量**;
整箱/零头箱在弹窗底部逐行提示、点打印时再 warning 一次但**不拦**;弹窗宽度 1000px → `min(1560px, 96vw)`,
12 列在 1523px 窗口下**无横向滚动条**。

## 关键设计取舍

1. **每箱数量放行表还是头表**:放**行**表。一张材料码打印单 = 一个采购订单行(`print` 的"每行一张单"口径),
   每箱数量是**物料/包装属性**;头表的 `[批次号]/[生产日期]` 是"这批货"的属性,不同级。
2. **为什么要落库**:卡面「数量」改成印每箱数量后,**重打必须原样重现** —— 不能靠"再抄一遍输入框"(人工可能改过)。
   所以打印时即快照,`reprint` 从行表读数出纸。
3. **历史行不回填**:`每箱数量` 为 NULL/0 ⇒ 卡面回退印本次打印数量,老标签行为一个字节都不变。
4. **零头箱只提示不拦**:用户口径要"可以单独打印零头箱" ⇒ 整箱照常出纸,零头由用户改数量再打一张;
   拦下来反而要让人算两遍。
5. **为什么不自动拆 N 张卡**:用户明确选 B("仍一行一张卡"),张数交给打印预览的**份数**。
