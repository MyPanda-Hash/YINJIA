## 一句话结论

材料码弹窗新增「每箱数量」列(**必填**);**标识卡卡面「数量」印每箱数量**;
**标签张数 = ⌈本次打印数量 ÷ 每箱数量⌉**,零头箱自动多出一张卡(卡面印零头数量);
已打印记录新增「标签张数」「零头箱」(零头用警示 tag 标出);弹窗宽度 1000px → `min(1560px, 96vw)`。

## 关键设计取舍

1. **每箱数量放行表而不是头表**:一张材料码打印单 = 一个采购订单行(`print` 的"每行一张单"口径),
   每箱数量是**物料/包装属性**;头表的 `[批次号]/[生产日期]` 是"这批货"的属性,不同级。
2. **为什么要落库**:卡面「数量」与**张数**都由它算 ⇒ **重打必须能原样重现同一批卡**(13 张、最后一张 50),
   不能靠"再抄一遍输入框"。所以打印时即快照。
3. **张数/零头不另存**:二者完全由 `打印数量` + `每箱数量` 决定,存了反而可能不一致 ⇒ 记录表里**派生**展示。
4. **零头箱是"自动出卡",不是"让用户再打一张"**(第二轮口径):`cardsOf` 直接展开成 N 张 + 1 张零头,
   提示只说明"最后那张印的是零头数量"。
5. **张数上限 1000**:每箱数量误填 1 会瞬间出上千张纸 ⇒ 超限先拦下让人核对(前端守卫;服务端仍按原口径校验数量)。
6. **必填但容历史**:后端对**新打印**强制每箱数量;历史行(该列为空)重打按"一张卡印整批"回退,老记录不受影响。
