### 与并行任务的口径交叉:检出限改名容错

2026-11-17 另一个任务把「送样登记表 / 检验委托单行表」的 **内部检出限 → 标准方法检出限**(整批换新目录)。
纸面(`InspCommissionSheet.vue`)因此加了容错:`LIMIT_KEYS = ['标准方法检出限','内部检出限']`,
表头文字与行值都优先取"真正有值的那一个键" —— 改名前后建的单都不会出现空列。
证据 `shots/round-34-limit-rename.png`:新目录带入一行后,表头显示「标准方法检出限」、值列有内容("/")。
