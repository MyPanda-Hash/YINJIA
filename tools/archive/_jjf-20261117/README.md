## 操作口径(给现场)

1. 责任人(建单人)填单 → 保存 → **提交审批**;此时纸面「编制/责任人」= 提交人、「责任部门」= 其所属部门。
2. 有该面板**审核反审核**权限的角色(如质量审核=冯敏)点「审批通过」→ 单据转 **待二级审批**,纸面「审核」格落其姓名+时间。
3. **超级管理员(冯总)** 点「批准通过」→ **已审核**,纸面「批准」格落值。
4. 任一级「审批驳回」回草稿(意见必填),重提后按当前提交人刷新「责任人/责任部门」。
