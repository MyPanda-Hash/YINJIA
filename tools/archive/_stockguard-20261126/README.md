## 死锁链

1. 转ERP 被金蝶拒（金蝶侧已有引用同一采购订单行的入库单草稿；或该 PO 行余量不足）；
2. 金蝶没有这 500 ⇒ 金蝶现存量里该键 = 0；
3. 同步（`deploy/sync-stock.mjs`）按 A 口径覆盖 `kucun.yl` = 0；
4. 弃审要冲回 −500 ⇒ `StockLedgerService.applyIn` 抛「不可冲回」⇒ **单据既推不了也删不掉**。

## 处置

- **代码根治（已做，2026-11-26）**：库存**数量**守卫默认放行（`GUARD_ISSUE` / `GUARD_REVERSE`），
  只 `log.warn` 留痕；`-Dmes.stock.guard.issue/reverse=true` 可恢复。部署后本单可直接弃审/删除。
- **金蝶侧**：按备注 `[MES:PI-2026-11-0169]`（推送时自动写，见 `KingdeePushService:351`）查有没有那张
  未审核入库单 —— 有就审核它（库存随即进金蝶，同步后 `kucun=500`），没有就是别的单占了 PO 行，先在金蝶删。
- **不要**用调拨单/盘点单在 MES 侧"补库存"：这两张单不推金蝶，补进去下一轮又被抹平。
