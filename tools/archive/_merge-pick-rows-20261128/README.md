# 合单选单窗:一张单据 → 多行物料(2026-11-28 客户口径)

## 客户原话(附截图红框圈住「物料名称」列)

> 「客户反馈物料罗列在一起,不好看是总共有哪些物料,
>  改成和金蝶一样,一个单据,多个物料分行罗列出来。
>  还有回答我那个可加入的状态表达什么,还有别的状态吗」

改前:选单窗(`MergePickDocsDialog.vue`)一张单一行,「物料名称」列把前两个物料用「、」拼成一格
(`M2-D胶粉、M3-D胶粉`),超过两个只显示「等 N 行」—— 客户看不出这张单到底有哪些物料。

## 改后

- 表格数据 = 单据 × 明细行摊平(`flatRows`);单据级列(选择/序号/单据编号/单据日期/供应商/行数/状态)
  用 `span-method` 纵向合并成一格,组内**一行一个物料**,逐行给 行号 / 物料编码 / 物料名称 / 规格型号 / 单位 / 数量 / 剩余数量。
- 状态列三态(客户追问的第二问):
  | 状态 | 含义 |
  |---|---|
  | 可加入 | 服务端放行的候选(已审核 + 还有未送量/超送额度),明细一条都不在合单页面上 |
  | 部分已添加 | 明细只**一部分**在合单页面上(在合单页删掉几行后再选回来就是这个状态) |
  | 已添加 | 明细**全部**在合单页面上(再选不会重复加,只提示"无需重复添加") |
  未审核 / 已关闭作废 / 已全部送完且超送额度用尽 / 别家供应商 **不进列表**(服务端选单口径),
  所以列表里看不到 —— 不是漏了状态。
- 已在合单页面上的明细行**灰显**(提示:加入时只会补没进来的行,不会重复)。
- 表头新增「本页全选」(只勾本页可勾的单据;未锁供应商时按第一张单的供应商收窄)。
- 勾选仍**按单据**(勾一格 = 这张单的全部明细),逐行挑行是在合单页面做的。

## 本次踩到并修掉的三处

1. `行号` 在库里是 decimal(`1.0000`),直接渲染成 `1.0000` 还会把行撑高 → 按整数显示(`lineNo`)。
2. `单位` 的键是**「单位」**(参照档案),不是「计量单位」—— 写死「计量单位」时整列是「-」;
   现在按候选键取(`UNIT_KEYS = ['单位','计量单位']`,同 `CODE_KEYS/NAME_KEYS/SPEC_KEYS`)。
   证据:`round-11.mjs` 打出的接口明细键。
3. 列宽合计 1214px > 表格可视 1164px,「状态」被挤到横向滚动区外 → 缩到 1122px,`overflow=0`。
