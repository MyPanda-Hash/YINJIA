# 内部样品单改共享表 + 外部样品单一级审批回填 / 归档后直改（2026-11-06）

## 用户口径（原话）

1. 内部单：「表头字段可以搜索筛选查询，这个内部的样品的不需要审批，样品状态字段允许进行修改，
   这个表可以新增数据行进行填写，不需要提交审批，就是一个共享文件面板，
   可以设置10行/20行/50行进行页面切换，防止一页数据太多了」
2. 外部单：「配方及工艺要求是在一级审批的时候填进去的 ⇒ 一级审批有一个回填弹窗写这个配方及工艺要求，
   审批通过回填进去，进入二级审批（管理员），管理员审批完成归档」
3. 「二级审批人只有管理员」
4. 「一级审批人和管理员都能看到一个修改单据按钮，点击就可以进行修改，修改完成点击保存回到归档状态，
   但是有一个修改记录记录谁修改的什么时候」+「修改的保存就直接归档回去了，不需要再次审批」

## ① 内部（开发样品申请单）= 共享表

- 面板 `RD_SAMPLE_INT` 由「头行式文书 + 审批」改为 **单表档案式**（`mode=archive`、`line_table=rd_sample_int_head`、
  `head_table=NULL`、`group_col=NULL`），与 商品档案/共享文件库 同一套：
  行内直接编辑、可「+ 新增数据」/作废行、**无 提交审批/审批通过**；
  14 个字段 `place=query,detail`（列表列 + 查询条件），每列表头带 🔍 筛选 + 升降序（生产实测 28 个图标）；
  列序 = 单据日期/申请人/单据编号/项目名/炭棒尺寸/数量/样品背景/配方要求/工艺要求/物料批次要求/期望交期/确认人/样品状态/备注；
  `样品状态/申请人/确认人` 可编辑（原来审批链回写只读）。
- 每页条数档位补 **10/20/50**（原 50/100/200/500），默认 20。
- 新行自动出号：`ButtonService.saveArchive` 在插入行时若面板同时声明 `code_col`+`prefix` 且该格为空，
  按 `SPN-…` 取号（现存档案里只有共享文件库有 code_col 且无 prefix ⇒ 零影响）。
- 迁移：`tools/migrate-sample-int-flat-20261106.sql`（幂等 + 行数守卫 + 自检）。

## ② 外部（开发样品申请单）= 一级审批回填 → 二级(管理员)归档

- 一级审批点「审批通过」→ 专用弹窗「一级审批 · 回填配方及工艺要求」：逐样品行填
  `配方及工艺要求`（必填）/组装要求/性能要求 + 审批意见；`二级审批人` 为**固定显示「管理员（固定）」**（不选人）。
- 后端 `applyL1Backfill`：白名单列 + **本单号 + 行 id 双条件**更新明细并留 `L1_BACKFILL` 痕迹
  （只对 RD_SAMPLE_EXT 生效）；二级审批人固定超级管理员（`fixedAdminL2`）。
- 生产点验（`round-70.mjs`）：弹窗标题/字段/固定二级人正确，**点了取消，生产单据未被推进**。

## ③ 归档后「修改单据」：直改 → 保存即回归档，不再审批

- 侧栏「修改单据」：仅 `RD_SAMPLE_EXT`、归档态、且 管理员 ∪ 本单一級审批人（`yj_form_approval` node_no=1
  留痕 或 纸面「审核」格署名）可见；后端 `openDirectModify` 同样鉴权，免申请进入修改态并插一条修改记录。
- 修改态点「保存」自动走 `保存修改`（`saveDirectModify`）：落库 → 修改记录 diff 收尾 →
  `archived='Y'`、`modify_state=NULL`，**不再进审批流**；再归档时间与申请/审批统一用同一时钟
  （原先 DB GETDATE 为 UTC，比本地时间早 8 小时）。
- 「修改记录」入口对 `RD_SAMPLE_EXT` 放开：逐条显示 申请/审批/再归档 时间 + 修改原因 + 明细变化。
- 本地点验：归档单 → 修改单据 → 改 → 保存（提示「保存修改」成功）→ 侧栏回到 已归档；
  修改记录显示 `admin / 18:10:30 / 一级审批人/管理员直接修改（免申请）/ 修改 1 行`。
