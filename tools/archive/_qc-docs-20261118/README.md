# 质量单据 6 张同款改造 + 「可附图片」附件位 + 两处版面修复(2026-11-18)

## 用户口径(本轮 4 条)

1. 「质量单据列的其余表单都是一样的模式进行改动,二级审批实现即可,不需要指定某个审批人」
   - 追问确认:**责任部门改成责任人所属部门(动态)**;只做「基础同款」(不做「固定品质部冯敏」「勾选负责人」)。
2. 「紧急放行单的日期没有显示出来,会被遮挡」
3. 「当前的单据中存在提及可附图片的单据需要为当前这个地方增加上传附件的组件。项目中存在这个组件的实现,找出进行复用即可」
4. 「来料检验要求和来料检验系列中点击修改后,当前的表格会缩小成单行,显示的字数内容无法查看完全」

## 已知边界(按用户口径刻意不做)

- **「四．不合格品处理意见」固定品质部冯敏**:用户选「只做基础同款」,未做;当前该格随 `signKey=责任人` 显示责任人姓名。
- **「原因分析/性能验证 由责任人勾选相关负责人」(会签式选人)**:同上未做;若以后要做,仓内已有现成范式
  (产品变更单 `提交会签/会签通过/驳回/撤回`)可扩。
- **QC_BHG 的「责任部门」**:是表头录入的业务值(问题责任部门),**不进**自动写入名单;其右上信息表仍是
  「填写部门/填写人/填写日期」。
