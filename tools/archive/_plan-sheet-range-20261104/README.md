# 排单计划日期列 = 勾选行「最前日期 → 最后日期」（2026-11-04）

## 1. 用户口径

> 「当前想法是打印的就按这些勾选的表中最前面的日期到最后的一个日期就行」

即：出纸的日期列不再固定「打印当天起 5 天」，而是取**本次勾选要打印的那些行**里
`日计划` 出现过的最早日期 → 最晚日期（中间没计划的日子保留空列）。这样历史/跨月计划
（例：GD-2026-10-0227 的 10-29~10-31）也能原样打出来。

这是《2026-11-04-排单计划打印日期-四方案》里方案 C 的收敛版：**C2 语义（只按勾选行算日期）
+ 纯前端实现**（后端 `/planSheet` 本来就返回含历史日期的 `日期[]` 与每行 `日计划`，本轮零后端改动）。

### 版式自适应（列多时）

- 列数 ≤7：沿用原版（`M月D日` 表头 9px / 正文 9.5px、固定列 73%、二维码 5%）；
- 列数 >7：`compact` 模式 —— 表头改 **`M/D`**（7px）、正文 8px、固定列按 `1-(n-7)*0.035` 收紧
  （下限 0.52）、二维码 4%，日期列均分剩余宽度。
- 实测：10 列 ⇒ 3.07%/列 ≈ 8.7mm；16 列 ⇒ 2.87%/列 ≈ 8.2mm，A4 横向仍可读（见下方截图）。

### 二维码尺寸 / 可扫性（2026-11-04 追加，口径演进：28px「太小」→ 60px → **52px 且提高底图质量**）

用户口径：「让二维码可以缩小一点，但是不要太小；这个形式其实也能被扫到，中间 228 能扫其他扫不到」。

- **显示尺寸**：行少（≤5）52px（≈13.8mm）、≤8 行 48px、≤14 行 42px、更多 36px；二维码列宽 6%
  （比 60px 版让出 1.5%，日期列更宽一点）；**日期列 >16 天时再收到 44px、>22 天收到 40px（≈10.6mm）**，
  把宽度让给日期列；
- **扫不出的真正原因（已修）**：二维码底图以前只有 **108×108px**（`qrcode` 默认尺寸）+ 白边只留 1 个模块
  ⇒ 打印放大到 15mm 后边缘发虚、表格线贴着码，个别行能扫、多数扫不出。
  现改为 `woQrImg`: `width: 300`（按 13.8mm 打印仍 ≈500dpi 等效）、`margin: 2`（静区 2 个模块）；
  实测同一张表 3 个码底图都是 300px、每模块 10.3px，打印后约 0.48mm/模块；
- 单测：52px/58px 行高/6% 列宽、8 行 48px、16 行 36px、底图 PNG 宽 = 300。

### 日期列很长（>12 天）：**始终横排** + 降字号 + 固定列最小宽度（2026-11-04 追加）

用户口径：「日期排太长就会挤成竖条，如何处理？」→ 先试了竖排表头，用户明确「**不要竖排**」⇒ 改回横排。

A4 横向 285mm 放 23 个日期列，每列约 7.4mm；横排「10/29」要放得下，靠三件事：

- **日期表头始终横排**：`th.dt{white-space:nowrap}` 禁止折行（以前 `word-break:break-all` 会折成竖条）；
  列越窄字号越小：常规 7px，日期列 <2.15%（约 >28 天）自动降到 **6px**；
- **固定列最小宽度**：给每个固定列设下限（数字列 2.2%、交期 2.4%、客户名称 3.8% 等），
  不再被等比压到 1.3%，避免「6000」和邻列叠字；
- **二维码随列数缩**：>16 天 44px、>22 天 40px（≈10.6mm，仍可扫）；
- **极窄兜底**：日期列 <2.3% 时格内数字降一档到 7px；
- 单测：23 天 ⇒ 23 个 `th.dt` 横排、nowrap、二维码 40px/4.6%、日期列 ~2.41%；31 天 ⇒ 表头 6px；
- 截图：`shot-long-range-23days.png`（3 行 × 23 天，10/29~11/20，日期全横排）。

### 空列自动隐藏：客户等级（2026-11-04 用户口径）

> 「客户等级这个列下不存在数据就默认隐藏了。」

- 勾选行（本次要打的行）在该列**全部为空** ⇒ 该列默认不印（`hideIfEmpty` 标记，现只用于「客户等级」）；
- 只要有一行有值（甲/乙/丙…）⇒ 照常打印该列并印值；
- 数据源 `dm_kh.khjb` 现役全空，所以实际效果是「客户等级」列默认消失，空出的宽度给日期列；
- 单测：行全空 ⇒ HTML 里无 `>客户等级</th>`；补一个 `客户等级:'甲'` 行 ⇒ 表头与值都在。

## 3. 边界

1. 勾选行一个非零日计划都没有 ⇒ 退回「今天起 5 天」（不打出没有日期列的空表）；
2. 跨度过大（脏数据/超长交期，>31 天）⇒ 截成**最近 31 天**（保留最新进度）；
3. 已完工行：仍按页面页签/勾选口径，可打；其历史计划日期会正常出列；
4. 二维码、单据编号、纸表固定列都不变；页头仍只有标题（2026-10-21 口径，不印打印日期/制单人）。
