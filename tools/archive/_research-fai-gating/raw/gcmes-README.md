本项目名称为生产管理系统，是一款面向制造行业的企业资源计划（ERP）软件。该系统旨在帮助企业对从原材料采购到产品交付的整个生产过程进行全面管理，涵盖计划管理、生产管理、质量管理、库房管理、设备管理、图纸管理、设备产能分析等核心业务模块。
本系统主要功能包括：
- 计划管理：制定销售计划、生产计划、物料计划等，并进行计划跟踪和调整。
- 生产管理：对生产过程进行实时监控和管理，包括生产进度、生产工艺、生产资源等。
- 质量管理：建立健全质量管理体系，对原材料、半成品、成品进行质量检验，确保产品质量。
- 库房管理：对原材料、半成品、成品进行出入库管理，以及库存盘点和预警。
- 设备管理：对生产设备进行维护保养，提高设备利用率，延长设备使用寿命。
本系统从用户层面主要面向企业内部管理人员，例如计划员、生产主管、质量工程师、库管员、设备管理员等，帮助他们更高效地完成日常工作。

### 系统功能说明

本项目包含以下重要功能：
- **计划管理**：涵盖销售订单、计划池、生产订单、排产计划、物料计划等功能，可以帮助企业制定合理的生产计划，并对计划执行情况进行跟踪和控制。
- **生产管理**：提供生产进度、生产工艺、生产资源等信息的实时监控和管理功能，帮助企业及时发现和解决生产过程中出现的问题。
- **质量管理**：提供质量计划、质检任务、检验标准、检验规范等功能，帮助企业建立健全质量管理体系，确保产品质量符合要求。
- **库房管理**：提供库房管理、库位管理、库存管理、库房台账等功能，帮助企业对原材料、半成品、成品进行高效的出入库管理和库存控制。
- **设备管理**：提供设备分类、设备信息、备品备件等功能，帮助企业对生产设备进行维护保养，提高设备利用率，延长设备使用寿命。
