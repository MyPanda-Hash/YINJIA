## 改了什么

1. 目录内容整批换新:**44 行 → 55 行**(54 个检测项 + 1 行「外送部分」说明)。
2. 新增 12 项:色度 / 高浓度银 / 总硬度(原「硬度」改名) / 吸附碘值 / 吸附亚甲基蓝 / 水分 / 灰分 /
   偏硅酸 / 磷酸盐 / 硅酸盐 / 粉体密实震动 / 强度测试仪-炭棒;「硬度」置 `asp_cancel='Y'`。
3. `yj_field.label`:「内部检出限」→「**标准方法检出限**」(SAMPLE_REG + INSP_COMMISSION 行表);
   物理列名 `内部检出限` 沿用(与「收费」同款 label≠col 先例);`yj_translation` 补 en 译名。
4. 「检测误差」新版源表已无此列 ⇒ 全表清空(列保留)。
5. 检出限口径:内部 ppm 量级 → 标准方法 mg/L 量级;测试周期:半天/一天/两天 → 「N个工作日出数据,5个工作日出报告」。
