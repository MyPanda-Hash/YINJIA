## 一句话留痕

`bl_pu_order`/`bl_so_order` 的明细行 id 是 MES 行级占用(`form_flow_link.source_line_key`)与
材料码(`bl_pu_label.采购订单行id`)的唯一锚点 —— **同步只许 UPDATE,不许整单删插**。
