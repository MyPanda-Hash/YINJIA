### 响应参数
| 参数名称        | 参数类型    | 参数说明                      |
| --- | --- | --- |
| errcode     | integer | 返回码，成功时为0                 |
| description | string  | 返回信息，成功时为success，失败时为具体信息 |
| data        | Data    | 业务返回具体对象                  |

**Data**
| 参数名称          | 参数类型          | 参数说明     |
| --- | --- | --- |
| id_number_map | Map <string>  | id与编码map 
| ids           | List <string> | 单据id数组对象 

#### 响应示例
```json
{
	"data":{
		"id_number_map":{},
		"ids":[
			"1"
		]
	},
	"description":"success",
	"errcode":0
}
```
