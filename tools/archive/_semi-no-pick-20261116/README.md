# _semi-no-pick-20261116 — 生产领料:半成品只显示、不领料、可跳过

用户口径(2026-11-16):

> 「生产领料单有一行带TB的是半成品,再客户那边半成品是不入库的,所以只要显示这行数据,
>  但是实际并不领料就可以,不要影响别的物料正常领料,半成品是可跳过的。」

## 判定口径(只认 `**TB`,不能认裸 `TB`)

实测半成品编码形如 `T410**TB` / `A-32-01**TB` / `C-87**TB`(测试库 bs_inv 里 1146 个)。

⚠ **不能按裸 `TB` 匹配**:`YJ-TB-009`(密封圈)、`TB-20120`、`D-55-04*TB` 都是**正常要领的料** ——
按裸 TB 匹配就会"影响别的物料正常领料"。规则钉死为:**物料编码含 `**TB`**。

## 改了哪些地方(缺一处就漏)

| 层 | 改动 |
|---|---|
| `MobilePickController.isSemiFinished` + `normalizeLine` | 每行带 `半成品: true/false` |
| `scanMaterial` | 扫到半成品 → 明确拒绝:「本厂不入库、不需要领料,直接跳过即可」 |
| `setQty` | 半成品不许填数量(填了会凭空扣库存) |
| `setQty` 的进度 | 分母/分子**只数能领的行** ⇒ `可以提交` 不再被半成品卡住 |
| `submit` 的缺料校验 | 跳过半成品 |
| `createMaterialOutFromPick` | **半成品不进材料出库单**(整单都是半成品时连单都不建,返回 `出库行数=0`) |
| `generateOne` 台账 `物料项数` | 只数能领的行(否则进度永远差一项) |
| `pickProgress`(前端) | 同样排除半成品;`toRows` 也带上这个标记 |
| `MobilePickDoc.vue` | 行上打「半成品·免领」标签、已领显示「免领」、点该行只提示不进填数 |

## 实测(测试库 · LL-2026-11-0012 / GD-2026-11-0014 #2,BOM = 半成品 + PE袋)

| 项 | 结果 |
|---|---|
| `/doc` 明细标记 | `D-01-50**TB → 半成品=true`,`YJ-KBL-012 → false` |
| 给半成品填数量 | 409:`物料 D-01-50**TB 是半成品(编码含 **TB),不需要领料:数量请留 0 直接跳到下一项` |
| 只填正常料(PE袋 2) | `物料项数=1 已领项数=1 可以提交=true`(分母已排除半成品) |
| 提交 | `出库行数=1`;**`bl_material_out` 只有 YJ-KBL-012 一行,`**TB` 行数 = 0** |
| 界面(LL-2026-11-0013,7 行含 1 个半成品) | 进度 **0 / 6**;半成品行有「半成品·免领」标签、已领显示「免领」;点它只出提示、不弹数量 |
