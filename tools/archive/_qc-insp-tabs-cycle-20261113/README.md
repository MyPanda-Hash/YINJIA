- 旧:右端 = `yj_doc_status.pending_at`(提交审批时间) 与 `shsj`(审核时间)的较晚者 ⇒ **提交审批后第二端就被钉住**。
- 新(`QueryService.docCycleText`):右端**只认 `shsj`(审批通过时间)**;`pending_at` 不再参与。
  弃审时 `ButtonService.unaudit` 会把 `shr/shsj` 清空 ⇒ 右端自动消失、退回只显示首次填写时间;
  重新审批通过后落新的审核时间。首端仍是头表 `MIN(asp_time1)`。
