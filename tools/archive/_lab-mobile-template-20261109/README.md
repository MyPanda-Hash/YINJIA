## 口径对齐(与电脑端同一套数据)

电脑端(`core/panel/spikeWaterLayout.js`):**一个标准库条目 = 一套表格样式**,列定义存在
`yj_std_lib.content` 的 JSON `cols` 里(可带 `group` 分格),换条目 = 换表头;没有列结构的老式条目
退回内置列集(判为"未设计")。手机端照这套来,不另建规则:

| 环节 | 手机端实现 |
|---|---|
| 候选 | `GET /stdlib/list?lib=lab.test_item&all=1`,停用条目剔除 |
| 选项名 | 新式条目用 `item_code`;**老式条目**(item_code=默认,名字写在 content 里,如 `NSF 42-余氯`)用 content —— 与电脑端下拉一致 |
| 选条目 | 表头「测试项目」变成下拉(filterable + 可手打新值,与电脑端 `allow-create` 同) |
| 列结构 | `parseLayout(content)` → `cols`;**解析失败/老式条目**退回内置列集并提示"未设计" |
| 明细字段 | `visibleDetailFields`:模版列(键=列名)+ 附件列(手机照片,固定排在最后) |
| 分格 | 同名 `group` 的相邻列,在行内并成一段,只在该段第一列前打一次小标题(试剂用量（g）/ 加标水水质指标) |
| 换项目 | 立即重建明细字段(新行按新列集);打开既有单按**这张单自己的测试项目**取列 |
| 其它面板 | `visibleDetailFields` 走原路径,字段与顺序一字不变 |

纯函数放在 `frontend/src/business/labMobile.js`(`stdLibOptions` / `stdLibContentOf` /
`templateDetailFields` / `visibleDetailFields`),单测 7 条钉住;页面只负责取数与渲染。
