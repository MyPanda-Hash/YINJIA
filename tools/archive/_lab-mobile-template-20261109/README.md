## 口径对齐(与电脑端同一套数据)

电脑端(`core/panel/spikeWaterLayout.js`):**一个标准库条目 = 一套表格样式**,列定义存在
`yj_std_lib.content` 的 JSON `cols` 里(可带 `group` 分格),换条目 = 换表头;没有列结构的老式条目
退回内置列集(判为"未设计")。手机端照这套来,不另建规则:

| 环节 | 手机端实现 |
|---|---|
| 候选 | `GET /stdlib/list?lib=lab.test_item&all=1`,停用条目剔除 |
| 选项名 | 新式条目用 `item_code`;**老式条目**(item_code=默认,名字写在 content 里,如 `NSF 42-余氯`)用 content —— 与电脑端下拉一致 |
| 选条目 | 表头「测试项目」变成下拉(filterable + 可手打新值,与电脑端 `allow-create` 同) |
| 列结构 | `parseLayout(content)` → `cols`;**解析失败/老式条目**退回内置列集并提示"未设计" |
| 明细字段 | `visibleDetailFields`:模版列(键=列名)+ 附件列(手机照片,固定排在最后) |
| 分格 | 同名 `group` 的相邻列,在行内并成一段,只在该段第一列前打一次小标题(试剂用量（g）/ 加标水水质指标) |
| 换项目 | 立即重建明细字段(新行按新列集);打开既有单按**这张单自己的测试项目**取列 |
| 其它面板 | `visibleDetailFields` 走原路径,字段与顺序一字不变 |

纯函数放在 `frontend/src/business/labMobile.js`(`stdLibOptions` / `stdLibContentOf` /
`templateDetailFields` / `visibleDetailFields`),单测 7 条钉住;页面只负责取数与渲染。

## 补丁(同日):模版列要**继承字段类型**,否则「测试日期」没有日期选择器

> 用户报障:「手机端的测试日期没有时间选择器」

根因:列结构(标准库 content 的 `cols`)只描述"有哪些列/叫什么/多宽/怎么分格",**不含 dataType**;
`templateDetailFields` 原先一律写死 `dataType:'文本'` ⇒ 手机端按类型选控件时,「测试日期」也被当成文本。

修法:按列名去**面板明细元数据**里找同名字段(名称归一:去掉字面量 `\n`/换行/空白,所以
`配水量（L）` 也能对上 `配水量\n（L）`),继承 `dataType` / `options` / `isNotNull`;元数据里没有的列仍退回「文本」。
`visibleDetailFields` 把 `metaFields` 一并传进去。

验证(`ego/07-测试日期.png`、`ego/08-日期面板.png`):加标水选「除汞」后展开第 1 行,
「测试日期」渲染成日期控件(占位「选择日期」),点开弹出日历面板(2026 年 11 月);
其余列(项目名称/测试装置/测试工位…)仍是文本框。单测新增 2 条钉住"日期必须继承成日期"。

APK 随之重出:**1.0.10(versionCode 11)**,`android/dist/yinjia-mes-1.0.10.apk`。

## 补丁(同日):「删除行」加确认弹窗(防误触)

> 用户口径:「还有点击删除行的时候要有弹窗,防止误触」

`removeRow` 改成 async:先 `ElMessageBox.confirm`,**取消/关闭 ⇒ 直接 return,什么都不动**;
确认才删(顺手丢掉这一行排队的照片与展开状态)。弹窗文案带**行号 + 这一行填了什么**
(例:`确定删除 第 1 行:(未填) 吗?删掉的行保存后才会从电脑端消失。`),现场能看出是不是点错行;
按钮 = 取消 / 删除(warning 样式,与"删除附件"同一个风格);非草稿仍先给"只有草稿才能删除行"提示,不弹确认。

验证(5173,`ego/09-删除行弹窗.png`、`ego/10-删除后.png`;复跑 `ego/round-07.mjs`):
两行明细点第 1 行「删除行」→ 弹窗;点「取消」行数仍 2;再点「删除」→ 行数变 1。
源码契约测试 `src/views/mobile/mobileLabRecordDeleteRow.test.js` 4 条(confirm 在前、取消 return、
文案带行摘要、草稿守卫在前)。
