### 打开「合单生单」的正确姿势（踩了半天）

1. 打开任意一张采购订单（`?docNo=…`，单据要「已审核」）→ 工具条「生单 ▼」→ **合单生单**；
2. 弹出「选择采购订单」：**多选要点击 `.el-checkbox__inner`**——点外层 `<label class="el-checkbox">` 会触发两次 toggle（label 的 for + input 自身），两行勾完反而只剩 1 行；
3. 勾够 2 张同供应商订单（页脚显示「已选 2 张单据」）→「加入合单」→ 才弹出 `合单生单 → 送料暂收单` 对话框。
