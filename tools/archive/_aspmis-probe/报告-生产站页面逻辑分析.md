## 1. 技术栈总览

| 层 | 实现 |
|---|---|
| 后端 | **LdCms.NetCore**(meta keywords 即 LdCms.NetCore;C#,ASP.NET Core MVC,Razor 服务端渲染) |
| 页面形态 | 服务端渲染整页 HTML,非 SPA;主框架 + iframe 多标签 |
| UI 框架 | **H-ui.admin v3.1**(顶栏+侧栏+选项卡经典后台模板)+ layer 2.4 弹层 |
| 表格(类型 A) | **jQuery EasyUI** datagrid(`Content/EasyUI`,中文字段名作 field) |
| 表格(类型 B) | **DataTables 1.10** + laypage 分页 |
| 图表 | echarts 3.4.0 |
| 表单/校验 | jquery 1.9.1 + `H-ui.min.js` **内嵌 jquery.form(ajaxForm)** + jquery.validate |
| 埋点 | 百度统计 hm.js(a7c0f06355739a07c54353f3a83e52b0) |
| 会话 | Cookie `.LdCmsNetCore`(ASP.NET Core 加密认证 Cookie)+ `CompanyId` + `LANGUAGE` + `Huiskin` |

与本仓库 YINJIA-MES(Vue3+Spring Boot+元数据面板)**完全不同技术路线**:该站是"每页一控制器动作、
服务端渲染 + 页面内联 JS"的传统多页应用,面板/字段不走元数据驱动。

## 2. 登录页 `/admin/login/sys`

### 2.1 表单与提交
- 字段:`LANGUAGE`(下拉)/`companyid`/`username`/`password` + 隐藏 `maxrecord`(显示最大记录数)、隐藏 `TenantId`。
- 提交走 `$("#form").ajaxForm`(H-ui.min.js 内嵌 jquery.form)→ **POST `/admin/login/sys`**(urlencoded),
  成功响应 `{"state":"success","message":"成功"}` 并下发 Cookie → JS `window.location.href='/admin'`。
- 实测(headless Edge):填公司 0/账号/口令点提交,最终 URL = `/admin`,登录链路通。

### 2.2 页面内联逻辑逐条
| 逻辑 | 实现 | 实测 |
|---|---|---|
| 顶部时钟+扫码心跳 | `showTime()` 每秒刷新时间文本,同时**同步 XHR(`open(..,false)`)POST `/admin/SMDL?BarCode=…`**,带 `screen_w/screen_h/CompanyID/StaffID` 头;响应含"成功"则跳 `/admin/login/sys?BarCode=…` | 心跳返回 `{"state":"error","message":""}`(扫码未命中),仅 console.info,不影响账密登录;**同步 XHR 阻塞主线程**,属反模式 |
| 语言切换 | `LANGUAGE` change → POST `/admin/UpdComm`(`arrid[]=[语言,'刷新']`)→ `location.reload()` | 服务端按 `LANGUAGE` Cookie 重渲染整页译文 |
| 公司/账户联动 | `companyid`/`username` change → POST `/admin/UpdComm`(`arrid[]=[公司,账号]`),静默无提示 | 探针填值触发 2 次,均返回 JSON |
| 刷新二维码 | POST `/admin/ReBarcode`(`arrid[]=[公司]`)→ reload | 未点击(只读) |
| 注册/客服 | `layer_show` 弹层:`/admin/Reg?StaffId=9999888877776666`、`/admin/KF?…` | 未点击 |
| 验证码 | `init()` 500ms 后 GET `/verifycode/get`,**代码引用未定义变量 `code`** | 必现 `ReferenceError: code is not defined`(login:194);该调用整段死代码,页面也无验证码输入框 |

### 2.3 发现的 Bug
1. **`code is not defined`**(login:194):验证码初始化死代码,每次打开登录页控制台报错。
2. **`eles is not defined`**(login:313):`formSubmit` 成功回调里 `window.location.href='/admin'` 之后
   有一句裸 `eles {…}`(疑似 `else` 打错)。实测登录**仍成功**——因为跳转语句先执行,
   ReferenceError 中断的是跳转之后的收尾逻辑(错误提示分支);即"登录失败时的错误消息弹层"实际不可达。
3. 登录 POST **无防伪 Token**,失败无锁定(未测,按代码未见)——安全观察,不做利用。

## 3. 主框架 `/admin`

### 3.1 布局与菜单(服务端渲染,登录态决定内容)
- 顶栏 8 个一级导航(`.navbar-levelone`)+ 侧栏 8 个模块组,一一对应:
  基础(Nền tảng)/订单(Đặt hàng)/主页(Trang chủ)/铜铁?铜粗(Dồng thô)/质量/设备/财务/系统——
  当前 `LANGUAGE=Other`(越南语)故显示越南语;切简体即中文(服务端按 Cookie 渲染)。
- **菜单全量 113 项**,每项 `data-href`(打开的子页路由)+ `data-title`(tab 标题),
  分组头为 `----------中文分组名----------`(分组名**硬编码中文**,不随语言切换,越南语模式下中越混排)。
  完整清单见 `menu-inventory.md`。分组涵盖:基础数据/销售/采购/仓库WMS(入库·出库·库存查询·盘点调拨)/
  生产计划·过程·报表看板/品质/设备/财务(应收应付发票)/系统管理。
- 菜单权限:Admin 角色渲染全量菜单;`/SysPower/Power`、`/SysRoles/Power` 为权限配置页(未进入修改)。

### 3.2 选项卡 + iframe 机制(`H-ui.admin.js`,实测全通过)
- 顶栏一级导航 ↔ 侧栏模块:`$("body").Huitab({...})` 按索引联动切换。
- 侧栏点击 → `Hui_admin_tab(this)`:
  1. 读 `data-href`/`data-title`(缺属性 alert 报错);
  2. 按 `data-href` **查重**:已开 tab 只切换,**并把该 iframe 的 `src` 重置为 href(=刷新子页)**;
  3. 未开则 `creatIframe()` 追加 `<li>` tab + `<div class="show_iframe"><iframe src=…>`,`iframe.load` 后隐 loading。
- tab 交互:单击切换(隐藏/显示对应 iframe)、点 `i` 关闭、双击关闭(首页 tab 保护)、
  右键菜单(关闭当前/全部)、`js-tabNav-prev/next` 横向滚动溢出 tab。
- **实测**:点客户资料后 tab=`["Thông số hệ thống"(welcome),"Thông tin khách hàng"]`、iframe 数 2、
  src=`[/admin/welcome, /BasCust/List]`;切回首页 tab 显示=`block,none` ✓。

### 3.3 顶栏其它逻辑
- 用户区:`系统管理员` + `Admin` 下拉(转换账户/退出 `/admin/logout`、修改密码 `/admin/PassWord`)。
- 语言:下拉点简体/繁體/English/Tiếng Việt → `Language(L)` POST `/admin/Language` → reload。
- 消息:`Hui-msg` 徽章(实测渲染 badge=1),**未见 JS 拉取逻辑**,为服务端注入值。
- 换肤:6 色 `data-val` → `$.cookie('Huiskin',v)` + 动态替换 `skin/<v>/skin.css`,iframe 内同步换肤。
- `myselfinfo()` 查看信息弹层内容是硬编码字符串 `'管理员信息'`(**无真实数据**)。
- `DigSig()` 电子看板 → `layer_show /admin/List3`;`PassWord()` 改密弹层。

## 5. 业务子页(iframe 内)两类模板

### 5.1 类型 A:EasyUI 行(以 `/BasCust/List` 客户资料为样本,实测 8 行)
- **数据加载 = 服务端渲染**:Razor 直接把查询结果渲成 `<tbody><tr>`(实测 iframe 内 8 行,
  首行 汕尾鼎裕/2010005…),EasyUI datagrid 消费静态表格;列定义 `field` 用**中文列名**(锁定标记/成交状态/客户名称…),
  冻结列(复选框+锁定标记+成交状态)+ 隐藏列若干。
- **查询**:整页 GET 刷新 `window.location.href='?datemin=&datemax=&keyword=&keyword2=&Find1=&Find2=&Find3=&ID='`;
  `Find1` 字段下拉数据源 `/UploadFiles/0AdminFIND.json`,`Find3` 操作符 11 种(类似于/等于/大于/包含/为空…),
  日期 WdatePicker。**查询条件直接拼 URL,无编码**(keyword 含 `&` 即断)。
- **工具条动作**(单据操作均为"勾选 checkbox 收集 `arrId[]` → layer 弹层或 POST"):
  - 新增 `layer_show /BasCust/add`;修改(仅允许 1 项)`layer_show /BasCust/add?StaffId=<id>`;
  - 删除 `POST /BasCust/DeleteBatch`(layer.confirm 二段);开通账套 `POST /BasCust/MakeZT`;
    锁定/解锁 `POST /BasCust/TOLock|NOLock`;改变成交状态 `POST /BasCust/ChangeZT`;
  - 特殊功能菜单:客户跟进/联系人/公海/更换负责人/退回公海/团队成员(弹层类);
  - 语言 `POST /<Ctrl>/ToLanguage`;**屏幕自适应** `resizeEasyuiComponents()` → 收集宽高偏移
    `POST /<Ctrl>/GetScreen` 成功后 `location.reload()`(页 ready 300ms 后自动执行一次;
    本次两次运行时会话未在 Network 捕获到该 POST,时序待复核);
  - 导出(EXCEL 画线/TXT/不画线/格式设置)、选择报表、下载/上传报表格式、打印 → 均 `layer_show` 到
    `/<Ctrl>/toExcel|toTXT|SelReport|DownLoadReport|UpLoadReport|Print` 弹层页;页脚显示"当前报表: 客户资料测试"、
    "共有数据:8 条"(服务端注入)。
- 弹层占位符机制:`layer_show(title,url,w,h,id)` 把 URL 中 **`9999888877776666` 占位符替换为选中 id**
  (H-ui.admin.js 实现,全站统一)。
- `cellStyler`:成交状态=="已成交" → 黄底红字;**回调首行残留 `layer.msg('网格颜色')` 调试弹窗**
  (源码级问题:若被 EasyUI 调用会每格弹 toast;运行时未专项复现)。
- 加载即景:ready 后 `showLoading` → 300ms 假 loading → 隐藏面板再显示(纯视觉,无数据等待)。

### 5.2 类型 B:H-ui 表格 + DataTables(以 `/SysLog/List` 系统日志为样本,实测 100 数据行)
- 服务端渲染 `<table class="table-sort">` 全部行(页脚"总记录:100"服务端注入),
  DataTables 初始化:`aaSorting [[1,'desc']]`、`bStateSave true`(排序/页长存 localStorage)、
  `aLengthMenu [10,25,50,100]`、首列不排序——**排序分页全在浏览器端对已渲染行操作**。
- 查询与类型 A 同款整页 GET 刷新(`?datemin=&datemax=&keyword=&keyword2=`)。
- 导出/选报表/打印同 5.1 的 layer 弹层模式(`$.mainu.toExcelA/toTXT/SelReport/Print…`)。
- 列:用户ID/姓名/日期/模组名/IP地址/电脑名称/功能/备注;复选框 `value` 为空(日志页无批量动作)。

### 5.3 两型共同点
- 面包屑:`首页 > … > <中文页名>.<动作>.<控制器>Controller`(如"客户资料.列表.BasCustController")。
- 语言切换、导出、报表格式上/下载、打印四件套每页标配(走弹层,未点击)。
- 子页 JS 错误(实测):`/Scripts/common.js:27 $(...).menu is not a function` ×2——
  子页自带 `/Content/EasyUI/jquery.min.js` 与主站 jQuery **双 jQuery 并存**,common.js 的 tab 右键菜单初始化抛错
  (EasyUI 侧菜单插件未加载/顺序问题),属生产实存缺陷。
