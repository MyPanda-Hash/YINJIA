# 日排产日期列取证与复核（2026-10-31 下午）

用户在一张「生产工单」页截图上画了红框（日期列区）与黄框（10-20 那一格），问：
「红框内的黄色框线为当前报工日期的报工数量对吗？这样如何修改呢？当前的实现感觉怪怪的」。
本目录是当次取证脚本 + 复核截图，配套改动见
`docs/plans/2026-10-31-工单排产-日排产分配与产能可见-方案.md` §8。

## 结论（查库取证）

| 问题 | 事实 |
|---|---|
| 黄框那格是什么 | 列 = **10-20**（不是今天 10-31）；上格 = 该行 10-20 的**日计划** 10；下方小字 = 该行 10-20 的**已审报工量** 10（`scjl.wgzt='Y'`，全库该单只此一条）⇒ 两个数相同，看着像重复渲染 |
| 10-20 这列为何存在 | 整表并集里那天「报过工」；10-21~10-30 全无列，列头从 10-20 直接跳到 10-31 |
| 真 bug | `buildDates` 过去日期只认「有已审报工」⇒ 过去只有**计划**时列被吞；但计划量照样计入 `7天已排/15天已排/计划合计`。取证 `GD-2026-10-0227` 行1（plang 2172）：10-29、10-30 各 2000 都不出列，而 `7天已排/15天已排` 显示 6000（表里只剩 10-31 的 2000） |
