# 合单生单 · 选单弹窗(2026-11-24)

用户口径(原文):

> 「和单生单添加一个弹窗选择,不再是勾选了,而是点击合单生单弹出一个窗口,这个窗口可以选择单据,
>  选择单据后,加入到现在的合单生单页面。然后又删除按钮,可以删除掉不需要单据的明细。也可以重新添加,
>  在合单生单页面多一个选择单据的按钮,选择后单据明细会添加进来,已经有的明细就只补没有的就行。
>  参考金蝶erp选单的设计逻辑。」

## 改了什么

| 位置 | 内容 |
|---|---|
| `frontend/src/core/views/MergePickDocsDialog.vue`(新) | 选单窗:只列 **已审核 + 还有未送量** 的采购订单(数据源 `/api/px/voucherFlow/sources`,行级剩余量与生单页面/后端校验同源);按单据号/供应商片段/日期段收窄;整行点击即勾选;供应商锁定(合单只能同一家);已加入的标「已添加」但仍可选(再选只补缺的行) |
| `GenerateLinesDialog.vue` | 合单页顶部加「选择单据」按钮(嵌同一个选单窗);单据行头加「删除本单」、明细行尾加「删除行」;选单补单按 `lineKey` 去重,只补页面上还没有的行(补进来的行与首次打开同口径:数量按剩余量预填、有剩余的订单行自动勾上);删到只剩一张单时点「确定合单生单」前端直接拦 |
| `PanelxList.vue` | 「生单 ▼ → 合单生单」不再依赖左栏勾选,点了先开选单窗,确定(≥2 张)后才开合单页面 |
| `en.js` | 选单/删除相关文案的英文词条 |

后端 `/px/push/merge`(一张送料暂收单、行级「采购单号」= 合单前订单号、占用用合单后暂收行 id)**未改**。
