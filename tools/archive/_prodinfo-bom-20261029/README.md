## 已知偏差 / 边界

- **`_q-verify.mjs` 的断言①会显示 FAIL**,原因是 `/px/callButton` 的返回体**不带「版本」**字段(不是功能没生效)。
  版本真值以 SQL 为准:`SELECT 版本 FROM rd_spec_doc_head WHERE 单据编号='SD-2026-10-xx'` → `V2026-10-29`。
  同脚本里的 `探针单清理 = 404` 也是因为项目没有 `/px/deleteDoc` 接口;作废改走
  `UPDATE rd_spec_doc_head SET asp_cancel='Y'`。
- 「采购物料清单」的取数源沿用现有**商品档案(INV)** 弹窗(与规格书第 4 页「从商品引用」同一套),
  不是另建一个采购物料源;数量不由引用带入(商品档案没有用量口径)。
- BOM 表的 `序号` 只作为物理列存在,纸面用 `hiddenCol` 隐藏(设计图那张表没有序号列)。
