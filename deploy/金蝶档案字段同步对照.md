# 金蝶云·星辰 → MES 基础资料字段同步对照(记录)

> 记录日期:2026-09-15 | 适用范围:12 类基础资料档案(deploy/sync-core.mjs 的 `BD_*` 条目)
> 配套工具:`_probe-archive-fields.mjs`(抓真实接口字段)、`_compare-fields.mjs`(双向自动对照)、`_gen-archive-fields.mjs`(生成迁移)

## 一、本次口径(用户确认后定稿)

1. **字段来源 = 列表接口 ∪ 详情接口**
   实测两者字段集不同:供应商列表有 `bank/rate/invoice_name/group_number` 而详情没有;商品列表有
   `brand_name/stock_name/base_unit_number` 而详情没有;仓库列表有 `group_name/is_allow_neg`;部门列表有 `is_leaf`。
   运行期用 `mergeListDetail()` 合并(列表打底、详情非空覆盖),避免"只调详情白丢字段"。
2. **只保留能同步过来的字段**:面板字段 = 映射实际写出、且接口真有该键的字段;其余删除(`migrate-kingdee-archive-prune.sql`
   + `migrate-kingdee-archive-keep-syncable.sql`)。物理列保留(MES 业务逻辑读列),只删面板字段。
3. **敏感字段解密导入**:官方《隐私数据解密》——AES-256-CBC / PKCS7,密钥 = 应用 `clientSecret`(32 位 ASCII),
   IV 固定 `5e8y6w45ju8w9jq8`,密文 Base64。实现见 `kingdee-crypto.mjs`(`setSecret/dec`),失败不阻断同步并计数。
4. **初始化清污**:`init-sync` 每轮先"确认→全量前像备份→删本同步器旧数据→全量重建"(手录行保留)。
5. **测试上限**:`config.sync.maxRecordsPerType`(当前 50)——够数即停,不再翻页。
