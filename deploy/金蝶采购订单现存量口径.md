# 金蝶采购订单「现存量」口径(2026-11-12 实测,真实账套 359797)

> 一句话:**有,但它是「这张单上存下来的库存快照」,不是现在的库存。**
> 想要"现在有多少"只能看 `inv_inventory_ims` 同步进 `kucun` 的数(见
> `docs/development/金蝶库存同步-以金蝶为准.md`),**不要**拿采购订单行上的「现存量」当库存用。

## 一、接口层面:字段确实存在

| 项 | 实测 |
|---|---|
| 接口 | `GET /jdy/v2/scm/pur_order_detail`(采购订单详情) |
| 商品分录键总数 | **103** 个 |
| 相关键 | `inv_qty`(库存数量)、`inv_base_qty`(基本库存数量) |
| 列表接口 | `/jdy/v2/scm/pur_order` 列表行只有 18 键、`material_entity` 为空 ⇒ **列表拿不到**,只有详情才给 |
| `inv_base_qty` | 采样 67 行**恒为 0**,不可用 |
| 「现存量说明」 | 接口无实时值(同步映射里硬编码 null,见 `deploy/金蝶档案字段同步对照.md` §二) |

官方字段表登记:`deploy/面板字段对照.md` §三 `MaterialEntity` → `inv_qty | number | 库存数量`。

## 二、数据层面:真实账套里是有值的

- 2026-11-12 抽 20 张已审核采购订单 / 67 行:带 `inv_qty` 键 **67/67**,空值 **0**,0 值 23,正值 44,负值 0。
- MES 已同步全量 `bl_pu_order`:**5030 行,空值 0**(0 值 1677、正 3335、负 18)。
  ⇒ 不是"字段空着没人填",金蝶确实把下单时的库存带到了单上。

## 三、关键结论:是「制单快照」,不是实时现存量

同一物料 `YJ-XH-001` 的 **49 张**采购订单(2025-04 ~ 2026-11,跨 19 个月),在**同一次运行、同一时刻**逐张取详情:

| 单据日期 | 单据编号 | 数量 | MES 库内现存量 | 金蝶现在返回 |
|---|---|---|---|---|
| 2025-05-06 | YJ-20250506-03 | 3000 | 6000 | 6000 |
| 2026-01-02 | YJ-20260102-03 | 3000 | 4000 | 4000 |
| 2026-06-05 | YJ-20260605-01 | 6000 | 700 | 700 |
| 2026-10-05 | YJ-20261005-01 | 5000 | 25 | 25 |
| 2026-11-05 | YJ-20261105-06 | 90000 | 2525 | 2525 |

- 49 张单 → **49 个互不相同的值**(0 / 6000 / 8000 / 10120 / 2495.5 / 14000 …),而"实时库存"对同一物料只可能是一个数 ⇒ **排除"读取时现算"**;
- 49 张单的金蝶返回值与 MES 库内已同步值 **49/49 逐一相同**(MES 是几个月里分批同步进去的)⇒ 值在单据上**冻结**,不随后续出入库变化;
- 同一天的两张单(如 2025-07-28 的 `YJ-20250728-12` / `YJ-20250728-01`)值相同 ⇒ 与"按单据日期取结存"也吻合,但无论按哪种解释,**都不是今天的库存**;
- 与今天的真实库存对比:`YJ-XH-001` 当前 `kucun` 合计 **2025**,而 11-05 的单上写着 2525 ⇒ 差 500,照抄会被当成"现在有 2525"。

**口径**:行上 `仓库` 为空(5030 行里 4980 行为空;有值的 50 行全是 2025-04 老单且值为 0)⇒ 这个数是**全仓合计**,不分仓库、不分批次。

## 四、MES 侧怎么用

- 面板 `PU_ORDER` 明细列表有一列「现存量」(`place=detail`,`visible=1`,`hidden=0`,`seq=130`),没有「现存量说明」;
  同步映射 `deploy/sync-core.mjs` 的 `PU_ORDER.mapLines` 写 `现存量: num(m.inv_qty)`。
- 该列只代表**这张采购订单在金蝶保存那一刻**的库存,业务上只适合做"当时库存参考",**不可用于可用量判断、缺料判断、库存对账**。
- 要"现在的库存":`kucun.yl`(金蝶 `inv_inventory_ims` 现存量,每 5 分钟覆盖一轮);
  要"按仓库/批次":`kucun` 的 `(物料,仓库,批号)` 三键;库存状况表 `v_stock_balance` 仍是流水口径,也不是现存量。

