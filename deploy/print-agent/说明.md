# 银嘉 MES · 打印代理(客户电脑部署)

> 用途:让**手机点打印**,这台电脑**自动出纸**;没有打印机时自动存成 PDF。

---

## 一、客户电脑需要什么

| 要求 | 说明 |
|---|---|
| Windows 10 / 11 | PowerShell 5.1 是系统自带的,不用装 |
| .NET Framework 4.x | Win10/11 自带(代理用 `System.Drawing` 画标签) |
| **能访问 MES 服务器** | 浏览器能打开 `http://服务器IP:8090` 就行 |
| 打印机(**可选**) | 没有也能用 —— 会自动存 PDF |
| 不需要管理员权限 | 自启写在当前用户 `HKCU\...\Run` 下 |

**不需要**:不需要装 Java、不需要装 Android SDK、不需要仓库代码。

---

## 二、部署步骤(3 分钟)

### 1. 拷贝文件夹

把整个 `print-agent` 文件夹拷到客户电脑,例如:

```
D:\MES打印\print-agent\
    ├─ print-agent.ps1    ← 代理本体(单文件,自包含)
    ├─ 安装.ps1           ← 安装逻辑
    ├─ 安装.bat           ← 双击这个
    ├─ 卸载.bat
    └─ 说明.md
```

> ⚠ **必须整个文件夹一起拷**,只拷 `print-agent.ps1` 也能跑(不含安装脚本),但不方便。

### 2. 双击「安装.bat」

它会:
1. 检查 .NET 组件与打印机
2. 写开机自启
3. **立刻在后台启动代理**
4. 报告当前状态

看到 `[OK] 代理已启动` 就成功了。

### 3. 在浏览器里开启自动打印

```
浏览器打开 http://服务器IP:8090
→ 菜单「手机扫码 → 自动打印」
→ 打开「自动打印」开关
→ 「输出方式」选「自动(推荐)」
→ 这个页面**保持开着**
```

### 4. 手机测试

```
手机扫码 → 生成工单领料/退料单 → 生成时自动打印
→ 这台电脑出纸(或存 PDF)
```

## 三、常见问题

### Q1:电脑重启后要手动再启动吗?

**不用。** 安装时已写入开机自启,开机后自动在后台运行。

验证方式:浏览器打开 `http://127.0.0.1:18777/health`,能返回 JSON 就是活着。

### Q2:改了配置要重启代理吗?

**不用。** 页面上的「输出方式」「PDF 存放目录」是**运行时生效**的,改完立即起作用。

只有改了**端口**才需要重启(而且要同步改服务器上的前端)。

### Q3:那个黑窗口能关吗?

安装时是**隐藏窗口**启动的,正常情况下看不到。

如果你手动双击 `print-agent.ps1` 跑,那个窗口关掉代理就停了 —— 请用「安装.bat」。

### Q4:打印机没连上怎么办?

默认「自动」模式会:
1. 先找真打印机(自动排除 Microsoft Print to PDF / XPS / OneNote / Fax)
2. 找不到 → 直接存 PDF
3. 找到但打失败(离线/缺纸)→ **也存 PDF**

所以**永远不会"点了没反应"**。

### Q5:PDF 存到哪?能改吗?

默认:

```
<print-agent 所在目录>\print-out\
```

改法:页面「PDF 存放目录」填新路径,例如 `D:\MES-PDF`,保存即生效(目录会自动创建)。

### Q6:同一台电脑能装两个吗?

不能(端口冲突)。第二个会自己退出并提示"端口被占用"。

一个**局域网**里可以有多台打印电脑,但**同一时间只建议开一台**——任务是被先取先得的,
开两台会随机分到其中一台上。

### Q7:怎么确认任务有没有到?

页面「连接状态」里能看到:
- 队列待打印数
- 最近心跳
- 最近的出纸记录(「已出纸」或「已生成 PDF:文件名」)

---

## 四、卸载

双击「卸载.bat」:取消开机自启 + 结束进程。

**不会删除**已生成的 PDF,需要的话自己清理。

彻底清理:删掉整个 `print-agent` 文件夹。

## 五、给运维的补充

### 端口

固定 `18777`,只绑 `127.0.0.1`(**不对外网开放**,局域网其它机器访问不到)。

如果确实要改端口,两处必须同步:

1. 代理启动参数 `-Port`
2. 前端 `frontend/src/business/printStation.js` 的 `AGENT_URL`,以及 `PrintStation.vue` 里的 `fetch('http://127.0.0.1:18777/...')`

### 手动命令行方式

```powershell
# 安装 + 启动(Auto 模式)
powershell -ExecutionPolicy Bypass -File 安装.ps1

# 指定模式
powershell -ExecutionPolicy Bypass -File 安装.ps1 -Mode Pdf

# 只跑代理(不写自启)
powershell -ExecutionPolicy Bypass -File print-agent.ps1 -Mode Auto
```

### 接口

| 接口 | 说明 |
|---|---|
| `GET /health` | 存活检查,返回 `{ok, mode, printer, pdfDir}` |
| `POST /print` | 打印一张标签 `{工单号, 工单行号, 产品名称, 规格型号, 二维码内容, 二维码图?}` |
| `POST /test` | 打一张测试标签 |
| `GET /config` / `POST /config` | 读/改运行时配置 `{mode, pdfDir}` |

### 日志

代理输出到它自己的控制台窗口。用「安装.bat」装的是隐藏窗口,**看不到输出** ——
排查问题时改成手动运行:

```powershell
powershell -ExecutionPolicy Bypass -File print-agent.ps1 -Mode Auto
```

### 改了这个脚本之后

**必须**确认文件编码是 **UTF-8 with BOM**(前 3 字节 `EF BB BF`)。

PowerShell 5.1 会按本地代码页(GBK)读脚本,**没有 BOM 中文全部乱码、语法直接崩**:

```
Unexpected token '宸ュ崟鍙?' in expression or statement
```

这个坑已经踩过多次。用 VSCode 改的话右下角选 `UTF-8 with BOM`;
命令行校验:

```powershell
$b = [System.IO.File]::ReadAllBytes('print-agent.ps1'); $b[0..2] -join ','
# 应为 239,187,191
```
