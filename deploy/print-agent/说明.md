# 银嘉 MES · 打印代理(客户电脑部署)

> 用途:让**手机点打印**,这台电脑**自动出纸**;没有打印机时自动存成 PDF。

---

## 一、客户电脑需要什么

| 要求 | 说明 |
|---|---|
| Windows 10 / 11 | PowerShell 5.1 是系统自带的,不用装 |
| .NET Framework 4.x | Win10/11 自带(代理用 `System.Drawing` 画标签) |
| **能访问 MES 服务器** | 浏览器能打开 `http://服务器IP:8090` 就行 |
| 打印机(**可选**) | 没有也能用 —— 会自动存 PDF |
| 不需要管理员权限 | 自启写在当前用户 `HKCU\...\Run` 下 |

**不需要**:不需要装 Java、不需要装 Android SDK、不需要仓库代码。

---

## 二、部署步骤(3 分钟)

### 1. 拷贝文件夹

把整个 `print-agent` 文件夹拷到客户电脑,例如:

```
D:\MES打印\print-agent\
    ├─ print-agent.ps1    ← 代理本体(单文件,自包含)
    ├─ 安装.ps1           ← 安装逻辑
    ├─ 安装.bat           ← 双击这个
    ├─ 卸载.bat
    └─ 说明.md
```

> ⚠ **必须整个文件夹一起拷**,只拷 `print-agent.ps1` 也能跑(不含安装脚本),但不方便。

### 2. 双击「安装.bat」

它会依次问你要三样东西:

| 提示 | 填什么 |
|---|---|
| **服务器地址** | 浏览器里访问系统的地址,如 `http://36.140.66.163:8090` |
| **打印机名字** | 手机端显示的名字,回车用计算机名 |
| **密码** | 登录 MES 的密码 |

然后它会:
1. 检查 .NET 组件与打印机
2. **当场登录服务器验证**(验证失败会直接报错,不会装一个连不上的代理)
3. 写配置文件与开机自启
4. **在后台启动代理**
5. 报告状态

看到 `[OK] 登录成功` + `[OK] 代理已启动` 就成功了。

> 🔴 **重要**:装完之后**不需要再开浏览器页面**。
> 代理会自己每 4 秒去服务器取任务 —— 这是 2026-11-03 的架构调整:
> 页面开在公网地址时,浏览器**禁止**它访问本机代理(非安全上下文访问 loopback),
> 页面永远显示「代理未连接」。改成代理主动拉任务后,这条限制就绕开了。

### 3. 在「自动打印」页配置这台电脑(2026-11-04 改版)

```
浏览器打开 http://服务器IP:8090
→ 菜单「手机扫码 → 自动打印」
→ 在「打印电脑」清单里找到**这台电脑**那一行(名字 = 安装时填的 -Station)
→ 打开它右边的开关(只影响这一台)
→ 勾上「生产领料单」(以后有别的报表也会出现在这里,按电脑各自勾)
→ 「输出方式」选「自动(推荐)」
```

要点(和旧版不一样的地方):

- **每台电脑单独配置**:开关和打印类型都是一行一台电脑,勾 A 电脑不影响 B 电脑;
  没打开开关、或没勾类型的电脑**不会**收到打印任务。
- **服务端总闸固定常开**,页面上只显示状态,没有"全局开关"可关 —— 不会出现
  "谁把总开关关了,全厂都不打"。
- **站点名必须和代理的 `-Station` 一致**(安装时填的那个;安装时直接回车 = **计算机名**)。
  清单里的行是代理自己报上来的,名字对不上就看不到自己。
- 同一类型多台电脑都勾了 ⇒ 那几台**都会打印**(各自出一张)。
- **纸张**可以按电脑选:`A5 · 中一刀 210×148.5 横`(默认,和以前一样)或 `A4 横 297×210`。
  选 A4 **只换纸、不缩放** —— 表格和字号大小一个像素都不变,内容从纸张左上角起画,
  多出来的是空白(适合只装了 A4 纸的打印机)。
- 页面**不需要一直开着**(代理自己每 4 秒拉任务);2026-11-04 起页面只负责配置与看状态。

**怎么认出清单里是哪台电脑**(2026-11-05 补):

- 行标题就是**那台电脑装代理时填的站点名**(回车默认 = 计算机名);
- 行下面小字显示**最近心跳时间**和**来源 IP**,两台同名的机器靠 IP 也能区分;
- 想更确定:在那台电脑上打开 `http://127.0.0.1:18777/health`,返回里的 `printer` 就是它的打印机。

**怎么加一台电脑**:

1. 在这个页面的「新增打印电脑」里填上站点名(建议就用那台电脑的计算机名)并「添加」——
   它会先以**离线/未启用**留在清单里;
2. 到那台电脑上双击「安装.bat」装代理,「这台打印机的名字」填**同一个名字**;
3. 代理连上后这一行会在 15 秒内变成**在线**,再把开关打开、勾上要打的报表即可出纸。

**「离线」是什么意思**:90 秒内没收到那台电脑的心跳 —— 电脑关机 / 打印代理没在运行 /
代理不是带 `-Server` 启动的 / 网络不通。离线期间**不给它派单**,手机端会退回自己弹打印;
清单里离线的行在 30 分钟后自动消失(只是显示,配置不会丢)。

### 4. 手机测试

```
手机扫码 → 生成工单领料/退料单 → 生成时自动打印
→ 这台电脑出纸(或存 PDF)
```

## 三、常见问题

### Q1:电脑重启后要手动再启动吗?

**不用。** 安装时已写入开机自启,开机后自动在后台运行。

验证方式:浏览器打开 `http://127.0.0.1:18777/health`,能返回 JSON 就是活着。

### Q2:改了配置要重启代理吗?

**不用。** 页面上的「输出方式」「PDF 存放目录」是**运行时生效**的,改完立即起作用。

只有改了**端口**才需要重启(而且要同步改服务器上的前端)。

### Q2.1:升级到 2026-11-04 那版后突然不打了?

本次把"全局开关"改成**按电脑的站点开关**(用户口径:设置的电脑开、没设置的不开)。
升级顺序与自查:

1. 服务器先跑迁移 `tools/migrate-print-station-20261104.sql`(两个账套都要)。
   它会把**旧参数 `print.station_name` 里的那台打印电脑**自动补一条
   「开关=Y + 类型=生产领料单」,所以现网一般不用再点一次就会继续打。
2. 打开「自动打印」页,确认清单里有这台电脑、开关是开的、「生产领料单」是勾的。
3. 清单里**没有**这台电脑 ⇒ 代理没在轮询:确认它是带 `-Server http://服务器:8090` 启动的
   (每 4 秒自己拉任务);只双击 `print-agent.ps1` 不带 `-Server` 的,只能由浏览器页面推任务。
4. 站点名对不上(`-Station` 与清单名字不一致)⇒ 清单里会多出一行,把两边名字统一即可。

### Q2.2:以后要加别的报表怎么办?

后端在 `PrintStationController.PRINT_TYPES` 注册新类型(如 `RETURN_SLIP`/退料单)、
产出方在 `POST /api/px/print/enqueue` 的 `类型` 里带上这个 code,「自动打印」页的勾选框
就会自动多一项,按电脑各自勾即可;纸面版式不同的话再给 `print-agent.ps1` 加一段绘制分支。

### Q2.3:一张领料单明细超过 9 行 / 10 行怎么办?(2026-11-05)

**能打,没有行数上限。** 一页放 **10 行**,超出自动**续页**:第 11 行起印在第 2 页,
抬头(二维码/单号/部门/日期)、表格线、四栏签名都重画一遍,右上角标「第 n/N 页」。

同时修掉两个版面问题:

- **空行不再填订单号**:纸表是固定 8 行格子,以前空行也印 `GD-…-#1`,看上去像有 8 行明细;
  现在只有真有数据的行才印订单号;
- **二维码缩小**:132px → 96px(≈24mm),扫码够用,不再挤掉标题和表格宽度。

> ⚠ 这两处改动在**代理端**(`print-agent.ps1`),不在服务器 jar 里 ——
> 换新版时要把 `print-agent.ps1` 拷到打印电脑(或重新跑一次「安装.bat」),
> 然后让代理重启(任务管理器结束 `powershell.exe` 里跑 print-agent 的那个进程,
> 或直接重启电脑)。不换文件的话,打印版式仍是旧的。

### Q3:那个黑窗口能关吗?

安装时是**隐藏窗口**启动的,正常情况下看不到。

如果你手动双击 `print-agent.ps1` 跑,那个窗口关掉代理就停了 —— 请用「安装.bat」。

### Q4:打印机没连上怎么办?

默认「自动」模式会:
1. 先找真打印机(自动排除 Microsoft Print to PDF / XPS / OneNote / Fax)
2. 找不到 → 直接存 PDF
3. 找到但打失败(离线/缺纸)→ **也存 PDF**

所以**永远不会"点了没反应"**。

### Q5:PDF 存到哪?能改吗?

默认:

```
<print-agent 所在目录>\print-out\
```

改法:页面「PDF 存放目录」填新路径,例如 `D:\MES-PDF`,保存即生效(目录会自动创建)。

### Q6:同一台电脑能装两个吗?

不能(端口冲突)。第二个会自己退出并提示"端口被占用"。

一个**局域网**里可以有多台打印电脑,但**同一时间只建议开一台**——任务是被先取先得的,
开两台会随机分到其中一台上。

### Q7:怎么确认任务有没有到?

页面「连接状态」里能看到:
- 队列待打印数
- 最近心跳
- 最近的出纸记录(「已出纸」或「已生成 PDF:文件名」)

## 五、给运维的补充

### 端口

固定 `18777`,只绑 `127.0.0.1`(**不对外网开放**,局域网其它机器访问不到)。

如果确实要改端口,两处必须同步:

1. 代理启动参数 `-Port`
2. 前端 `frontend/src/business/printStation.js` 的 `AGENT_URL`,以及 `PrintStation.vue` 里的 `fetch('http://127.0.0.1:18777/...')`

### 手动命令行方式

```powershell
# 安装 + 启动(Auto 模式)
powershell -ExecutionPolicy Bypass -File 安装.ps1

# 指定模式
powershell -ExecutionPolicy Bypass -File 安装.ps1 -Mode Pdf

# 只跑代理(不写自启)
powershell -ExecutionPolicy Bypass -File print-agent.ps1 -Mode Auto
```

### 接口

| 接口 | 说明 |
|---|---|
| `GET /health` | 存活检查,返回 `{ok, mode, printer, pdfDir}` |
| `POST /print` | 打印一张标签 `{工单号, 工单行号, 产品名称, 规格型号, 二维码内容, 二维码图?}` |
| `POST /test` | 打一张测试标签 |
| `GET /config` / `POST /config` | 读/改运行时配置 `{mode, pdfDir}` |

### 日志

代理输出到它自己的控制台窗口。用「安装.bat」装的是隐藏窗口,**看不到输出** ——
排查问题时改成手动运行:

```powershell
powershell -ExecutionPolicy Bypass -File print-agent.ps1 -Mode Auto
```

### 改了这个脚本之后

**必须**确认文件编码是 **UTF-8 with BOM**(前 3 字节 `EF BB BF`)。

PowerShell 5.1 会按本地代码页(GBK)读脚本,**没有 BOM 中文全部乱码、语法直接崩**:

```
Unexpected token '宸ュ崟鍙?' in expression or statement
```

这个坑已经踩过多次。用 VSCode 改的话右下角选 `UTF-8 with BOM`;
命令行校验:

```powershell
$b = [System.IO.File]::ReadAllBytes('print-agent.ps1'); $b[0..2] -join ','
# 应为 239,187,191
```

## 七、开机自启(2026-11-06 补充)

- 自启项名字:`YinjiaMesPrintAgent`,位置 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
  (当前登录用户,登录后自动起;不开机登录不会起);
- **参数是写死在自启项里的**(`-Server / -Factory / -Station / -Mode` 全在那一串命令里),
  配置同时落在 `print-agent.config.json`(含账号密码,已 gitignore,不入库);
- ⚠ **换服务器 / 换站点名 / 换账套之后,必须重跑一次 `安装.bat`**,否则开机起的还是旧参数
   —— 典型症状:**代理在线(心跳在跳)但永远不出纸**,因为它的 `-Server` 指向老地址、
   `-Station` 对不上面板上的那台电脑;
- 核对当前自启参数(不装任何工具,一条命令):

```powershell
(Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'YinjiaMesPrintAgent').YinjiaMesPrintAgent
```

- 想确认"开机那套参数能不能用":先停掉现有代理,再原样执行上面那条命令返回的整串命令,
  看 `http://127.0.0.1:18777/health` 是否返回 `ok:true`、站点是否变在线。

## 八、Windows 7 老电脑(2026-11-10 兼容改造)

现场那台 Win7 双击「安装.bat」先后踩了两个坑:

**坑 1(0x1F 输出中断)**:安装.bat 里 `chcp 65001` 在 Win7 控制台上会让 `Write-Host` 写不进输出缓冲区,
而脚本又是 `$ErrorActionPreference='Stop'`,第一行输出就把安装打断(环境检查都没跑完)。

**坑 2(PowerShell 2.0)**:Win7 自带的是 PowerShell 2.0,没有 `ConvertFrom-Json` / `ConvertTo-Json` /
`Invoke-WebRequest`(都是 3.0+ 才有)。原来脚本直接退出「请先装 WMF 5.1」。

**现在两个坑都补了:客户双击「安装.bat」即可,不需要装 WMF、不需要任何额外操作。**

| 改动 | 说明 |
|---|---|
| 去掉 `chcp 65001` | 改成 `chcp 936`,安装.bat 以 **GBK** 保存(中文/中文文件名在 Win7 正常) |
| `Write-Host` → `Say` | 先试带颜色输出;写不进控制台就退 `[Console]::Out`,再不行只写日志 —— **不会再把安装打断** |
| **PS 2.0 兼容层 `compat-ps2.ps1`** | PS<3 时自动加载,补上 JSON 解析/生成与 HTTP 请求;PS 3~5 仍用系统自带命令 |
| `Get-Printer` → `.NET InstalledPrinters` | Win7/PS2 就有,Win10 同样可用 |
| `Get-CimInstance` → `Get-WmiObject` / .NET | Win7 原生 WMI,不依赖 CIM 服务 |
| 开 TLS 1.2 | Win7 默认没有 TLS1.2,HTTPS 服务器不加会「连不上」 |
| 安装日志 | 同目录 `install.log`(卸载 `uninstall.log`,代理 `agent.log`),让客户直接发回来 |
| 先体检再安装 | 可跑 `-DryRun`:只检查环境/账号/打印机,不写配置、不设自启、不起代理 |

排障顺序(让客户照做):

1. 确认用的是 **2026-11-10 之后**的文件夹,且里面有 `compat-ps2.ps1`(整个文件夹一起拷,别只拷一个文件);
2. 先跑体检(DryRun),看 `install.log` 最后几行:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File "安装.ps1" -Server http://36.140.66.163:8090 -User admin -Pass 你的密码 -Station 打印机名 -DryRun
```

3. 通过后再双击「安装.bat」正常安装(会问服务器地址/账号/打印点);
4. 只有极老系统(连 **.NET 3.5** 都没有)才会提示先装 .NET 3.5 —— Win7 默认自带,一般遇不到;
5. 仍失败就把 `install.log` 整段发回来 —— 现在所有输出都落这个文件,不用再靠截图。
