# YINJIA-MES 服务器部署说明（Windows）

> 部署包内容：`HSDZ_MES.bak`（数据库备份，含全部数据）、`app.jar`（后端+前端一体）、`start.bat`（启动脚本）、本说明。
> 服务器要求：Windows Server / Windows 10+，可访问外网（装运行时用），内存 ≥ 4GB。

---

## 一、安装 SQL Server（已装可跳过）

1. 下载 **SQL Server 2022 Express**（免费）：
   https://www.microsoft.com/zh-cn/download/details.aspx?id=104781
   选「基本」安装，一路默认（实例名默认 `MSSQLSERVER`，端口 1433）。
2. 安装 **SQL Server Management Studio (SSMS)**（安装完成页有链接，或官网下载）。
3. 装完后打开 SSMS，服务器名填 `localhost`，身份验证选 **Windows 身份验证**，连接。

## 二、恢复数据库

SSMS 里对 `localhost` 新建查询，执行（路径按需调整）：

```sql
-- 1) 恢复数据库（自动放置到默认数据目录）
RESTORE DATABASE [HSDZ_MES]
FROM DISK = N'C:\yinjia\deploy\HSDZ_MES.bak'
WITH RECOVERY,
     MOVE N'ASPSMT'     TO N'C:\Program Files\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQL\DATA\HSDZ_MES.mdf',
     MOVE N'ASPSMT_log' TO N'C:\Program Files\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQL\DATA\HSDZ_MES_log.ldf';

-- 2) 开启混合身份验证所需的应用账号（数据库用户已随备份恢复，这里建服务器登录并映射）
CREATE LOGIN [yinjia] WITH PASSWORD = N'Yinjia@2026', CHECK_POLICY = OFF;
USE [HSDZ_MES];
ALTER USER [yinjia] WITH LOGIN = [yinjia];
-- 若提示登录已存在，只执行上面 ALTER USER 两行即可

-- 3) 授予应用账号必要权限
USE [HSDZ_MES];
EXEC sp_addrolemember N'db_datareader', N'yinjia';
EXEC sp_addrolemember N'db_datawriter', N'yinjia';
EXEC sp_addrolemember N'db_ddladmin',  N'yinjia';
```

> 注意：MOVE 的目标目录以服务器实际安装路径为准（SSMS 里右键服务器→属性→数据库设置可查）。
> 若恢复时提示文件已存在，换个文件名或先 DROP 已有的 HSDZ_MES。

## 三、安装 Java 运行时

后端需要 **JDK/JRE 17 或更高**（推荐 21 LTS）：

- 下载 Temurin 21（Windows x64 .msi）：https://adoptium.net/temurin/releases/?version=21
- 安装时勾选「Set JAVA_HOME」+「Add to PATH」（msi 默认勾选）。
- 验证：开 cmd 执行 `java -version`，显示 21.x 即可。

## 四、放置后端并启动

1. 把部署包放到 `C:\yinjia\`（示例路径，随意）。
2. 双击 `start.bat`（或命令行运行）。首次启动约 5~15 秒。
3. 浏览器打开 `http://localhost:8090` 能看到登录页即成功。
   默认账号 `admin / 123456` —— **上线后立刻改密码**（右上角用户菜单→修改密码）。

## 五、生产环境加固（重要）

1. **修改 admin 密码**：默认 123456 必须改。
2. **JWT 密钥**：编辑 start.bat，取消注释环境变量一行，填 64 位随机十六进制串（本地 PowerShell 生成：
   `-join ((1..64) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })`）。
3. **数据库密码**（可选但推荐）：SSMS 里 `ALTER LOGIN yinjia WITH PASSWORD = N'新密码';`，
   同时改 start.bat 里 `--spring.datasource.password=新密码`（追加在 java -jar 后）。
4. **防火墙**：只放行 8090（入站规则→端口 8090 TCP）。**不要**把 1433 暴露到公网。
5. **云安全组**：在云厂商控制台放行 8090 入方向（源限制为你办公网段更佳）。

## 六、开机自启（可选）

- 简单方案：任务计划程序→创建任务→触发器「启动时」→操作 `C:\yinjia\start-service.bat`。
- 服务方案：下载 NSSM（https://nssm.cc/），`nssm install YinjiaMES "C:\Program Files\Java\jdk-21\bin\java.exe" "-jar C:\yinjia\app.jar"`，失败自动重启在 NSSM 里配。

## 七、常用排查

| 症状 | 处理 |
|---|---|
| 启动报 Connection refused / 登录失败 | SQL Server 服务没起 / yinjia 登录没建或密码不对（见二） |
| 外网打不开 8090 | 服务器防火墙 + 云安全组都没放行 |
| `java -version` 无输出 | JDK 没装或 PATH 没生效，重开 cmd |
| 数据库恢复失败 | 检查 .bak 路径、目标目录存在、SQL 版本 ≥ 2019 |
