# 生产面板单据数据(从服务器拉取,2026-10-18)

> 用途:把**服务器生产库**上「生产制造 / 生产过程」10 张单据面板的实际数据拉成 CSV,随仓库同步到云端,供同事拉取后直接查看/比对,不必连服务器。

## 一、为什么是「从服务器拉」而不是「从 GitHub 拉」

用户在仓库里找不到生产单据数据,核实结果:

| 仓库里的候选 | 实际内容 |
|---|---|
| `db/HSDZ_MES.sql`(2MB) | 83 张表的**建表 + 少量种子数据**(`bs_emp`/`bs_inv`/`bs_op` 等),**不含 `scjl` 也不含 `plang`** |
| `db/scjl-data-20261016.csv` | 只有 **7 行取证样本**(提交信息:「手机端报工行形状取证」),不是全量 |

⇒ 仓库里没有生产单据全量数据,改从服务器拉。

## 四、口径与注意

- **一行 = 一个明细行**;单据没有明细时退化为一行(单据级字段照填)。所以「CSV 行数」可能略大于「单据数」(日报表/投料/混合各多 1 行,来自 2 行明细)。
- **列 = 该面板在界面上可见的字段名**(`单据编号`/`工单号`/`工序`/`报工数量`…),中文列名与界面一致;`saved`/`审核人`/`审批状态` 等运行时字段也一并保留。
- **服务器数据 ≠ 本地库数据**:服务器报工有 1261 张,本机 `scjl` 只有 35 行 —— 两边不是同一份账,不要混用。
- 含工单号/产品/工序/报工人姓名(业务事实数据,与 `db/emp-data-20261018` 同口径保留),**不含任何联系方式**。
- **CSV 是导出时刻的快照**;要看最新数据请直接开系统。

## 五、怎么复跑

```powershell
# 仓库根;需能访问服务器 8090 + 管理员账号(口令走环境变量,不写进仓库)
$env:SRV_BASE='http://36.140.66.163:8090'; $env:SRV_USER='admin'; $env:SRV_PASS='<口令>'
node tools/archive/_prod-export-20261018/_export-prod-csv.mjs
```

脚本只读:登录 → 分页调用 `queryFormDataList` → 写 CSV,不碰服务器数据。

### 两个踩过的坑(留档)

1. **`detail` 的键不固定**:普通单据是 `detail.items`,archive 模式的面板用 `yj_panel.detail_key` 命名(实测 `PROD_ABN` → `detail.prod_abn`)。只读 `items` 会把这类面板导成一行面板元数据。
2. **archive 模式顶层带面板元数据**:顶层 `编号` 是面板名(如「生产异常处理单」)、`状态`/`单据状态` 是「启用」,不是单据字段。判定:顶层「编号」与明细「单据编号」不一致 ⇒ 整行是元数据,丢掉这三个噪音列。
